# DataFetcher管理规范

维护Provider能力、字段映射、缓存键、标准化、质量校验、数据谱系和额度处理。新增数据源只实现统一Provider接口并登记能力，不修改调用方或金融模块。

验收覆盖缓存命中、增量补齐、复权口径、字段缺失、额度耗尽、权限失败、重复请求和DataAssetRef可复现性。凭据只由SecretProvider注入，不进入页面、日志、结果或测试夹具。

## 修改与回滚

可修改Provider、字段映射、缓存和质量规则，但不得改变DataAssetRef协议或调用方金融逻辑。新Provider先以独立能力探测接入；失败时回退到上一个Provider版本和缓存索引，不覆盖已存在的数据资产。

## 冲突升级

字段或复权语义冲突交由General Manager裁决；凭据、服务器和用户授权由App管理，不在本模块保存。
