# 光大红研究档案设计系统

本规范服务于机构结构化产品研究报告的HTML交付。目标是让结论、条款、运行记录、参数与风险边界按统一秩序阅读，而不是把报告设计成仪表盘或营销页面。

## 1. 适用边界

- Designer只渲染已确认的`report-payload.json`，不取数、不计算、不推荐结构、不改变状态。
- `src/design_tokens.py`是唯一机器可读视觉令牌源。`designer-theme.css`只保存选择器和布局规则，运行时由Designer注入令牌；本文件只解释设计意图。
- HTML详细报告固定为连续A4研究版；宽屏提供固定左侧阅读目录，PDF隐藏目录，HTML与PDF正文使用同一主题、同一输入与同一内容。
- 不使用外链字体、图片、CSS或脚本。离线图表仅使用项目内ECharts。

## 2. 色彩令牌

| 语义 | Token | 允许用途 |
| --- | --- | --- |
| 品牌红 | `colors.brand_red` | 题头秩序线、章节引导线、主数据序列、关键结论标记 |
| 冷白纸面 | `colors.paper` | 报告正文纸面 |
| 浅灰背景 | `colors.ground` | 网页阅读背景 |
| 白色表面 | `colors.surface` | 必须独立分层的图表或附件承载面 |
| 墨色 | `colors.ink` | 标题与正文主文字 |
| 深灰蓝 | `colors.ink_soft` | 表格正文、次级标题 |
| 说明灰 | `colors.muted` | 元数据和辅助说明 |
| 来源灰 | `colors.muted_soft` | 小字号来源与次级注记 |
| 暖灰分隔线 | `colors.rule` | 表格行线、章节线、信息网格 |
| 蓝灰数据 | `colors.blue_gray` | 比较序列、来源标题、非主序列数据 |
| 风险金 | `colors.risk_gold` | 风险、未运行状态、阈值提示 |

正式浅色值固定为品牌红`#C8102E`、品牌前景`#FFFFFF`、纸张与表面`#FFFFFF`、中性页面背景`#F4F4F2`、正文`#252628`、次级正文`#404246`、说明文字`#6B7075`、数据蓝灰`#49647D`、风险金`#936719`、分隔线`#E2E0DC`和强分隔线`#C9C5BF`。深色值同样只在`design_tokens.py`定义，品牌红仍为`#C8102E`。其他变量名只允许映射这些正式颜色，不得形成第二种红色或粉色体系。

颜色语义必须稳定。红色不用于风险，金色不用于正常结果，蓝灰不用于主结论。禁止紫色、粉色、霓虹色、装饰性渐变和无语义的高饱和配色。Payload、模板和`presentation_patch`均不得覆盖颜色。

## 3. 字体与层级

- 英文与数字：`Arial`。
- 中文优先使用系统字体：macOS为`PingFang SC`，其他系统交由系统无衬线中文字体回退，不强制指定微软雅黑。
- 不混用第三种展示字体，不使用外链字体，不用等宽字体模拟专业感。

| 角色 | 连续A4 HTML Token | 规则 |
| --- | --- | --- | --- |
| 报告标题 | `type_scale.report_title_a4` | 760字重，字距`-0.03em`，不超过两行 |
| 一级章节 | `type_scale.section_a4` | 750字重，红色短竖线引导，标题后接延展细线 |
| 二级标题 | `type_scale.subsection_a4` | 730字重，深灰蓝 |
| 正文 | `type_scale.report_body` | 1.72行高，最大阅读宽度75ch |
| 表格正文 | `type_scale.table` | 允许长文本换行，不压缩整页 |
| 注记与来源 | `type_scale.meta` | 使用说明灰，仍须可读 |

## 4. 布局与组件

### 网页阅读

- `a4`使用连续A4白纸研究画布。宽屏左侧目录仅作为阅读跳转。没有单次展示要求时，默认阅读顺序为核心结论、结构推荐、合同参数、收益结构、估值定价、历史回测、风险提示。用户明确提出单次展示要求时，可通过受校验的`presentation_patch`增删、改名或移动板块；该变更不写回标准模板。
- 报告纸面使用10px圆角和一次冷灰阴影。内部内容不用投影，不重复使用大圆角卡片。
- 题头以4px品牌红线开始，依次呈现品牌、标题、身份账本和研究链路。
- 章节以红色短竖线、标题和延展细线组织。章节之间只用留白与一条暖色细线分隔。

### 信息组件

- 结论区使用品牌红秩序线、纸张或页面背景色和紧凑内边距，不使用粉色块或色块大标题。
- 条款、身份和指标使用细线网格，不使用无语义边框卡片。
- 图表和收益图使用上下细线与左对齐图注。ECharts颜色顺序固定为品牌红、蓝灰、风险金、中性灰和墨色；多序列同时使用实线、虚线、点线和不同符号，不只依靠颜色区分。
- 表格使用纸张底色、品牌红三线、明确列宽与自动换行。参数快照和结果表遵从各自字段层级。
- 模块未运行、待接入或受限时使用风险金上边线和极浅金底，只展示真实状态与原因。

## 5. 响应式

- 宽度不高于900px时，报告纸面取消阴影、边框和圆角，内容单列展示。
- 宽表保留横向可读性，窄屏通过横向滚动或拆分展示，不缩小正文和表格字号。
- 连续A4报告在窄屏保持同一单列规则，保留全部内容，不引入第二套移动端信息结构。
- 图表、收益图、公式与模块状态块保持完整边界。标题不得与紧随内容分离。

## 6. 动效与无障碍

- `prefers-reduced-motion`下禁用滚动平滑和过渡。
- 正文和说明文字满足可读对比度。跳转正文链接与宽表键盘焦点必须保持清晰可见。
- 不通过颜色单独表达模块状态，状态文字和原因必须始终显示。
- 图表提供读屏摘要和完整数据表；宽表容器必须可由键盘聚焦并明确标注横向滚动区域。
