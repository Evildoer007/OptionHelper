# 页面使用当前输入，历史由运行快照承担

OptDesk中的任务不绑定产品、标的、合同或数据，模块页面也不维护可重新选择的合同方案与版本。每次预览或运行都按当前ProductDefinition和页面当前输入重新编译合同；成功运行完整保存合同快照、数据引用和结果，复现性由明确运行记录承担，而不是由活动合同、父子版本或业务指纹承担。产品规则更新后，系统按`product_id`和正整数`rule_revision`失效该产品旧规则生成的内容，同时保留任务、人工对话和其他产品结果。

## Consequences

模块再次打开时最多恢复最近产品编号，条款、标的和日期从当前默认值开始。页面修改不会覆盖历史运行，失败运行不会产生合同状态。旧任务合同协议和业务哈希不提供兼容读取；首次升级通过隔离且幂等的迁移清理旧任务内容，开发与测试不得对真实App状态执行该迁移。
