# Node发行许可证

`node-v24.18.0-LICENSE.txt`原样归档自Node.js官方v24.18.0标签：

https://raw.githubusercontent.com/nodejs/node/v24.18.0/LICENSE

该文件包含Node本体及其内置第三方依赖的许可证。原生Runtime预检按实际Node版本选择对应文件，随App复制到`Resources/agent-runtime/Nodejs-LICENSE.txt`，并在资源验证时核对原文。更新Node版本时先补齐相同版本的官方完整LICENSE；不复用其他版本的许可证，也不在构建时自动下载。
