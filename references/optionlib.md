# 期权结构库OptionLib

## 1 通用说明

### 1.1 记号

| 符号 | 含义 |
| --- | --- |
| $S_0$ | 单一标的期初价格 |
| $S_t$ | 单一标的在存续期内$t$时刻的价格，其中$0\le t\le T$ |
| $S_T$ | 单一标的到期价格 |
| $t$、$T$ | 存续期内任一观察时刻和到期时刻 |
| $K$ | 行权价；多个行权价按大小记为$K_1<K_2<K_3<K_4$ |
| $N$ | 名义本金 |
| $g$ | 初始保证金比例 |
| $G$ | 初始保证金，$G = N\cdot g$ |

同一结构内$t$仅表示存续期内的观察时刻，$T$仅表示到期时刻。仅在个别结构中使用的符号，在对应结构内首次出现时定义。

### 1.2 损益口径

多头为买方或产品持有方，空头为卖方或发行方，买卖双方构成零和，空头损益与多头损益大小相等、方向相反，故每种结构以多头列示，空头反向。普通期权损益按每份标的计，并已扣除期权费；期权费是取得期权权利或承担期权义务所支付、收取的价格。保证金是履约担保资金，不等于期权费，除非特别说明不计入损益。结构化产品按名义本金折算收益率。有单一盈亏平衡价的结构，盈亏平衡指多头净损益等于零时的到期价格；路径依赖结构未必有单一盈亏平衡价。

### 1.3 行权与结算

欧式在到期时刻$T$依据$S_T$结算，美式在存续期内任一时刻$t$依据$S_t$行权结算，障碍类按约定观察时点检查$S_t$是否触及障碍并在触及时提前结算；除特别说明外均为欧式。

## 2 方向性期权

### 2.1 看涨期权

#### 2.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 多头买入1份看涨期权 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例取$K = S_0 = 100$ |
| 期权费 | $c$，多头即买方在期初支付，空头即卖方在期初收取，示例$c = 5$ |
| 行权方式 | 欧式，仅在到期时刻$T$行权；若为美式，则存续期内任一时刻$t$均可行权 |

#### 2.1.2 损益结构

多头净损益 = $\max(S_T-K,0)-c$，其中$\max(S_T-K,0)$ 为到期时刻的行权价值，$c$为期初支付的期权费；空头损益与之大小相等、方向相反。盈亏平衡为到期价格$S_T = K+c$。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\le K$ |$-c$ |
| $S_T>K$ | $S_T-K-c$ |

#### 2.1.3 示例

$S_0 = 100$、$K = 100$、$c = 5$，盈亏平衡在$S_T = K+c = 105$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T<K$，不行权 |$-5$ |$+5$ |
| $100$ | $S_T = K$，不行权 |$-5$ |$+5$ |
| $105$ | 行权，恰好损益为零 | $0$ | $0$ |
| $110$ | 行权 |$+5$ |$-5$ |
| $120$ | 行权 |$+15$ |$-15$ |

多头在$S_T$超过105后开始盈利，标的每上涨一元收益增加一元；空头在$S_T$不超过105时盈利，最大盈利为期权费5，超过105后亏损随涨幅扩大且没有上限。

#### 2.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看空到中性，判断标的不会明显上涨、大概率横盘或小幅下跌；同时做空波动率，预期隐含波动率偏高且回落，靠时间价值获利 | $S_T$不高于$K$时保留全部期权费$c$即最大盈利；高于$K$后按$S_T-K$赔付、亏损随涨幅扩大且没有上限，盈亏平衡在$K+c$。常在持有标的的同时卖出看涨即备兑，以让渡上行空间换取期权费收入 |
| 期权持有方 | 看涨，判断标的在存续期内上涨且到期涨幅超过期权费；同时做多波动率，标的越涨、波动越大越有利；隐含波动率处于较低分位、期权价格较低时买入成本更低 | $S_T$高于$K+c$才盈利，之后标的每上涨一元收益增加一元、没有上限；$S_T$落在$K$与$K+c$之间时仍亏损，但亏损小于期权费$c$；$S_T$不高于$K$时亏损全部期权费$c$，即最大亏损。相比直接买入标的，占用资金少、下行风险封顶 |

#### 2.1.5 总结

看涨期权以固定期权费换取标的上涨的全部收益，适合明确看涨且希望把最大亏损锁定在期权费内的情形。到期价格只有超过行权价加期权费才产生净利润；上涨越多，收益越高。卖方的期权费收入有限，但需要承担标的大幅上涨的风险。

### 2.2 看跌期权

#### 2.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 多头买入1份看跌期权 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例取$K = S_0 = 100$ |
| 期权费 | $p$，多头即买方在期初支付，空头即卖方在期初收取，示例$p = 5$ |
| 行权方式 | 欧式，仅在到期时刻$T$行权；若为美式，则存续期内任一时刻$t$均可行权 |

#### 2.2.2 损益结构

多头净损益 = $\max(K-S_T,0)-p$，其中$\max(K-S_T,0)$ 为到期时刻的行权价值，$p$为期初支付的期权费；空头损益与之大小相等、方向相反。盈亏平衡为到期价格$S_T = K-p$。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\ge K$ |$-p$ |
| $S_T<K$ | $K-S_T-p$ |

#### 2.2.3 示例

$S_0 = 100$、$K = 100$、$p = 5$，盈亏平衡在$S_T = K-p = 95$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $110$ | $S_T>K$，不行权 |$-5$ |$+5$ |
| $100$ | $S_T = K$，不行权 |$-5$ |$+5$ |
| $95$ | 行权，恰好损益为零 | $0$ | $0$ |
| $90$ | 行权 |$+5$ |$-5$ |
| $80$ | 行权 |$+15$ |$-15$ |

多头在$S_T$跌破95后开始盈利，标的每下跌一元收益增加一元，最大收益在标的跌至零时为95；空头在$S_T$不低于95时盈利，最大盈利为期权费5，到期价格跌破95后被行权、须按$K$买入标的并承担扩大的亏损。

#### 2.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看多到中性，判断标的不会明显下跌、大概率横盘或小幅上涨；同时做空波动率，预期隐含波动率偏高且回落，并可接受在更低价位买入标的 | $S_T$不低于$K$时保留全部期权费$p$即最大盈利；到期价格低于$K$时被行权，须按行权价$K$买入标的，承担$K-S_T$的亏损，最大亏损$K-p$，盈亏平衡在$K-p$。相当于预收期权费，并承诺在到期价格低于$K$时按$K$买入标的，也是雪球等结构中投资者承担下行风险换取票息的基础形态 |
| 期权持有方 | 看跌，判断标的在存续期内下跌且到期跌幅超过期权费，或不判断方向只为持仓买保险；同时做多波动率，标的越跌、波动越大越有利；隐含波动率较低时保护成本便宜 | $S_T$低于$K-p$才盈利，标的价格越低收益越大，最大收益$K-p$即标的跌到零；$S_T$落在$K-p$与$K$之间时仍亏损，但亏损小于期权费$p$；$S_T$不低于$K$时亏损全部期权费$p$，即最大亏损。市场大幅下跌时隐含波动率往往显著上升、保护成本上升，宜在隐含波动率较低时提前买入 |

#### 2.2.5 总结

看跌期权以固定期权费获得标的下跌时的收益，可用于直接看跌，也可作为现货持仓的下行保护。到期价格低于行权价减期权费才盈利，标的下跌越多，保护效果越明显。卖方以收取期权费为代价，承担标的下跌时按行权价买入的风险。

## 3 垂直价差

用两个同类型、不同行权价的期权一买一卖构成，方向温和、收益封顶。设价差宽度$W = K_2-K_1$，净支出记$D$、净收入记$C$。四种价差按常用命名分别列示；其中牛市看涨与熊市看涨互为对手方、牛市看跌与熊市看跌互为对手方，同一对的两个损益反向。


### 3.1 牛市看涨价差

#### 3.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入$c(K_1)$、卖出$c(K_2)$，$K_1<K_2$，构成一个净支出组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 低行权价$K_1$、高行权价$K_2$，示例$K_1 = 95$、$K_2 = 105$ |
| 净支出 | $D = c(K_1)-c(K_2)$，期初净额支付，示例$D = 4$ |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 3.1.2 损益结构

多头净损益 = $\max(S_T-K_1,0)-\max(S_T-K_2,0)-D$。盈亏平衡为$S_T = K_1+D$；最大盈利$W-D$，在$S_T\ge K_2$取得；最大亏损$D$，在$S_T\le K_1$取得。对手方即熊市看涨价差，损益反向。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\le K_1$ |$-D$ |
| $K_1<S_T<K_2$ | $S_T-K_1-D$ |
| $S_T\ge K_2$ | $W-D$ |

#### 3.1.3 示例

$K_1 = 95$、$K_2 = 105$、$D = 4$，$W = 10$，盈亏平衡在$S_T = K_1+D = 99$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T\le K_1$ |$-4$ |$+4$ |
| $99$ | $K_1$与$K_2$之间，恰好损益为零 | $0$ | $0$ |
| $105$ | $S_T\ge K_2$ |$+6$ |$-6$ |
| $110$ | $S_T\ge K_2$ |$+6$ |$-6$ |

多头在$S_T$超过99后盈利，涨到105及以上收益封顶于6；跌至95及以下亏损封顶于4。收益与亏损两端都被锁定。

#### 3.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看空到中性，即熊市看涨价差，判断标的难以上涨至$K_1$以上；期初收取净额，承担有限上行风险 | $S_T$不高于$K_1$时保留净收入即最大盈利；涨破$K_2$后亏损封顶为$W-D$；盈亏平衡在$K_1+D$ |
| 期权持有方 | 温和看涨，判断标的上涨但涨幅有限、难以超过$K_2$；卖出高行权价腿收回部分期权费以降低成本，代价是收益封顶 | $S_T$高于$K_1+D$才盈利，涨到$K_2$以上锁定最大盈利$W-D$；$S_T$落在$K_1$与$K_1+D$之间仍亏损但小于$D$；$S_T$不高于$K_1$时亏损全部净支出$D$ |

#### 3.1.5 总结

牛市看涨价差通过买入低行权价看涨、卖出高行权价看涨，把单边看涨改为有限收益、有限亏损的组合。卖出高行权价腿降低了期初成本，但也放弃了超过高行权价后的额外上涨收益。适合预期标的温和上涨而非大幅突破的情形。

### 3.2 牛市看跌价差

#### 3.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 卖出$p(K_2)$、买入$p(K_1)$，$K_1<K_2$，构成一个净收入组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 低行权价$K_1$、高行权价$K_2$，示例$K_1 = 95$、$K_2 = 105$ |
| 净收入 | $C = p(K_2)-p(K_1)$，期初净额收取，示例$C = 6$ |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 3.2.2 损益结构

多头净损益 = $C-\max(K_2-S_T,0)+\max(K_1-S_T,0)$。盈亏平衡为$S_T = K_2-C$；最大盈利$C$，在$S_T\ge K_2$取得；最大亏损$W-C$，在$S_T\le K_1$取得。与牛市看涨价差到期损益等价，区别在期初收取净额而非支付。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\ge K_2$ | $C$ |
| $K_1<S_T<K_2$ | $C-(K_2-S_T)$ |
| $S_T\le K_1$ | $C-W$ |

#### 3.2.3 示例

$K_1 = 95$、$K_2 = 105$、$C = 6$，$W = 10$，盈亏平衡在$S_T = K_2-C = 99$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $110$ | $S_T\ge K_2$ |$+6$ |$-6$ |
| $99$ | $K_1$与$K_2$之间，恰好损益为零 | $0$ | $0$ |
| $95$ | $S_T\le K_1$ |$-4$ |$+4$ |
| $90$ | $S_T\le K_1$ |$-4$ |$+4$ |

多头在$S_T$不低于105时赚满净收入6，跌破99后转亏，跌至95及以下亏损封顶于4。

#### 3.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看空到中性，即熊市看跌价差，判断标的下跌但跌幅有限；期初支付净额，承担有限下行收益 | $S_T$跌破$K_2-C$才盈利，跌到$K_1$以下锁定最大盈利$W-C$；$S_T$不低于$K_2$时亏损全部净支出 |
| 期权持有方 | 温和看涨，判断标的不明显下跌、大概率守在$K_2$以上；希望期初即收取净额，并把下行亏损锁定 | $S_T$不低于$K_2$时保留净收入$C$即最大盈利；跌破$K_1$后亏损封顶为$W-C$；盈亏平衡在$K_2-C$ |

#### 3.2.5 总结

牛市看跌价差通过卖出高行权价看跌、买入低行权价看跌，期初先收取净额，并把下行风险限制在两个行权价之间。只要标的未明显下跌即可获利，收益上限是期初净收入；深度下跌时，保护腿使亏损封顶。适合温和看涨或判断标的能够守住关键价格的情形。

| --- | --- | --- |
| 期权对手方 | 温和看多到中性，即牛市看跌价差，判断标的难以跌破$K_2$；期初收取净额，承担有限下行风险 | $S_T$不低于$K_2$时保留净收入即最大盈利；跌破$K_1$后亏损封顶为$W-D$；盈亏平衡在$K_2-D$ |
| 期权持有方 | 温和看跌，判断标的下跌但跌幅有限、难以跌破$K_1$；买入高行权价腿、卖出低行权价腿降低成本，收益封顶 | $S_T$低于$K_2-D$才盈利，跌到$K_1$以下锁定最大盈利$W-D$；$S_T$落在$K_2-D$与$K_2$之间仍亏损但小于$D$；$S_T$不低于$K_2$时亏损全部净支出$D$ |

#### 3.3.5 总结

熊市看跌价差通过买入高行权价看跌、卖出低行权价看跌，以有限期权费押注标的温和下跌。卖出低行权价腿降低成本，同时限制标的深跌后的额外收益。适合预期下跌幅度有限、希望明确最大亏损的情形。

### 3.4 熊市看涨价差

#### 3.4.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 卖出$c(K_1)$、买入$c(K_2)$，$K_1<K_2$，构成一个净收入组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 低行权价$K_1$、高行权价$K_2$，示例$K_1 = 95$、$K_2 = 105$ |
| 净收入 | $C = c(K_1)-c(K_2)$，期初净额收取，示例$C = 6$ |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 3.4.2 损益结构

多头净损益 = $C-\max(S_T-K_1,0)+\max(S_T-K_2,0)$。盈亏平衡为$S_T = K_1+C$；最大盈利$C$，在$S_T\le K_1$取得；最大亏损$W-C$，在$S_T\ge K_2$取得。与熊市看跌价差到期损益等价，区别在期初收取净额而非支付。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\le K_1$ | $C$ |
| $K_1<S_T<K_2$ | $C-(S_T-K_1)$ |
| $S_T\ge K_2$ | $C-W$ |

#### 3.4.3 示例

$K_1 = 95$、$K_2 = 105$、$C = 6$，$W = 10$，盈亏平衡在$S_T = K_1+C = 101$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T\le K_1$ |$+6$ |$-6$ |
| $101$ | $K_1$与$K_2$之间，恰好损益为零 | $0$ | $0$ |
| $105$ | $S_T\ge K_2$ |$-4$ |$+4$ |
| $110$ | $S_T\ge K_2$ |$-4$ |$+4$ |

多头在$S_T$不高于95时赚满净收入6，涨破101后转亏，涨至105及以上亏损封顶于4。

#### 3.4.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看多到中性，即牛市看涨价差，判断标的上涨但涨幅有限；期初支付净额，承担有限上行收益 | $S_T$高于$K_1+C$才盈利，涨到$K_2$以上锁定最大盈利$W-C$；$S_T$不高于$K_1$时亏损全部净支出 |
| 期权持有方 | 温和看跌，判断标的不明显上涨、大概率不超过$K_1$；希望期初即收取净额，并把上行亏损锁定 | $S_T$不高于$K_1$时保留净收入$C$即最大盈利；涨破$K_2$后亏损封顶为$W-C$；盈亏平衡在$K_1+C$ |

#### 3.4.5 总结

熊市看涨价差通过卖出低行权价看涨、买入高行权价看涨，期初收取净额，以有限风险换取标的不涨的收益。收益上限是净收入，标的大涨时由买入高行权价看涨限制亏损。适合温和看跌或判断标的难以突破上方压力位的情形。

## 4 波动率与区间

方向多为中性，核心是押波动率大小或到期落点。跨式与宽跨式的多头做多波动率，标的波动越大越有利；蝶式与鹰式的多头相反，做空波动率，押标的到期落在特定区间、波动越小越有利。各结构多头均期初净支出、空头净收入，以多头列示、空头反向。蝶式与鹰式的净支出记$D$、净收入记$C$。


### 4.1 跨式

#### 4.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入同一行权价$K$、同一到期的看涨与看跌各1份 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 成本 | $c+p$，期初支付，示例$c = p = 7$，合计14 |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 4.1.2 损益结构

多头净损益 = $|S_T-K|-(c+p)$。两个盈亏平衡为$S_T = K-(c+p)$ 与$S_T = K+(c+p)$；最大亏损$c+p$，在$S_T = K$取得；上行与下行收益均无上限。空头损益与之大小相等、方向相反。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T<K$ | $K-S_T-(c+p)$ |
| $S_T = K$ | $-(c+p)$ |
| $S_T>K$ | $S_T-K-(c+p)$ |

#### 4.1.3 示例

$K = 100$、$c = p = 7$，成本14，盈亏平衡在$S_T = 86$与$S_T = 114$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $80$ | $S_T<K$ |$+6$ |$-6$ |
| $86$ | 下行盈亏平衡 | $0$ | $0$ |
| $100$ | $S_T = K$ |$-14$ |$+14$ |
| $114$ | 上行盈亏平衡 | $0$ | $0$ |
| $120$ | $S_T>K$ |$+6$ |$-6$ |

多头在$S_T$跌破86或涨过114后盈利，停在100附近亏损最大14；空头相反，标的越接近100越有利。

#### 4.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的窄幅震荡、无大行情，预期隐含波动率偏高且回落；做空波动率，靠时间价值获利 | $S_T$停在$K$附近赚满$c+p$即最大盈利；偏离$K$超过$c+p$后转亏，方向剧烈波动时亏损无上限，须对冲 |
| 期权持有方 | 判断标的短期大幅波动但方向不明，如重大事件公布前；做多波动率，要求已实现波动显著超过隐含波动 | $S_T$偏离$K$超过$c+p$才盈利，无论上行下行、偏离越大收益越大且无上限；停在$K$附近亏损最大，为$c+p$ |

#### 4.1.5 总结

跨式同时买入看涨和看跌，买的是到期价格偏离行权价的幅度，而不是方向。两腿期权费构成最大亏损，只有上涨或下跌幅度超过总成本才盈利。适合预期将出现大幅波动、但无法判断方向的情形；卖方则承担双向大幅波动的风险。

### 4.2 宽跨式

#### 4.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入低行权价看跌$p(K_p)$ 与高行权价看涨$c(K_c)$，$K_p<K_c$ |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 看跌行权价$K_p$、看涨行权价$K_c$，示例$K_p = 90$、$K_c = 110$ |
| 成本 | $c+p$，期初支付，示例合计8 |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 4.2.2 损益结构

多头净损益 = $\max(K_p-S_T,0)+\max(S_T-K_c,0)-(c+p)$。两个盈亏平衡为$S_T = K_p-(c+p)$ 与$S_T = K_c+(c+p)$；最大亏损$c+p$，在$K_p\le S_T\le K_c$取得；两侧收益无上限。空头损益反向。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T<K_p$ | $K_p-S_T-(c+p)$ |
| $K_p\le S_T\le K_c$ | $-(c+p)$ |
| $S_T>K_c$ | $S_T-K_c-(c+p)$ |

#### 4.2.3 示例

$K_p = 90$、$K_c = 110$，成本8，盈亏平衡在$S_T = 82$与$S_T = 118$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $78$ | $S_T<K_p$ |$+4$ |$-4$ |
| $82$ | 下行盈亏平衡 | $0$ | $0$ |
| $100$ | $K_p$与$K_c$之间 |$-8$ |$+8$ |
| $118$ | 上行盈亏平衡 | $0$ | $0$ |
| $122$ | $S_T>K_c$ |$+4$ |$-4$ |

多头在$S_T$跌破82或涨过118后盈利，落在90与110之间亏损最大8；空头相反。

#### 4.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的长期区间震荡；做空波动率，安全区比卖出跨式更宽 | $S_T$落在$K_p$与$K_c$之间赚满$c+p$、胜率高于卖出跨式，但收取的期权费较少；突破区间后亏损无上限 |
| 期权持有方 | 判断标的大幅波动、方向不明，但希望比跨式更低成本；做多波动率 | 用更虚值的行权价降低成本，$S_T$突破$K_p-(c+p)$ 或$K_c+(c+p)$ 才盈利，需要更大波动；落在$K_p$与$K_c$之间亏损最大，为$c+p$ |

#### 4.2.5 总结

宽跨式同时买入虚值看跌和虚值看涨，用更低成本押注大幅波动。相较跨式，获利所需的价格变动更大，但最大亏损较低。适合预期存在大行情、同时接受需要更强波动才能盈利的情形。

### 4.3 蝶式

#### 4.3.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入$c(K_1)$、卖出2份$c(K_2)$、买入$c(K_3)$，$K_2 = (K_1+K_3) / 2$；全用看跌构造损益相同 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K_1<K_2<K_3$，示例$K_1 = 90$、$K_2 = 100$、$K_3 = 110$ |
| 净支出 | $D$，期初净额支付，示例$D = 2.5$ |
| 行权方式 | 欧式，各腿均在到期时刻$T$行权 |

#### 4.3.2 损益结构

多头净损益 = $\max(S_T-K_1,0)-2\cdot \max(S_T-K_2,0)+\max(S_T-K_3,0)-D$。两个盈亏平衡为$S_T = K_1+D$与$S_T = K_3-D$；最大盈利为($K_2-K_1)-D$，在$S_T = K_2$时取得；最大亏损为$D$，在$S_T\le K_1$或$S_T\ge K_3$时取得。对手方即卖出蝶式，损益反向。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\le K_1$或$S_T\ge K_3$ |$-D$ |
| $K_1<S_T\le K_2$ | $S_T-K_1-D$ |
| $K_2<S_T<K_3$ | $K_3-S_T-D$ |

#### 4.3.3 示例

$K_1 = 90$、$K_2 = 100$、$K_3 = 110$、$D = 2.5$，盈亏平衡在$S_T = 92.5$与$S_T = 107.5$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T\le K_1$ |$-2.5$ |$+2.5$ |
| $92.5$ | 下侧盈亏平衡 | $0$ | $0$ |
| $100$ | $S_T = K_2$，峰值 |$+7.5$ |$-7.5$ |
| $107.5$ | 上侧盈亏平衡 | $0$ | $0$ |
| $110$ | $S_T\ge K_3$ |$-2.5$ |$+2.5$ |

多头在$S_T$落于92.5与107.5之间盈利，收在100时最大7.5；偏离到90及以下或110及以上亏损最大2.5。

#### 4.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的到期明显偏离$K_2$、朝任一方向走出去，即卖出蝶式；温和做多波动率 | $S_T$远离$K_2$至两端之外时保留净收入即最大盈利；恰好收在$K_2$时亏损最大且有限 |
| 期权持有方 | 判断标的到期正好落在$K_2$附近、波动收敛；以很低成本博一个精确落点 | $S_T$落在$K_1+D$与$K_3-D$之间才盈利，恰好收在$K_2$时收益最大 ($K_2-K_1)-D$，偏离越远越少；落到两端之外亏损最大，为$D$，金额小且已知 |

#### 4.3.5 总结

蝶式用有限成本押注到期价格落在中间行权价附近，收益在中间位置最高，偏离越远收益越低。其本质是放弃大幅波动的收益，换取窄区间内的较高回报和明确的最大亏损。适合预期波动收敛、且对到期位置有较明确判断的情形。

### 4.4 鹰式

#### 4.4.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入$c(K_1)$、卖出$c(K_2)$、卖出$c(K_3)$、买入$c(K_4)$，$K_1<K_2<K_3<K_4$ |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K_1<K_2<K_3<K_4$，示例$K_1 = 85$、$K_2 = 95$、$K_3 = 105$、$K_4 = 115$ |
| 净支出 | $D$，期初净额支付，示例$D = 3$ |
| 行权方式 | 欧式，各腿均在到期时刻$T$行权 |

#### 4.4.2 损益结构

多头净损益 = $\max(S_T-K_1,0)-\max(S_T-K_2,0)-\max(S_T-K_3,0)+\max(S_T-K_4,0)-D$。两个盈亏平衡为$S_T = K_1+D$与$S_T = K_4-D$；最大盈利为($K_2-K_1)-D$，在$K_2\le S_T\le K_3$时取得；最大亏损为$D$，在两端之外取得。对手方即卖出鹰式，损益反向。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\le K_1$或$S_T\ge K_4$ |$-D$ |
| $K_1<S_T<K_2$ | $S_T-K_1-D$ |
| $K_2\le S_T\le K_3$ | ($K_2-K_1)-D$ |
| $K_3<S_T<K_4$ | $K_4-S_T-D$ |

#### 4.4.3 示例

$K_1 = 85$、$K_2 = 95$、$K_3 = 105$、$K_4 = 115$、$D = 3$，盈亏平衡在$S_T = 88$与$S_T = 112$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $85$ | $S_T\le K_1$ |$-3$ |$+3$ |
| $88$ | 下侧盈亏平衡 | $0$ | $0$ |
| $100$ | $K_2$与$K_3$之间，平台 |$+7$ |$-7$ |
| $112$ | 上侧盈亏平衡 | $0$ | $0$ |
| $115$ | $S_T\ge K_4$ |$-3$ |$+3$ |

多头在$S_T$落于88与112之间盈利，落在95与105之间收益最大7；偏离到两端之外亏损最大3。

#### 4.4.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的到期走出$K_2$与$K_3$区间、方向不明，即卖出鹰式；温和做多波动率 | $S_T$落在两端之外时保留净收入即最大盈利；落在$K_2$与$K_3$之间亏损最大且有限 |
| 期权持有方 | 判断标的到期落在$K_2$与$K_3$区间、波动收敛，但不押死具体一点；比蝶式容错高 | $S_T$落在$K_1+D$与$K_4-D$之间才盈利，落在$K_2$与$K_3$之间收益最大 ($K_2-K_1)-D$；两端之外亏损最大，为$D$。最高收益略低于同宽蝶式，换来更宽的获利区间 |

#### 4.4.5 总结

鹰式与蝶式同样受益于到期价格落在目标区间，但最大收益形成于两个中间行权价之间，而非单一点位。相比蝶式，鹰式的获利区间更宽，代价是峰值收益通常更低。适合预期标的窄幅波动、但不希望把判断限定在单一价格的情形。

## 5 障碍期权

在普通期权上附加价格触发条件。敲出型在存续期内触及障碍$H$时作废，敲入型在触及$H$后才生效。普通看涨与看跌的到期价值分别为$\max(S_T-K,0)$和$\max(K-S_T,0)$。若以$V_T$表示对应普通期权到期价值，则敲出型净损益为$V_T\cdot\mathbf{1}_{\{\text{全程未触及}H\}}-\text{期权费}$，敲入型净损益为$V_T\cdot\mathbf{1}_{\{\text{曾触及}H\}}-\text{期权费}$。敲入敲出平价：同方向、同行权价、同障碍价格的买入敲入与买入敲出之和等于对应普通期权。观察多为每日观察，障碍附近损益不连续。以下均以多头列示，期权费示例取5，空头损益反向。


### 5.1 向上敲出看涨

#### 5.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入向上敲出看涨，存续期内触及$H$即作废 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$；若提前敲出则终止 |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 障碍价 | 向上障碍$H>K$，示例$H = 120$ |

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的难以触及$H$、合约无法激活；收取期权费 | 标的始终不触及$H$时保留全部期权费；触及$H$且标的下行时按多头收益反向赔付 |
| 期权持有方 | 判断标的先冲高触及$H$、再回落下跌；以低于普通看跌的期权费押这一路径 | 需先触及$H$才生效，激活后$S_T$跌破$K-p$才盈利、越跌越多；始终未触及$H$则即便下跌也作废，只亏期权费$p$ |

#### 5.7.5 总结

向上敲入看跌要求标的先冲高触及上方障碍，再回落下跌，触发后才具备看跌收益。该结构以更低成本押注冲高回落的路径，单纯下跌而未先触及障碍并不能使合约生效。

### 5.8 向下敲入看跌

#### 5.8.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入向下敲入看跌，触及$H$后才生效 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 障碍价 | 向下障碍$H<K$，示例$H = 82$ |
| 观察 | 每日观察$S_t$是否触及$H$ |
| 期权费 | $p$，期初支付，示例$p = 5$ |
| 收益时点 | 到期时刻$T$结算，未触及$H$则作废 |

#### 5.8.2 损益结构

多头净损益 = $\max(K-S_T,0)\cdot\mathbf{1}_{\{\text{曾触及}H\}}-p$。触及$H$激活后同普通看跌、承担下行；始终未触及$H$则作废，为$-p$。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 未触及$H$ |$-p$ |
| 触及$H$后且$S_T<K$ | $K-S_T-p$ |
| 触及$H$后且$S_T\ge K$ |$-p$ |

#### 5.8.3 示例

$K = 100$、$H = 82$、$p = 5$，激活后盈亏平衡在$S_T = 95$。

| 情景 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- |
| 未触及82 |$-5$ |$+5$ |
| 触及82后，$S_T = 75$ |$+20$ |$-20$ |
| 触及82后，$S_T = 90$ |$+5$ |$-5$ |
| 触及82后回升，$S_T = 100$ |$-5$ |$+5$ |

多头只有在标的先跌到82激活、且到期收在95以下时才盈利，越跌越多；从未跌到82则作废，亏损为期权费5。空头则在标的始终守住82时赚取期权费。

#### 5.8.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的不会深跌触及$H$、合约无法激活；收取期权费。这一空头正是雪球投资者承担下行风险换取票息的基础形态 | 标的守在$H$以上、始终不触及时保留全部期权费，相当于赚取票息；一旦跌破$H$激活且标的下行，按多头收益反向承担下行亏损 |
| 期权持有方 | 看跌，且判断标的先破位跌到$H$、再进一步走弱；以低于普通看跌的期权费押这一路径 | 需先触及$H$才生效，激活后$S_T$跌破$K-p$才盈利、越跌越多；始终未跌到$H$则作废，只亏期权费$p$ |

#### 5.8.5 总结

向下敲入看跌要求标的先跌破下方障碍，之后继续走弱时才产生看跌收益。它以较低期权费换取对破位后下跌的敞口，核心风险在于未触及障碍时合约始终无效。该卖方形态也是投资者承担下行风险以换取票息的基础之一。

## 6 二元与数字期权

按到期价格或存续期内是否触碰障碍，支付一笔固定赔付，押的是是非题或概率。记赔付发生的条件成立取1、否则取0。恒等关系：同$K$的现金二元看涨与看跌之和等于赔付$Q$；同$H$、同到期的触碰即付与不碰才付之和等于赔付$Q$。现金二元与触碰型的最大盈利为赔付减期权费、最大亏损为期权费；资产二元赔付为标的价值。以下以多头列示，空头损益反向。


### 6.1 现金二元看涨

#### 6.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入现金二元看涨，到期$S_T>K$支付固定$Q$，否则归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 赔付 | 固定金额$Q$，示例$Q = 20$ |
| 期权费 | $c$，期初支付，示例$c = 8$ |
| 收益时点 | 到期时刻$T$依据$S_T$判定 |

#### 6.1.2 损益结构

多头净损益 = $Q\cdot (S_T>K)-c$。到期损益是$K$处从$-c$跳到$Q-c$的阶梯，与涨幅无关。最大盈利$Q-c$，最大亏损$c$。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\le K$ |$-c$ |
| $S_T>K$ | $Q-c$ |

#### 6.1.3 示例

$K = 100$、$Q = 20$、$c = 8$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $95$ | $S_T\le K$ |$-8$ |$+8$ |
| $100$ | $S_T\le K$ |$-8$ |$+8$ |
| $101$ | $S_T>K$ |$+12$ |$-12$ |
| $120$ | $S_T>K$ |$+12$ |$-12$ |

多头只要到期站上100即净赚12，涨到101与涨到120收益相同；未站上则亏期权费8。

#### 6.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断到期标的站不上$K$；收取期权费，承担站上后的固定赔付 | $S_T$不高于$K$时保留期权费即最大盈利；站上$K$后固定赔付$Q$、净亏$Q-c$ |
| 期权持有方 | 判断到期标的能否站上$K$，只关心是否过线、不关心涨幅；对某价位到期能否守住有明确概率判断 | $S_T$站上$K$得固定净收益$Q-c$；未站上亏期权费$c$。赔付固定，不随涨幅变化 |

#### 6.1.5 总结

现金二元看涨只判断到期是否站上行权价，达到条件即获得固定赔付，涨幅大小不再影响收益。投资者买的是一个价格事件发生的概率，而非上涨幅度；最大收益和最大亏损均在期初确定。适合对关键价位能否被突破有明确判断的情形。

### 6.2 现金二元看跌

#### 6.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入现金二元看跌，到期$S_T<K$支付固定$Q$，否则归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |

#### 6.2.2 损益结构

| 情形或判断条件 | 持有方净损益 |

多头只要到期跌破100即净赚12，跌到99与跌到80收益相同；未跌破则亏期权费8。

#### 6.2.5 总结

现金二元看跌只判断到期是否跌破行权价，触发后支付固定金额，继续下跌不会增加收益。其核心是对到期是否失守关键价位的判断，损益两端在期初已知。适合对支撑位是否会被跌破有明确判断的情形。

### 6.3 资产二元看涨

#### 6.3.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入资产二元看涨，到期$S_T>K$支付标的价值$S_T$，否则归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 赔付 | 标的价值$S_T$ |
| 期权费 | $c$，期初支付，示例$c = 50$ |
| 收益时点 | 到期时刻$T$依据$S_T$判定 |

#### 6.3.2 损益结构

多头净损益 = $S_T\cdot (S_T>K)-c$。站上$K$后赔付随$S_T$线性增大。普通看涨可分解为资产二元看涨减$K$份现金二元看涨，资产二元多用于结构的拆解与重组。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| $S_T\le K$ |$-c$ |
| $S_T>K$ | $S_T-c$ |

#### 6.3.3 示例

$K = 100$、$c = 50$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $95$ | $S_T\le K$ |$-50$ |$+50$ |
| $101$ | $S_T>K$ |$+51$ |$-51$ |
| $120$ | $S_T>K$ |$+70$ |$-70$ |

站上100后，到期价越高多头得到的标的价值越大；未站上则亏期权费50。

#### 6.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的站不上$K$；收取期权费，承担站上后按标的价值的赔付 | $S_T$不高于$K$时保留期权费；站上后按$S_T$赔付、随$S_T$增大而扩大 |
| 期权持有方 | 判断标的站上$K$，并需要站上即按标的价值交付这种支付方式；多用于拆解与重组结构 | $S_T$站上$K$得$S_T-c$，随$S_T$增大而增大；未站上亏期权费$c$ |

#### 6.3.5 总结

资产二元看涨在到期站上行权价后按标的价值支付，收益既取决于是否站上行权价，也随到期价格继续上升。它主要用于拆解和重组更复杂的支付结构，而非单纯表达固定金额的方向判断。

### 6.5 触碰即付

#### 6.5.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入触碰即付，存续期内触及$H$即支付固定$Q$，否则归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$，存续期内任一时刻均可触发 |
| 障碍价 | 触碰价$H$，示例$H = 115$ |
| 赔付 | 固定金额$Q$，示例$Q = 20$ |
| 观察 | 每日观察$S_t$是否触及$H$ |
| 期权费 | $c$，期初支付，示例$c = 8$ |
| 收益时点 | 触及$H$即支付，不要求到期仍在；始终未触及则到期归零 |

#### 6.5.2 损益结构

多头净损益 = $Q\cdot\mathbf{1}_{\{\text{存续期内触及}H\}}-c$。只要任一时刻触及$H$即得$Q$，与到期价格无关。最大盈利$Q-c$，最大亏损$c$。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 触及$H$ | $Q-c$ |
| 始终未触及$H$ |$-c$ |

#### 6.5.3 示例

$H = 115$、$Q = 20$、$c = 8$。

| 情景 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- |
| 存续期内触及115 |$+12$ |$-12$ |
| 始终未触及115 |$-8$ |$+8$ |

多头只要存续期内任一时刻触及115即净赚12，即使到期又回落也不影响；始终触不到则亏期权费8。

#### 6.5.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的整个存续期都触不到$H$；收取期权费，承担触及后的固定赔付 | 始终未触及$H$时保留期权费即最大盈利；触及后固定赔付$Q$、净亏$Q-c$ |
| 期权持有方 | 判断标的会朝某方向触及关键价位$H$，但不确定到期能否守住；波动越大越易触及、越有利 | 存续期内触及$H$即净赚$Q-c$，不要求到期仍在；始终未触及则亏期权费$c$ |

#### 6.5.5 总结

触碰即付只看存续期内是否触及障碍，触发后立即获得固定赔付，到期是否回落不再影响结果。它押注的是价格路径和触碰概率，波动越大通常越有利。适合判断标的会触及关键价位、但不要求到期守住该价位的情形。

### 6.6 不碰才付

#### 6.6.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入不碰才付，存续期内全程未触及$H$才支付固定$Q$，触及即归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$，全程观察 |
| 障碍价 | 触碰价$H$，示例$H = 115$ |
| 赔付 | 固定金额$Q$，示例$Q = 20$ |
| 观察 | 每日观察$S_t$是否触及$H$ |
| 期权费 | $c$，期初支付，示例$c = 8$ |
| 收益时点 | 到期时刻$T$结算，存续期内触及$H$则提前作废 |

#### 6.6.2 损益结构

多头净损益 = $Q\cdot\mathbf{1}_{\{\text{全程未触及}H\}}-c$。全程不触及$H$才得$Q$，中途触及一次即归零。最大盈利$Q-c$，最大亏损$c$。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 全程未触及$H$ | $Q-c$ |
| 触及$H$ |$-c$ |

#### 6.6.3 示例

$H = 115$、$Q = 20$、$c = 8$。

| 情景 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- |
| 全程未触及115 |$+12$ |$-12$ |
| 存续期内触及115 |$-8$ |$+8$ |

多头只要标的全程不触及115即净赚12；中途触及一次即作废、亏期权费8。与触碰即付方向相反，波动越小越有利。

#### 6.6.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的迟早会触及$H$；收取期权费，承担全程未触及时的固定赔付 | 触及$H$后保留期权费即最大盈利；全程未触及则固定赔付$Q$、净亏$Q-c$ |
| 期权持有方 | 判断标的始终在区间内、不会突破到$H$，即窄幅震荡；波动越小越有利 | 全程未触及$H$得净收益$Q-c$；中途触及一次即归零、亏期权费$c$ |


#### 6.6.5 总结

不碰才付要求标的在整个存续期内始终不触及障碍，任何一次触碰都会使固定赔付失效。它押注的是低波动和区间稳定，路径比到期价格更重要。适合预期标的不会突破关键价位的情形，但障碍附近的短暂波动也可能导致全部收益落空。



## 7 气囊结构

气囊（Airbag）在普通看涨敞口上加一层下行保护，形似汽车安全气囊。设期初价 S0、到期价 ST，记涨跌幅 R = ST / S0 − 1；另设敲入线 B（B < S0，示例取 B = 80%·S0，每日观察）。核心机制：存续期内标的从未触及敲入线（未敲入）时，下跌不亏、只放弃期初支付的期权费，上涨则按约定方式参与；一旦触及敲入线（敲入），保护失效，投资者按 R 承担标的的全部涨跌，与直接持有标的相仿。标准型付期权费换取“不封顶的上行参与＋下行保护”，封顶型与折让参与率型以让渡部分上行换取零期权费。以下各结构的敲入线、参与率、封顶水平、期权费均为示例值，可按实际条款调整；以多头（产品持有方）列示，空头为发行方，损益反向，收益按名义本金折算收益率。

### 7.1 标准安全气囊Airbag

#### 7.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入标准安全气囊Airbag，未敲入享上行参与＋下行保护，敲入后承担标的涨跌 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，自期初持有至到期时刻 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲入线 | 敲入价 B，示例 B = 80%·S0，每日观察 St 是否触及 |
| 未敲入收益 | Max(0, R)，即上涨全额参与、下跌保护为零 |
| 敲入后收益 | R，即按标的实际涨跌线性承担 |
| 期权费 | 期初支付，示例取 5% |
| 收益时点 | 到期时刻 T 按 ST 结算 |

#### 7.1.2 损益结构

净收益率 = [未敲入时 Max(0, R)，敲入后 R] − 期权费。未敲入且上涨时收益随涨幅无上限；未敲入且下跌时收益为零、只亏期权费，这就是“气囊”的缓冲；一旦触及 B 敲入，保护失效，按 R 承担全部下跌。最大盈利无上限，最大亏损在敲入且标的大跌时接近 R − 期权费。未敲入时盈亏平衡为 R 等于期权费。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 未敲入且 R > 0 | R − 期权费 |
| 未敲入且 R ≤ 0 | −期权费 |
| 敲入（R 已跌破敲入水平） | R − 期权费 |

#### 7.1.3 示例

示例取 S0 = 100、敲入线 B = 80、期权费 5%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入，上涨 | 全程未触及80，ST = 130（R = +30%） | +25% |
| 未敲入，恰好盈亏平衡 | 全程未触及80，ST = 105（R = +5%） | 0% |
| 未敲入，下跌但不亏本金 | 全程未触及80，ST = 90（R = −10%，未触及敲入线） | −5% |
| 敲入，到期未修复 | 存续期内触及80后，到期ST = 70 | −35% |

多头只要标的始终不触及敲入线，下跌最多亏期权费，上涨则全额参与；一旦跌破敲入线，就按标的实际跌幅承担亏损，与直接持股相仿。

#### 7.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看涨但担心阶段性回调，判断标的不会深跌至敲入线；愿付期权费换取“下跌不亏、上涨全参与” | 未敲入且上涨超过期权费才净盈利、收益无上限；未敲入即便下跌也只亏期权费；触及敲入线后保护失效，按标的跌幅承担亏损 |
| 空头 | 发行方，判断标的大概率上涨有限或将跌破敲入线；收取期权费，承担未敲入上行时的参与赔付 | 标的敲入或到期不涨时保留期权费；未敲入且大涨时按多头收益反向赔付 |

#### 7.1.5 总结

标准安全气囊Airbag由“未敲入前的上行参与＋下行保护”和“敲入后按标的实际涨跌线性承担”两段损益拼接而成：先看存续期内是否触及敲入线，未触及时以固定期权费换取下跌不亏、上涨不封顶；一旦触及敲入线，保护即失效，收益与直接持有标的相近。它是用期权费交换“深跌保护”，适合看涨但担心阶段性深跌、且判断标的不会跌穿敲入线的情形；若标的持续下探并跌破敲入线，保护作用随即消失。

### 7.2 安全气囊Airbag（上涨收益封顶）

#### 7.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入封顶型安全气囊Airbag，以让渡上限以上涨幅换取零期权费 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，自期初持有至到期时刻 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲入线 | 敲入价 B，示例 B = 80%·S0，每日观察 |
| 收益上限 | 封顶水平 Cap，示例取 25% |
| 未敲入收益 | Max[0, Min(Cap, R)]，即上行参与但封顶 |
| 敲入后收益 | R，即按标的实际涨跌线性承担 |
| 期权费 | 示例取 0%，以封顶换取零成本 |
| 收益时点 | 到期时刻 T 按 ST 结算 |

#### 7.2.2 损益结构

净收益率 = 未敲入时 Max[0, Min(Cap, R)]，敲入后 R；期权费为零。未敲入且上涨时收益随涨幅递增但不超过封顶水平 Cap，涨幅再高收益也不增加；未敲入且下跌时收益为零、不亏期权费；敲入后按 R 承担全部下跌。用“放弃封顶以上的涨幅”换来了零成本。最大盈利为 Cap，最大亏损在敲入且标的大跌时接近 R。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 未敲入且 R ≥ Cap | Cap |
| 未敲入且 0 < R < Cap | R |
| 未敲入且 R ≤ 0 | 0 |
| 敲入（R 已跌破敲入水平） | R |

#### 7.2.3 示例

示例取 S0 = 100、敲入线 B = 80、封顶 Cap = 25%、期权费 0%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入，涨幅超过封顶 | 全程未触及80，ST = 140（R = +40%） | +25% |
| 未敲入，涨幅在封顶以内 | 全程未触及80，ST = 115（R = +15%） | +15% |
| 未敲入，下跌但不亏本金 | 全程未触及80，ST = 90（R = −10%，未触及敲入线） | 0% |
| 敲入，到期未修复 | 存续期内触及80后，到期ST = 70 | −30% |

多头零成本参与上行，但涨过封顶水平后收益不再增加；未敲入下跌不亏；跌破敲入线则承担全部跌幅。

#### 7.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看涨但预期涨幅温和、大概率不超过封顶水平，且不愿支付期权费；判断标的不会深跌至敲入线 | 未敲入时涨多少赚多少、以封顶水平为限；未敲入下跌也不亏（零成本）；触及敲入线后按标的跌幅承担亏损 |
| 空头 | 发行方，判断标的涨幅有限或将敲入；以封顶换取不收期权费的结构，承担未敲入且涨幅在封顶以内的赔付 | 标的敲入或不涨时无需赔付；未敲入且上涨时按多头收益（以封顶为限）反向赔付 |

#### 7.2.5 总结

安全气囊Airbag（上涨收益封顶）与标准安全气囊共用同一套敲入判断逻辑，区别在于把上行参与由“不封顶”改为“封顶于 Cap”，以此换取零期权费：未敲入时下跌不亏、上涨参与但达到封顶后不再增加；一旦触及敲入线，保护失效，按标的实际跌幅承担损失。它省去了期初成本，代价是牺牲大涨时的额外收益，适合预期涨幅温和、不愿支付期权费的情形。

### 7.3 安全气囊Airbag（折让上涨参与率）

#### 7.3.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入折让参与率型安全气囊Airbag，以低于 100% 的参与率换取零期权费 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，自期初持有至到期时刻 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲入线 | 敲入价 B，示例 B = 80%·S0，每日观察 |
| 参与率 | 参与率 α，示例取 74% |
| 未敲入收益 | Max(0, R) × α，即上涨按参与率参与 |
| 敲入后收益 | R，即按标的实际涨跌线性承担 |
| 期权费 | 示例取 0%，以折让参与率换取零成本 |
| 收益时点 | 到期时刻 T 按 ST 结算 |

#### 7.3.2 损益结构

净收益率 = 未敲入时 Max(0, R) × α，敲入后 R；期权费为零。未敲入且上涨时按涨幅的 α 参与、上不封顶；未敲入且下跌时收益为零、不亏期权费；敲入后按 R 承担全部下跌。用“打折的上行参与率”换来了零成本，与封顶型相比保留了大涨的空间，但每一元涨幅只拿 α。最大盈利无上限，最大亏损在敲入且标的大跌时接近 R。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 未敲入且 R > 0 | R × α |
| 未敲入且 R ≤ 0 | 0 |
| 敲入（R 已跌破敲入水平） | R |

#### 7.3.3 示例

示例取 S0 = 100、敲入线 B = 80、参与率 α = 74%、期权费 0%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入，大涨 | 全程未触及80，ST = 140（R = +40%） | +29.6% |
| 未敲入，温和上涨 | 全程未触及80，ST = 110（R = +10%） | +7.4% |
| 未敲入，下跌但不亏本金 | 全程未触及80，ST = 90（R = −10%，未触及敲入线） | 0% |
| 敲入，到期未修复 | 存续期内触及80后，到期ST = 70 | −30% |

多头零成本参与上行、且不封顶，但每一元涨幅只拿参与率；未敲入下跌不亏；跌破敲入线则承担全部跌幅。与封顶型相比，大涨时更占优、温和上涨时略逊。

#### 7.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看涨且预期可能大涨、不愿封顶也不愿付期权费；接受每元涨幅只拿参与率 α；判断标的不会深跌至敲入线 | 未敲入时按涨幅的 α 参与、上不封顶；未敲入下跌不亏（零成本）；触及敲入线后按标的跌幅承担亏损 |
| 空头 | 发行方，判断标的涨幅有限或将敲入；以折让参与率换取不收期权费，承担未敲入上行按 α 的赔付 | 标的敲入或不涨时无需赔付；未敲入且上涨时按多头收益（α 参与）反向赔付 |

#### 7.3.5 总结

安全气囊Airbag（折让上涨参与率）同样以未触及敲入线为前提提供下行保护，但把上行参与由“封顶”改为“打折”：未敲入时下跌不亏、上涨不封顶，只是每一元涨幅按参与率 α 打折兑现；一旦触及敲入线，保护失效，按标的实际跌幅承担损失。相较封顶型，它在大涨行情中更占优，在温和上涨行情中收益略逊，适合预期可能出现较大涨幅、又不愿意支付期权费的情形。

## 8 累计期权

累计期权（Accumulator）以约定的执行价格分批买入或卖出标的，通过每日观察收盘价与执行价、敲出价的关系，决定当日成交数量：价格对投资者越有利（如标的下跌）时，通常需要以更大数量成交；价格达到敲出价则提前终止后续观察。它不是单笔到期结算的期权，而是逐日累计买入或卖出的路径依赖结构，最终损益取决于全部成交数量与执行价、结算价格的关系。以下要素、观察日数、执行价、敲出价、单日数量和累计倍数均为示例值，可按实际条款调整；以多头（投资者/买入方）列示，空头为对手方，损益反向。

### 8.1 标准累购

#### 8.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入标准累购合约，按日以折价方式买入标的，价格跌破执行价时加倍买入，价格达到敲出价后合约提前终止 |
| 标的 | 单一个股、指数或指数基金等标的资产 |
| 合约期限 | 自期初持有至到期，共 N 个观察日，每个交易日观察一次，示例取 N = 240 个交易日 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲出价 | H，示例取 H = 105%·S0；任一观察日收盘价 St ≥ H 即触发敲出，当日起停止观察 |
| 执行价格（买入价） | K，示例取 K = 90%·S0，低于期初价；无论当日收盘价高于或低于 K，均按 K 价成交 |
| 单日基础数量 | q，示例取 q = 100 股 |
| 累计倍数 | m，示例取 m = 2；当日收盘价 St < K 时按 m·q 买入，即 200 股 |
| 保股期 | 合约起算后的前 L 个观察日，示例取 L = 20 个交易日 |
| 保股期内敲出 | 敲出日（含）至保股期截止日（含）之间的每个观察日仍按执行价买入基础数量 q，不再判断当日股价，保股期截止后停止买入 |
| 保股期外敲出 | 敲出当日起立即停止买入 |

#### 8.1.2 损益结构

每个观察日先判断合约是否已敲出：未敲出时，若当日收盘价不低于执行价则按执行价买入基础数量 q，若低于执行价则按执行价买入 m·q；一旦某观察日收盘价达到敲出价，当日及以后是否继续买入取决于敲出日是否落在保股期内。全部成交数量累计后，按累计股数与结算价格、执行价的差额计算最终损益：净损益 = 累计买入股数 ×（结算价格 − 执行价）。结算价格越高于执行价，投资者持有的低价买入份额增值越多；标的持续深跌时，因跌破执行价的交易日按加倍数量买入，累计份额被放大，按结算价格计算的亏损也随之放大。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 保股期内敲出（第 d 个观察日敲出，d ≤ L） | 累计买入股数 ×（结算价格 − 执行价），累计股数含敲出前按当日股价判断的买入量与敲出后至保股期截止日按基础数量买入的部分 |
| 保股期外敲出（第 d 个观察日敲出，d > L） | 累计买入股数 ×（结算价格 − 执行价），累计股数为敲出前 d − 1 个观察日按当日股价判断的买入量，敲出当日不买入 |
| 合约期内未敲出（全部 N 个观察日均低于 H） | 累计买入股数 ×（结算价格 − 执行价），累计股数为全部 N 个观察日按当日股价判断的买入量 |

#### 8.1.3 示例

示例取 S0 = 100、H = 105、K = 90、q = 100 股、m = 2、L = 20 个交易日、N = 240 个交易日。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 保股期内敲出 | 第15个观察日敲出（保股期内），此前11天收盘价不低于执行价、3天低于执行价，敲出后至第20天保股期截止再买入6天，结算价格110；累计买入股数 = 11×100 + 3×200 + 6×100 = 2,300股 | 2,300 ×（110 − 90）= 46,000元 |
| 保股期外敲出 | 第60个观察日敲出（保股期外），此前57天收盘价不低于执行价、2天低于执行价，敲出当日不买入，结算价格110；累计买入股数 = 57×100 + 2×200 = 6,100股 | 6,100 ×（110 − 90）= 122,000元 |
| 未敲出，温和下跌 | 全程未达到105，237天收盘价不低于执行价、3天低于执行价，期末价格95；累计买入股数 = 237×100 + 3×200 = 24,300股 | 24,300 ×（95 − 90）= 121,500元 |
| 未敲出，持续深跌 | 全程未达到105，前60天收盘价不低于执行价，其后180天持续低于执行价，期末价格85；累计买入股数 = 60×100 + 180×200 = 42,000股 | 42,000 ×（85 − 90）= −210,000元 |

#### 8.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的将维持震荡或温和上涨、不易持续深跌，愿意按执行价持续向投资者出售标的，并承担标的深跌时按加倍数量出售的义务 | 标的达到敲出价时提前终止义务；标的温和波动或上涨时按执行价出售获得价差收益；标的持续深跌时因加倍出售数量而承担更大敞口 |
| 期权持有方 | 本身有持续买入标的的需求，判断标的将在期初价附近区间震荡或温和上涨，愿意每天以低于期初价的执行价折价买入，并接受价格深跌时加倍买入以摊低成本、价格上涨过快时提前终止不再继续买入 | 标的达到敲出价后不再继续买入，已买入部分若结算价格高于执行价则盈利；标的温和波动或上涨时持续以折价买入获利；标的持续深跌时因加倍买入放大累计份额，按结算价格计算的亏损也相应放大 |

#### 8.1.5 总结

标准累购是一种路径依赖的分批买入结构：每个观察日先看合约是否已敲出，未敲出时按当日收盘价与执行价的高低决定当天买入数量——收盘价不低于执行价时按基础数量买入，跌破执行价时按累计倍数加倍买入，且无论哪种情形均按同一折价执行价成交；一旦某个观察日收盘价达到或超过敲出价，合约随即向提前终止方向发展：若敲出发生在保股期内，仍需按基础数量买入至保股期截止日；若发生在保股期外，敲出当日起立即停止买入。

最终损益取决于累计买入股数与执行价相对结算价格的差额：结算价格越高于执行价，持续折价买入的份额增值越多；若标的持续深跌，跌破执行价交易日的加倍买入会放大累计份额，按结算价格计算的亏损也随之放大。它适合本身就有持续加仓标的需求、且能接受价格下跌时被迫加倍买入的投资者，本质是用“折价买入＋深跌加倍摊薄”换取整体买入成本的降低，但深跌情形下由于份额被动放大，最终亏损也会比不设累计买入机制的普通买入更大。

## 9 自动赎回结构

自动赎回结构以敲出、敲入和票息为核心，涵盖雪球、凤凰式、FCN/DCN等以自动提前终止条款为特征的结构化产品。敲出通常表示标的（或表现最差的标的）在观察日达到或超过敲出价格后产品提前终止并支付约定票息；敲入通常表示标的在观察期内触及或跌破敲入价格后，投资者到期可能承担标的下跌损失。此类结构不是单纯的到期价格结构，必须同时判断存续期内是否敲出、是否敲入以及到期修复情况。本章按分类编号收录已登记结构，编号不连续的部分对应尚待录入的结构，参见optionlist.md。

### 9.1 经典型雪球

#### 9.1.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入经典型雪球产品，发行方卖出该结构 |

| 期限 | 自期初持有至到期时刻$T$，示例为24个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取20%，有追加保证金要求 |
| 初始价格与执行价 | $S_0$，$K = S_0$ |
| 约定票息/年化收益率 | $y$，示例取年化20% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出方向 | 向上敲出 |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |

| 敲出结果 | 产品提前终止，投资者取得截至敲出日的约定票息 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入方向 | 向下敲入 |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}$，示例取$70\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 若未敲出且曾敲入，到期按$S_T$与$S_0$的差额结算；若到期修复至$S_0$或以上，损失为0 |

#### 9.1.2 损益结构

| 情形 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日，使$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$，产品提前终止 |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全部敲入观察节点$S_t>H_{in}$ | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 全部敲出观察日$S_t<H_{out}$，且曾有$S_t\le H_{in}$ | $N\cdot \min((S_T-S_0)/S_0,0)$ |

#### 9.1.3 示例

设标的为中证500，名义本金$N = 1000$万元，期限24个月，初始保证金比例$g = 20\%$，约定票息$y = 20\%$，敲出线$H_{out} = 103\%\cdot S_0$，敲入线$H_{in} = 70\%\cdot S_0$，执行价$K = S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入后提前敲出 | 第240天观察日$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot20\%\cdot\frac{240}{365}=131.5\text{万元}$ |
| 曾敲入后提前敲出 | 存续期内曾跌破$70\%\cdot S_0$，第182天观察日$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot20\%\cdot\frac{182}{365}=99.7\text{万元}$ |
| 未敲出且未敲入 | 全程未达到$103\%\cdot S_0$，也从未低于$70\%\cdot S_0$ | $1000\text{万元}\cdot20\%\cdot2=400\text{万元}$ |
| 曾敲入且到期未修复 | 存续期内曾跌破$70\%\cdot S_0$，到期$S_T=65\%\cdot S_0$ | $1000\text{万元}\cdot(65\%-100\%)=-350\text{万元}$ |

#### 9.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 向投资者出售票息收入，并获得标的下跌时由投资者承担损失的经济敞口 | 发行方收益与投资者相反，主要风险来自标的走势、波动率和敲入敲出路径对冲 |
| 期权持有方 | 判断标的不会持续大幅下跌，接受以承担下行风险换取较高票息 | 标的上涨至敲出线时提前获得票息；震荡但未敲入时持有到期获得票息；一旦敲入且到期低于期初价格，承担全部跌幅损失 |

#### 9.1.5 总结

经典型雪球是最常见的单标的雪球框架：向上敲出、向下敲入、敲入后以期初价格作为到期结算基准。它以较高票息交换投资者对标的大幅下跌风险的承担。

判断顺序应先看是否敲出，敲出即提前按持有期结算票息；未敲出时再看是否发生过敲入，未敲入则取得到期票息；若曾敲入，则到期价格低于期初价格时按跌幅承担损失，到期回到期初价格或以上时损失为0。它适合对标的持中性偏多判断、且能够承受敲入后下跌风险的投资者。

#### 9.2.2 损益结构

| 情形 | 判断条件 | 持有方净损益 |
| --- | --- | --- |

#### 9.2.3 示例

| --- | --- | --- |
| 提前敲出 | 第8个月观察日$S_t=104\%\cdot S_0$ | $N\cdot 12\%\cdot 8/12 = 80$万元 |

| 曾敲入但到期高于执行价 | 存续期内曾跌至$68\%\cdot S_0$，到期$S_T=90\%\cdot S_0$ | 0 |
| 曾敲入且到期低于执行价 | 存续期内曾跌至$68\%\cdot S_0$，到期$S_T=65\%\cdot S_0$ | $N\cdot (65\%-85\%) = -200$万元 |

#### 9.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 通过下调执行价减轻投资者部分尾部损失，并相应调整票息、保证金或其他报价要素 | 敲出前的票息责任与经典雪球相近；未敲出且敲入后，需承担标的下跌风险的对冲成本 |
| 期权持有方 | 看好标的不会深跌，并希望在经典雪球的基础上获得更低的到期损失起点 | 执行价低于期初价格，曾敲入但到期价格介于$K$与$S_0$之间时不产生损失；若到期跌破$K$，才按低于$K$的部分承担损失 |

#### 9.2.5 总结

OTM型雪球与经典雪球的主要区别是执行价$K$低于期初价格$S_0$。敲入后若未敲出，投资者并非从期初价格开始承担下跌，而是只有到期价格跌破$K$才产生损失，因此相对经典雪球多了一段下跌保护。

这部分保护通常以较低票息、较高保证金要求或其他报价条件为代价。它仍是路径依赖结构：敲出即提前结束并按持有期支付票息；未敲出且发生敲入时，最终是否亏损取决于到期价格是否低于执行价。

| 期权持有方 | 除获取固定票息外，也希望在标的上涨幅度较大时参与部分上涨收益 | 敲出时，敲出价格越高于敲出线，增强收益越高；未敲出且未敲入时获得固定票息；敲入后未敲出时仍承担到期下跌损失 |

| 到期结算 | 未敲出时返还本金，并按合同支付未敲出到期票息 |

#### 9.17.2 损益结构

| 情形 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日，使$S_t\ge H_{out}$ | $N\cdot y_{out}\cdot\frac{\text{实际持有天数}}{365}$，产品提前终止 |
| 未敲出 | 全部敲出观察日$S_t<H_{out}$ | $N\cdot y_{maturity}\cdot\frac{\text{总期限天数}}{365}$ |

#### 9.17.3 示例

设标的为中证1000，名义本金$N = 1$亿元，期限12个月，初始保证金比例$g = 100\%$。产品一的敲出线$H_{out} = 100\%\cdot S_0$，敲出票息$y_{out} = 4.8\%$，未敲出到期票息$y_{maturity} = 0.55\%$；产品二的敲出线$H_{out} = 103\%\cdot S_0$，敲出票息$y_{out} = 6.5\%$，未敲出到期票息$y_{maturity} = 0.55\%$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 产品一提前敲出 | 第60天观察日$S_t\ge100\%\cdot S_0$ | $1\text{亿元}\cdot4.8\%\cdot\frac{60}{365}=78.9\text{万元}$ |
| 产品二提前敲出 | 第120天观察日$S_t\ge103\%\cdot S_0$ | $1\text{亿元}\cdot6.5\%\cdot\frac{120}{365}=213.7\text{万元}$ |
| 未敲出 | 全部观察日均低于对应敲出线 | $1\text{亿元}\cdot0.55\%=55\text{万元}$ |

#### 9.17.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 通过设置敲出线和两档票息，取得标的上涨时提前终止收益的选择权 | 标的未达到敲出线时，需要支付较低的到期票息并维持产品至到期；标的较早上涨至敲出线时，产品提前结束 |
| 期权持有方 | 以全额资金换取有条件的固定收益，不愿承担敲入后的标的下跌损失或追加保证金压力 | 敲出时按较高的敲出票息结算；未敲出时收益降为较低的到期票息，但不因标的下跌承担本金损失 |

#### 9.17.5 总结

全保证金型小雪球不设置敲入，因此没有经典雪球在敲入后、未敲出时承担标的下跌损失的情形。代价是初始保证金占用为名义本金的100%，且未敲出时的到期票息通常较低。

它的核心判断只有两种：标的在观察日达到敲出线则提前按敲出票息结算；否则持有到期并取得较低的到期票息。敲出线越高，通常敲出票息越高，但未敲出概率也越大。

### 9.18 Worst-Of雪球

#### 9.18.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入多标的$Worst$-Of雪球产品，发行方卖出该结构 |
| 标的资产 | 两个或多个指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为12个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例为30% |
| 初始价格 | 每个标的的期初价格分别记为$S_{1,0}$、$S_{2,0}$、…、$S_{n,0}$ |
| 相对价格 | 第$i$个标的在$t$时刻的相对价格为$R_{i,t} = S_{i,t}/S_{i,0}$ |
| 多资产表现/最差表现 | $P_t = \min(R_{1,t},R_{2,t},\ldots,R_{n,t})$，即所有标的里表现最差的那个 |
| 约定票息/年化收益率 | $y$，示例取年化22.5% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出方向 | 向上敲出 |
| 敲出观察对象 | 每个敲出观察节点看$P_t$ |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出线 | $H_{out}$，示例取103% |
| 敲出触发条件 | 任一敲出观察日$P_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，投资者拿到截至敲出日的约定票息 |
| 敲出票息 | 票息通常按$N\cdot y\cdot\frac{\text{实际持有天数}}{365}$计算 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入方向 | 向下敲入 |
| 敲入观察对象 | 每个敲入观察节点看$P_t$ |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}$，示例取70% |
| 敲入触发条件 | 任一敲入观察日$P_t\le H_{in}$ |
| 敲入结果 | 不会终止产品，但会改变到期结算；若到期$P_T<100\%$，投资者承担最差标的跌幅损失$N\cdot (1-P_T)$ |
| 敲入后修复 | 若到期$P_T\ge 100\%$，通常本金不亏；是否仍支付票息以合同条款为准 |

#### 9.18.2 损益结构

| 情形 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日，使该日$P_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$，产品提前终止 |
| 未敲出、未敲入 | 全部敲出观察日$P_t<H_{out}$，且全部敲入观察节点$P_t>H_{in}$ | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入、到期修复 | 全部敲出观察日$P_t<H_{out}$，曾有$P_t\le H_{in}$，且$P_T\ge 100\%$ | 通常为0；若合同约定修复给息，则按合同给付 |
| 未敲出、曾敲入、到期未修复 | 全部敲出观察日$P_t<H_{out}$，曾有$P_t\le H_{in}$，且$P_T<100\%$ | $N\cdot (P_T-100\%)$，为负值；等价于损失$N\cdot (1-P_T)$ |

#### 9.18.3 示例

设标的为两个相关性较高的个股，名义本金$N = 1000$万元，初始保证金比例$g = 30\%$，初始保证金为300万元，期限12个月，约定票息$y = 22.5\%$，敲出线$H_{out} = 103\%$，敲入线$H_{in} = 70\%$，到期时以两个标的中表现较差者结算。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 第4个月观察日，两个标的分别为105%和104%，$P_t = 104\%\ge 103\%$ | $N\cdot 22.5\%\cdot 4/12 = 75$万元 |
| 未敲出且未敲入 | 全程$P_t$从未低于70%，且未在观察日达到103% | $N\cdot 22.5\% = 225$万元 |
| 曾敲入但到期修复 | 存续期内$P_t$曾跌至68%，到期$P_T$回到101% | 通常为0或约定票息，以合同为准 |
| 曾敲入且到期未修复 | 存续期内$P_t$曾跌至68%，到期$P_T$为80% | $N\cdot (80\%-100\%) = -200$万元 |

#### 9.18.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 收取投资者承担下行风险的补偿，并在多标的相关性、波动率和路径分布中管理风险 | 发行方收益与投资者相反，主要风险来自最差标的大幅下跌及相关性变化 |
| 期权持有方 | 判断一篮子标的整体不会大幅下跌，且至少不会出现某一标的显著拖累组合；希望用承担下行尾部风险换取较高票息 | 最有利情形是较早敲出并获得按持有期计算的票息；次优情形是未敲出且未敲入，持有至到期获得票息；不利情形是曾敲入且到期最差标的未修复，投资者承担最差标的跌幅 |

#### 9.18.5 总结

Worst-Of雪球挂钩两个或两个以上基础资产，所有收益、敲出和敲入判断均由表现最差的标的决定。向上敲出时，只有最差标的也达到敲出线，产品才会提前结束，因此挂钩标的越多，敲出条件越苛刻；向下敲入时，只要一只标的跌至敲入线即可触发，因此单一标的大幅下跌就会影响整笔产品。较高票息正是对这部分更严格敲出条件和更集中下行风险的补偿。

损益按路径判断：先看是否敲出，敲出后产品提前终止，投资者取得截至敲出日的约定票息；未敲出时再看是否曾敲入，未敲入则持有至到期取得约定票息；曾敲入后，若到期最差标的回到期初价格或以上，通常不发生本金损失，票息是否支付以合同为准；若到期仍低于期初价格，则按最差标的的跌幅承担损失。

因此，该结构适合预期各标的走势稳定、相关性较高且不会出现单一标的明显跑输的情形。即使多数标的表现良好，只要一只标的成为明显弱者，仍可能导致敲入并决定最终损失。

### 10.1 Worst-Of香草看涨期权

#### 10.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入Worst-Of香草看涨期权，收益由两个或多个标的中表现最差者决定 |
| 标的资产 | 两个或多个指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻T，示例取1个月 |
| 名义本金 | N，示例1000万元 |
| 初始价格 | 各标的期初价格分别记为S1,0、S2,0、…、Sn,0 |
| 相对价格 | 第i个标的在t时刻的相对价格Ri,t = Si,t / Si,0 |
| 多资产表现 | P = min(R1,R2,…,Rn)，即到期时所有标的里表现最差者 |
| 执行价 | K，示例K = 100% |
| 期权费率 | 示例取1.59%，明显低于任一单标的普通看涨期权的期权费率 |
| 到期收益 | 名义本金 × Max(P−K, 0) |
| 行权方式 | 欧式，仅在到期时刻T按P结算 |

#### 10.1.2 损益结构

净收益率 = Max(P−K, 0) − 期权费率。P取所有标的里表现最差者，只要有一个标的涨幅落后，收益即被拖累；只有全部标的都上涨、且表现最差的一个涨幅也超过K时，才产生正的行权价值。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| P > K | P − K − 期权费率 |
| P ≤ K | −期权费率 |

#### 10.1.3 示例

示例取两个标的，K = 100%，期权费率1.59%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 到期不行权 | 标的1收95%，标的2收97%，最差表现P = 95%（P ≤ K） | −1.59% |
| 到期不行权 | 标的1收102%，标的2收100%，最差表现P = 100%（P ≤ K） | −1.59% |
| 到期小幅行权，仍亏损 | 标的1收101%，标的2收105%，最差表现P = 101% | −0.59% |
| 恰好盈亏平衡 | 标的1收105%，标的2收101.59%，最差表现P = 101.59% | 0% |
| 到期获利 | 标的1收120%，标的2收105%，最差表现P = 105% | +3.41% |
| 到期获利 | 标的1收110%，标的2收125%，最差表现P = 110% | +8.41% |

多头只有在两个标的都上涨、且表现较差的一个涨幅也超过期权费率时才净盈利；只要有一个标的滞涨或下跌，都会拖累最终收益。

#### 10.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断多个标的中至少有一个难以持续上涨或将跑输，愿以较低期权费率换取“只需一个标的走弱即可获利”的优势 | 只要最差标的到期涨幅不超过K，保留全部期权费；若全部标的都大涨，按最差者的涨幅赔付，赔付幅度小于分别对每个标的卖出看涨的总和 |
| 期权持有方 | 同时看好多个标的但更看重成本控制，接受收益由表现最差者决定；相较于分别买入各标的的看涨期权，Worst-Of结构期权费率明显更低 | 到期收益取决于表现最差的标的，只要最差标的涨幅超过期权费率即可盈利；只要有一个标的滞涨或下跌，都会拖累整体收益，最大亏损为期权费率 |

#### 10.1.5 总结

Worst-Of香草看涨期权由多个标的的相对表现和取最小值的规则构成：到期先算出每个标的的涨跌幅，再取其中最差者作为结算依据，最后按行权价比较是否产生收益。挂钩标的越多、相关性越低，最差表现越容易被单个弱势标的拖累，期权费率也因此明显低于分别持有各标的看涨期权的费率之和，即以“收益由最弱标的决定”换取更低成本。适合看好一篮子标的整体方向、希望以更低成本参与，并能接受收益被最弱标的拖累的情形。

### 10.2 折价看涨8080（保证金）

#### 10.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入折价看涨8080（保证金），以保证金占用资金，让渡部分上涨收益换取零期权费 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻T，示例1个月 |
| 名义本金 | N，示例1000万元 |
| 保证金 | 名义本金 × 保证金比例，示例保证金比例20% |
| 期权费 | 示例0%，以保证金替代期权费 |
| 执行价格一（保底价） | K1，示例K1 = 80%·S0 |
| 执行价格二 | K2，示例K2 = 100%·S0（即S0） |
| 上涨参与率 | α，示例80% |
| 行权方式 | 欧式，到期时刻T按ST结算 |

#### 10.2.2 损益结构

记R = ST/S0 − 1为标的涨跌幅。净收益率：到期价格高于执行价格二时按涨幅乘参与率参与上涨；到期价格落在保底价与执行价格二之间时按标的实际跌幅承担损失；到期价格不高于保底价时损失封顶，不再随标的进一步下跌扩大。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| ST > K2 | R × α |
| K1 < ST ≤ K2 | R（为负值或零） |
| ST ≤ K1 | −(S0 − K1)/S0，示例为−20% |

#### 10.2.3 示例

示例取S0 = 100、K1 = 80、K2 = 100、α = 80%，名义本金1000万元。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 到期上涨 | ST = 110%·S0（涨幅+10%） | 1000×10%×80% = 80万元 |
| 到期下跌但未破保底价 | ST = 90%·S0（跌幅−10%） | 1000×(−10%) = −100万元 |
| 到期跌破保底价 | ST = 65%·S0 | 1000×(−20%) = −200万元 |

#### 10.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的上涨有限或将跌破保底价，愿以保证金占用换取零期权费的结构，承担未跌破保底价前的下跌及上涨参与赔付 | 标的跌破保底价后只需按封顶亏损赔付，不再随跌幅扩大；标的在保底价与执行价格二之间时按标的实际跌幅赔付；标的涨过执行价格二后按参与率赔付涨幅 |
| 期权持有方 | 看涨标的但愿意让渡部分上涨收益换取零期权费，同时接受下跌时的最大亏损被封顶 | 涨过执行价格二后按参与率分享涨幅；标的落在保底价与执行价格二之间时按实际跌幅承担损失；跌破保底价后损失封顶，不再随标的进一步下跌扩大 |

#### 10.2.5 总结

折价看涨8080（保证金）以保证金占用资金、期权费为零，用两个执行价格把持有标的的损益曲线改造成“下跌有限、上涨打折”的形态：先看到期价格是否高于执行价格二，高于则按参与率分享涨幅；否则再看是否跌破保底价（执行价格一），跌破前按标的实际跌幅承担损失，跌破后亏损封顶、不再随标的下跌扩大。相较于直接持有标的，占用资金更少且锁定了最大亏损，代价是放弃部分上涨收益。

### 10.3 折价看涨8080（期权费）

#### 10.3.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入折价看涨8080（期权费），期初支付期权费，让渡部分上涨收益 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻T，示例1个月 |
| 名义本金 | N，示例1000万元 |
| 期权费 | 示例20%，期初支付 |
| 执行价格一（保底价） | K1，示例K1 = 80%·S0 |
| 执行价格二 | K2，示例K2 = 100%·S0（即S0） |
| 上涨参与率 | α，示例80% |
| 行权方式 | 欧式，到期时刻T按ST结算 |

#### 10.3.2 损益结构

记R = ST/S0 − 1为标的涨跌幅。损益形态与折价看涨8080（保证金）一致，区别在于成本形式：本结构期初一次性支付期权费，而非以保证金占用资金。

#### 10.3.3 示例

示例取S0 = 100、K1 = 80、K2 = 100、α = 80%、期权费20%，名义本金1000万元。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 到期上涨 | ST = 110%·S0（涨幅+10%） | 1000×10%×80% = 80万元 |
| 到期下跌但未破保底价 | ST = 90%·S0（跌幅−10%） | 1000×(−10%) = −100万元 |
| 到期跌破保底价 | ST = 65%·S0 | 1000×(−20%) = −200万元 |

#### 10.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 收取期初期权费，判断标的上涨有限或将跌破保底价，承担未跌破保底价前的下跌及上涨参与赔付 | 标的跌破保底价后只需按封顶亏损赔付，不再随跌幅扩大；标的在保底价与执行价格二之间时按标的实际跌幅赔付；标的涨过执行价格二后按参与率赔付涨幅 |
| 期权持有方 | 看涨标的但愿意让渡部分上涨收益、以期初一次性期权费换取20%下跌保护 | 涨过执行价格二后按参与率分享涨幅；标的落在保底价与执行价格二之间时按实际跌幅承担损失；跌破保底价后损失封顶于已支付的期权费，不再随标的进一步下跌扩大 |

#### 10.3.5 总结

折价看涨8080（期权费）与保证金版本共用同一套两档执行价格和参与率安排，损益曲线完全一致，唯一区别是成本形式：本结构期初即支付期权费作为沉没成本，保证金版本则以保证金占用资金、期权费为零，具体占用或返还方式以合同条款为准。两者都以放弃部分上涨收益换取“下跌亏损封顶”的结构，适合看涨但希望锁定最大亏损、并接受成本以期权费形式先行支付的情形。

### 10.4 方差互换

#### 10.4.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入方差互换（多头做多波动），到期按已实现方差与执行方差之差结算 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，按存续期内日收益计算已实现波动率 σ |
| 执行波动率 | 执行波动率 K，示例取 K = 13（波动率点），执行方差 K² = 169 |
| 方差名义本金 | 每 1 个方差点对应的金额，示例取 2500 |
| Vega 名义 | 方差名义 × 2K，示例 2500 × 26 = 65000 |
| 结算变量 | 已实现年化波动率 σ 及其平方 σ²（已实现方差） |
| 收益时点 | 到期时刻 T 按 σ² 结算 |

#### 10.4.2 损益结构

多头到期损益 = 方差名义本金 ×(σ² − K²)。结算只看已实现波动率的平方与执行方差之差，与标的涨还是跌无关，是纯粹的波动率敞口。已实现波动率高于执行水平时多头获利、且因平方项而随波动加速放大；等于执行水平时损益为零；低于执行水平时多头亏损。多头做多波动，空头（发行方）做空波动、赚取波动率风险溢价。多头最大亏损在 σ = 0 时为 方差名义 × K²，理论最大盈利随波动率无上限。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| σ² > K²（已实现波动率高于执行） | 方差名义 ×(σ² − K²)，为正 |
| σ² = K²（已实现波动率等于执行） | 0 |
| σ² < K²（已实现波动率低于执行） | 方差名义 ×(σ² − K²)，为负 |

#### 10.4.3 示例

示例取执行 K = 13、K² = 169、方差名义 2500。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 已实现波动率低于执行 | 到期已实现波动率σ = 10（σ² = 100） | −17.25万元 | +17.25万元 |
| 已实现波动率等于执行 | 到期已实现波动率σ = 13（σ² = 169），恰好等于执行 | 0 | 0 |
| 已实现波动率略高于执行 | 到期已实现波动率σ = 15（σ² = 225） | +14万元 | −14万元 |
| 已实现波动率明显高于执行 | 到期已实现波动率σ = 20（σ² = 400） | +57.75万元 | −57.75万元 |

多头在已实现波动率超过执行水平后盈利，且因方差是波动率的平方，波动越大盈利加速放大；空头相反，只要波动率不超过执行水平就赚取风险溢价，一旦市场剧烈波动则亏损迅速扩大。

#### 10.4.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的未来已实现波动率将高于执行水平，或为持仓对冲波动风险；只做多波动、不含方向敞口 | 已实现波动率高于执行才盈利，且随波动率平方加速放大；低于执行则亏损，最大亏损在波动率归零时为 方差名义 × K² |
| 空头 | 发行方，判断已实现波动率将低于执行水平；收取波动率风险溢价，承担波动放大时的赔付 | 已实现波动率低于执行时获利，最大盈利即执行方差对应的金额；高于执行后亏损随波动加速扩大 |

#### 10.4.5 总结

方差互换以已实现方差与执行方差之差直接结算，收益与标的涨跌方向无关，是纯粹押注已实现波动率相对执行水平高低的结构，且因结算变量是波动率的平方，波动越大盈亏越加速放大。判断顺序只需比较到期已实现波动率与执行波动率：高于执行则多头盈利，低于执行则多头亏损。它适合直接对波动率而非价格方向进行判断或对冲的情形；卖方在波动率维持温和时能持续获得风险溢价，一旦市场剧烈波动则亏损可能迅速扩大。

### 10.5 看涨鲨鱼鳍（UOC）

#### 10.5.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入看涨鲨鱼鳍（UOC），以放弃敲出价以上部分收益换取更低期权费率 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻T，示例6个月 |
| 名义本金 | N，示例1000万元 |
| 行权价 | K，示例K = 100%·S0 |
| 敲出观察日 | 每日观察St是否触及敲出价格 |
| 敲出价格（敲出障碍） | H，示例H = 110%·S0 |
| 敲出补偿 | 示例5%，敲出后按固定补偿了结，不再随涨幅继续增加 |
| 期权费率 | 示例2.6% |
| 行权方式 | 未敲出时到期按ST结算；敲出后提前终止并按敲出补偿结算 |

#### 10.5.2 损益结构

净收益率 = 敲出时为敲出补偿，未敲出且ST > K时为(ST−K)/S0，未敲出且ST ≤ K时为0，均需再扣除期权费率。未敲出时的收益随涨幅累积，一旦存续期内触及敲出价格，产品提前按固定补偿了结，即便当时涨幅已超过敲出补偿也不再增加。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 存续期内触及H，敲出 | 敲出补偿 − 期权费率 |
| 未敲出且ST > K | (ST−K)/S0 − 期权费率 |
| 未敲出且ST ≤ K | −期权费率 |

#### 10.5.3 示例

示例取S0 = 100、K = 100、H = 110、敲出补偿5%、期权费率2.6%，名义本金1000万元。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 有敲出 | 存续期内收盘价触及110 | 1000×(5%−2.6%) = 24万元 |
| 未敲出，到期高于行权价 | 全程未触及110，ST = 108 | 1000×(8%−2.6%) = 54万元 |
| 未敲出，到期不高于行权价 | 全程未触及110，ST = 95 | 1000×(−2.6%) = −26万元 |

#### 10.5.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的将触及敲出价格或涨幅有限；收取期权费率，承担未敲出且标的上涨时的赔付 | 触及敲出价格后只需按固定补偿赔付；未敲出且标的下跌或持平时保留期权费；未敲出且上涨时按涨幅赔付 |
| 期权持有方 | 温和看涨，判断标的上涨但可能触及敲出价格；愿放弃敲出价格以上的收益，换取比普通看涨更低的期权费率 | 未敲出时收益随涨幅累积，最高接近敲出价格与行权价之差；一旦触及敲出价格，产品提前按敲出补偿了结，不再随涨幅继续增加；未敲出且不涨则只亏期权费率 |

#### 10.5.5 总结

看涨鲨鱼鳍（UOC）在普通看涨期权上叠加向上敲出障碍：先看存续期内是否触及敲出价格，未触及时收益随涨幅累积，最高接近敲出价格与行权价之差；一旦触及敲出价格，产品提前按固定的敲出补偿了结，不再随涨幅继续增加。这一障碍换来了明显低于普通看涨期权的期权费率，适合看涨但预期涨幅可能触顶、或愿意用涨幅上限换取更低成本的情形。

### 10.7 双边鲨鱼鳍

#### 10.7.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入双边鲨鱼鳍，设有高低两个障碍价格，同时放弃上端和下端部分收益换取更低期权费率 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻T，示例2个月 |
| 名义本金 | N，示例1000万元 |
| 敲出观察日 | 存续期内每个交易日（日频观察） |
| 期权费率 | 示例0.88% |
| 高敲出价格 | Hu，示例Hu = 115%·S0；任一敲出观察日ST ≥ Hu即向上敲出 |
| 高执行价格 | Ku，示例Ku = 105%·S0 |
| 高敲出补偿 | 示例3% |
| 高参与率 | 示例50%，用于未敲出且到期价格不低于Ku时的上行参与 |
| 低敲出价格 | Hd，示例Hd = 85%·S0；任一敲出观察日ST ≤ Hd即向下敲出 |
| 低执行价格 | Kd，示例Kd = 95%·S0 |
| 低敲出补偿 | 示例4% |
| 低参与率 | 示例80%，用于未敲出且到期价格不高于Kd时的下行参与 |

#### 10.7.2 损益结构

净收益率按向上敲出、向下敲出、未敲出三种情形分别确定，均需再扣除期权费率：向上敲出按高敲出补偿了结；向下敲出按低敲出补偿了结；未敲出且到期价格不低于高执行价格时，按超出部分乘高参与率参与上行；未敲出且到期价格不高于低执行价格时，按低于部分乘低参与率参与下行；未敲出且到期价格落在两个执行价格之间时不产生行权收益。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 向上有敲出（存续期内触及Hu） | 高敲出补偿 − 期权费率 |
| 向下有敲出（存续期内触及Hd） | 低敲出补偿 − 期权费率 |
| 未敲出且ST ≥ Ku | (ST−Ku)/S0 × 高参与率 − 期权费率 |
| 未敲出且ST ≤ Kd | (Kd−ST)/S0 × 低参与率 − 期权费率 |
| 未敲出且Kd < ST < Ku | −期权费率 |

#### 10.7.3 示例

示例取S0 = 100、Hu = 115、Ku = 105、高敲出补偿3%、高参与率50%、Hd = 85、Kd = 95、低敲出补偿4%、低参与率80%、期权费率0.88%，名义本金1000万元。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 向上有敲出 | 存续期内收盘价触及115 | 1000×(3%−0.88%) = 21.2万元 |
| 向下有敲出 | 存续期内收盘价触及85 | 1000×(4%−0.88%) = 31.2万元 |
| 未敲出，到期高于高执行价 | 全程未触及敲出价格，ST = 110 | 1000×[(110%−105%)×50%−0.88%] = 16.2万元 |
| 未敲出，到期低于低执行价 | 全程未触及敲出价格，ST = 90 | 1000×[(95%−90%)×80%−0.88%] = 31.2万元 |
| 未敲出，到期落在两执行价之间 | 全程未触及敲出价格，ST = 100 | 1000×(−0.88%) = −8.8万元 |

#### 10.7.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的将维持窄幅震荡、大概率停留在两个执行价格之间；收取期权费率，承担触及任一端敲出价格或到期突破执行价格时的赔付 | 标的停留在两个执行价格之间时保留期权费率即最大盈利；触及任一端敲出价格后按对应固定补偿赔付；未敲出且突破执行价格时按参与率赔付 |
| 期权持有方 | 无需判断标的运动方向，只要标的最终触及任一端敲出价格或到期收于执行价格之外即可获得收益，接受落在两个执行价格之间时只损失期权费率 | 触及任一端敲出价格后按对应固定补偿了结；未敲出且到期突破执行价格时按参与率分享该方向的涨跌；落在两个执行价格之间时只亏期权费率 |

#### 10.7.5 总结

双边鲨鱼鳍在向上和向下同时设置敲出价格与执行价格：先看存续期内是否触及任一端敲出价格，触及后即按对应固定补偿了结；未触及时再看到期价格是否突破执行价格，突破哪一侧就按对应参与率分享该方向的涨跌，落在两个执行价格之间则只损失期权费率。相较于单边鲨鱼鳍，双边结构无需判断方向、覆盖了两个方向的机会，但每个方向的参与率和补偿也相应更保守，通常对应更低的期权费率。

### 10.8 区间计息（Range Accrual）

#### 10.8.1 要素

| 要素 | 取值 |

| 满额票息 | 全程每个观察日均在区间内时的最高收益率，示例取 1.45% |
| 单日累计 | 每个落在区间内的观察日累计 满额票息 / N |
| 期权费 | 期初支付，示例取 1.21% |
| 收益时点 | 到期时刻 T 按累计结果结算 |

#### 10.8.2 损益结构

记 P 为 N 个观察日中落在区间内的天数，满额票息记为 R_max。到期票息率 = R_max × P / N，净收益率 = R_max × P / N − 期权费。标的每在区间内停留一天就累计 R_max / N 的票息，落在区间外的天不计息。全程在区间内得满额 R_max、净赚 R_max − 期权费；全程在区间外得零票息、净亏期权费。因“停留在窄区间”才最有利，该结构做空波动率，标的越平稳越好。最大盈利 R_max − 期权费，最大亏损为期权费。

| 情形或判断条件 | 持有方净损益 |
| --- | --- |
| 全程在区间内（P = N） | R_max − 期权费 |
| 部分在区间内 | R_max × P / N − 期权费 |
| 全程在区间外（P = 0） | −期权费 |

#### 10.8.3 示例

示例取满额票息 R_max = 1.45%、N = 22、期权费 1.21%。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 全程在区间内 | 22个观察日中P = 22天收盘价落在区间内 | +0.24% | −0.24% |
| 部分在区间内 | 22个观察日中P = 11天落在区间内 | −0.485% | +0.485% |
| 全程在区间外 | 22个观察日中P = 0天落在区间内 | −1.21% | +1.21% |

多头在标的窄幅震荡、长期停留区间内时收益最佳；标的大幅波动、频繁走出区间时票息不足以覆盖期权费而亏损。

#### 10.8.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的在存续期内窄幅震荡、大部分时间停留在区间内；做空波动率，波动越小、停留越久越有利 | 停留在区间内的天数越多票息越高，全程在内净赚 R_max 减期权费；停留越少票息越低，全程在外只亏期权费 |
| 空头 | 发行方，判断标的会频繁走出区间；收取期权费，承担标的长期停留区间内时的票息赔付 | 标的常在区间外时保留期权费；标的长期停留区间内则按累计票息赔付 |

#### 10.8.5 总结

区间计息本质是逐日区间二元观察的加总：每个观察日先判断标的收盘价是否落在约定区间内，落在区间内的天数累计一份满额票息，落在区间外的天不计息，到期按累计天数占比结算票息并扣除期权费，属于做空波动率的路径依赖结构。区间越窄、观察频率越高，对标的稳定性的要求也越高。适合判断标的将维持窄幅震荡的情形；一旦标的持续走出区间，票息将不足以覆盖期权费，产生亏损。
