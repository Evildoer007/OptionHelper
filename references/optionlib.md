# 期权结构库OptionLib

## 1 通用说明

### 1.1 记号

| 符号 | 含义 |
| --- | --- |
| $S_0$ | 单一标的期初价格 |
| $S_t$ | 单一标的在存续期内$t$时刻的价格，其中$0\le t\le T$ |
| $S_T$ | 单一标的到期价格 |
| $t$、$T$ | 存续期内任一观察时刻和到期时刻 |
| $K$ | 行权价；多个行权价按大小记为$K_1<K_2<K_3<K_4$ |
| $N$ | 名义本金 |
| $g$ | 初始保证金比例 |
| $G$ | 初始保证金，$G = N\cdot g$ |

同一结构内$t$仅表示存续期内的观察时刻，$T$仅表示到期时刻。仅在个别结构中使用的符号，在对应结构内首次出现时定义。

### 1.2 损益口径

多头为买方或产品持有方，空头为卖方或发行方，买卖双方构成零和，空头损益与多头损益大小相等、方向相反，故每种结构以多头列示，空头反向。普通期权损益按每份标的计，并已扣除期权费；期权费是取得期权权利或承担期权义务所支付、收取的价格。保证金是履约担保资金，不等于期权费，除非特别说明不计入损益。结构化产品按名义本金折算收益率。有单一盈亏平衡价的结构，盈亏平衡指多头净损益等于零时的到期价格；路径依赖结构未必有单一盈亏平衡价。

损益结构表中，“情景”列仅写简明文字描述，例如“未敲出且到期实值”“向上敲出”“全程在区间内”，不得写公式、变量符号、不等式或具体阈值。“判断条件”列写完整的到期条件或路径条件，可使用公式、变量、不等式和障碍价格；“持有方净损益”列写相应损益公式或结果。

### 1.3 行权与结算

欧式在到期时刻$T$依据$S_T$结算，美式在存续期内任一时刻$t$依据$S_t$行权结算，障碍类按约定观察时点检查$S_t$是否触及障碍并在触及时提前结算；除特别说明外均为欧式。

## 2 方向性期权

### 2.1 看涨期权

#### 2.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 多头买入1份看涨期权 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例取$K = S_0 = 100$ |
| 期权费 | $c$，多头即买方在期初支付，空头即卖方在期初收取，示例$c = 5$ |
| 行权方式 | 欧式，仅在到期时刻$T$行权；若为美式，则存续期内任一时刻$t$均可行权 |

#### 2.1.2 损益结构

多头净损益 = $\max(S_T-K,0)-c$，其中$\max(S_T-K,0)$ 为到期时刻的行权价值，$c$为期初支付的期权费；空头损益与之大小相等、方向相反。盈亏平衡为到期价格$S_T = K+c$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期不高于行权价 | $S_T\le K$ | $-c$ |
| 到期高于行权价 | $S_T>K$ | $S_T-K-c$ |

#### 2.1.3 示例

$S_0 = 100$、$K = 100$、$c = 5$，盈亏平衡在$S_T = K+c = 105$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T<K$，不行权 |$-5$ |$+5$ |
| $100$ | $S_T = K$，不行权 |$-5$ |$+5$ |
| $105$ | 行权，恰好损益为零 | $0$ | $0$ |
| $110$ | 行权 |$+5$ |$-5$ |
| $120$ | 行权 |$+15$ |$-15$ |

多头在$S_T$超过105后开始盈利，标的每上涨一元收益增加一元；空头在$S_T$不超过105时盈利，最大盈利为期权费5，超过105后亏损随涨幅扩大且没有上限。

#### 2.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看空到中性，判断标的不会明显上涨、大概率横盘或小幅下跌；同时做空波动率，预期隐含波动率偏高且回落，靠时间价值获利 | $S_T$不高于$K$时保留全部期权费$c$即最大盈利；高于$K$后按$S_T-K$赔付、亏损随涨幅扩大且没有上限，盈亏平衡在$K+c$。常在持有标的的同时卖出看涨即备兑，以让渡上行空间换取期权费收入 |
| 期权持有方 | 看涨，判断标的在存续期内上涨且到期涨幅超过期权费；同时做多波动率，标的越涨、波动越大越有利；隐含波动率处于较低分位、期权价格较低时买入成本更低 | $S_T$高于$K+c$才盈利，之后标的每上涨一元收益增加一元、没有上限；$S_T$落在$K$与$K+c$之间时仍亏损，但亏损小于期权费$c$；$S_T$不高于$K$时亏损全部期权费$c$，即最大亏损。相比直接买入标的，占用资金少、下行风险封顶 |

#### 2.1.5 总结

看涨期权以固定期权费换取标的上涨的全部收益，适合明确看涨且希望把最大亏损锁定在期权费内的情形。到期价格只有超过行权价加期权费才产生净利润；上涨越多，收益越高。卖方的期权费收入有限，但需要承担标的大幅上涨的风险。

### 2.2 看跌期权

#### 2.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 多头买入1份看跌期权 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例取$K = S_0 = 100$ |
| 期权费 | $p$，多头即买方在期初支付，空头即卖方在期初收取，示例$p = 5$ |
| 行权方式 | 欧式，仅在到期时刻$T$行权；若为美式，则存续期内任一时刻$t$均可行权 |

#### 2.2.2 损益结构

多头净损益 = $\max(K-S_T,0)-p$，其中$\max(K-S_T,0)$ 为到期时刻的行权价值，$p$为期初支付的期权费；空头损益与之大小相等、方向相反。盈亏平衡为到期价格$S_T = K-p$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期不低于行权价 | $S_T\ge K$ | $-p$ |
| 到期低于行权价 | $S_T<K$ | $K-S_T-p$ |

#### 2.2.3 示例

$S_0 = 100$、$K = 100$、$p = 5$，盈亏平衡在$S_T = K-p = 95$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $110$ | $S_T>K$，不行权 |$-5$ |$+5$ |
| $100$ | $S_T = K$，不行权 |$-5$ |$+5$ |
| $95$ | 行权，恰好损益为零 | $0$ | $0$ |
| $90$ | 行权 |$+5$ |$-5$ |
| $80$ | 行权 |$+15$ |$-15$ |

多头在$S_T$跌破95后开始盈利，标的每下跌一元收益增加一元，最大收益在标的跌至零时为95；空头在$S_T$不低于95时盈利，最大盈利为期权费5，到期价格跌破95后被行权、须按$K$买入标的并承担扩大的亏损。

#### 2.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看多到中性，判断标的不会明显下跌、大概率横盘或小幅上涨；同时做空波动率，预期隐含波动率偏高且回落，并可接受在更低价位买入标的 | $S_T$不低于$K$时保留全部期权费$p$即最大盈利；到期价格低于$K$时被行权，须按行权价$K$买入标的，承担$K-S_T$的亏损，最大亏损$K-p$，盈亏平衡在$K-p$。相当于预收期权费，并承诺在到期价格低于$K$时按$K$买入标的，也是雪球等结构中投资者承担下行风险换取票息的基础形态 |
| 期权持有方 | 看跌，判断标的在存续期内下跌且到期跌幅超过期权费，或不判断方向只为持仓买保险；同时做多波动率，标的越跌、波动越大越有利；隐含波动率较低时保护成本便宜 | $S_T$低于$K-p$才盈利，标的价格越低收益越大，最大收益$K-p$即标的跌到零；$S_T$落在$K-p$与$K$之间时仍亏损，但亏损小于期权费$p$；$S_T$不低于$K$时亏损全部期权费$p$，即最大亏损。市场大幅下跌时隐含波动率往往显著上升、保护成本上升，宜在隐含波动率较低时提前买入 |

#### 2.2.5 总结

看跌期权以固定期权费获得标的下跌时的收益，可用于直接看跌，也可作为现货持仓的下行保护。到期价格低于行权价减期权费才盈利，标的下跌越多，保护效果越明显。卖方以收取期权费为代价，承担标的下跌时按行权价买入的风险。

## 3 垂直价差

用两个同类型、不同行权价的期权一买一卖构成，方向温和、收益封顶。设价差宽度$W = K_2-K_1$，净支出记$D$、净收入记$C$。四种价差按常用命名分别列示；其中牛市看涨与熊市看涨互为对手方、牛市看跌与熊市看跌互为对手方，同一对的两个损益反向。


### 3.1 牛市看涨价差

#### 3.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入$c(K_1)$、卖出$c(K_2)$，$K_1<K_2$，构成一个净支出组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 低行权价$K_1$、高行权价$K_2$，示例$K_1 = 95$、$K_2 = 105$ |
| 净支出 | $D = c(K_1)-c(K_2)$，期初净额支付，示例$D = 4$ |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 3.1.2 损益结构

多头净损益 = $\max(S_T-K_1,0)-\max(S_T-K_2,0)-D$。盈亏平衡为$S_T = K_1+D$；最大盈利$W-D$，在$S_T\ge K_2$取得；最大亏损$D$，在$S_T\le K_1$取得。对手方即熊市看涨价差，损益反向。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期不高于低行权价 | $S_T\le K_1$ | $-D$ |
| 到期介于两行权价之间 | $K_1<S_T<K_2$ | $S_T-K_1-D$ |
| 到期不低于高行权价 | $S_T\ge K_2$ | $W-D$ |

#### 3.1.3 示例

$K_1 = 95$、$K_2 = 105$、$D = 4$，$W = 10$，盈亏平衡在$S_T = K_1+D = 99$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T\le K_1$ |$-4$ |$+4$ |
| $99$ | $K_1$与$K_2$之间，恰好损益为零 | $0$ | $0$ |
| $105$ | $S_T\ge K_2$ |$+6$ |$-6$ |
| $110$ | $S_T\ge K_2$ |$+6$ |$-6$ |

多头在$S_T$超过99后盈利，涨到105及以上收益封顶于6；跌至95及以下亏损封顶于4。收益与亏损两端都被锁定。

#### 3.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看空到中性，即熊市看涨价差，判断标的难以上涨至$K_1$以上；期初收取净额，承担有限上行风险 | $S_T$不高于$K_1$时保留净收入即最大盈利；涨破$K_2$后亏损封顶为$W-D$；盈亏平衡在$K_1+D$ |
| 期权持有方 | 温和看涨，判断标的上涨但涨幅有限、难以超过$K_2$；卖出高行权价腿收回部分期权费以降低成本，代价是收益封顶 | $S_T$高于$K_1+D$才盈利，涨到$K_2$以上锁定最大盈利$W-D$；$S_T$落在$K_1$与$K_1+D$之间仍亏损但小于$D$；$S_T$不高于$K_1$时亏损全部净支出$D$ |

#### 3.1.5 总结

牛市看涨价差通过买入低行权价看涨、卖出高行权价看涨，把单边看涨改为有限收益、有限亏损的组合。卖出高行权价腿降低了期初成本，但也放弃了超过高行权价后的额外上涨收益。适合预期标的温和上涨而非大幅突破的情形。

### 3.2 牛市看跌价差

#### 3.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 卖出$p(K_2)$、买入$p(K_1)$，$K_1<K_2$，构成一个净收入组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 低行权价$K_1$、高行权价$K_2$，示例$K_1 = 95$、$K_2 = 105$ |
| 净收入 | $C = p(K_2)-p(K_1)$，期初净额收取，示例$C = 6$ |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 3.2.2 损益结构

多头净损益 = $C-\max(K_2-S_T,0)+\max(K_1-S_T,0)$。盈亏平衡为$S_T = K_2-C$；最大盈利$C$，在$S_T\ge K_2$取得；最大亏损$W-C$，在$S_T\le K_1$取得。与牛市看涨价差到期损益等价，区别在期初收取净额而非支付。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期不低于高行权价 | $S_T\ge K_2$ | $C$ |
| 到期介于两行权价之间 | $K_1<S_T<K_2$ | $C-(K_2-S_T)$ |
| 到期不高于低行权价 | $S_T\le K_1$ | $C-W$ |

#### 3.2.3 示例

$K_1 = 95$、$K_2 = 105$、$C = 6$，$W = 10$，盈亏平衡在$S_T = K_2-C = 99$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $110$ | $S_T\ge K_2$ |$+6$ |$-6$ |
| $99$ | $K_1$与$K_2$之间，恰好损益为零 | $0$ | $0$ |
| $95$ | $S_T\le K_1$ |$-4$ |$+4$ |
| $90$ | $S_T\le K_1$ |$-4$ |$+4$ |

多头在$S_T$不低于105时赚满净收入6，跌破99后转亏，跌至95及以下亏损封顶于4。

#### 3.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看空到中性，即熊市看跌价差，判断标的下跌但跌幅有限；期初支付净额，承担有限下行收益 | $S_T$跌破$K_2-C$才盈利，跌到$K_1$以下锁定最大盈利$W-C$；$S_T$不低于$K_2$时亏损全部净支出 |
| 期权持有方 | 温和看涨，判断标的不明显下跌、大概率守在$K_2$以上；希望期初即收取净额，并把下行亏损锁定 | $S_T$不低于$K_2$时保留净收入$C$即最大盈利；跌破$K_1$后亏损封顶为$W-C$；盈亏平衡在$K_2-C$ |

#### 3.2.5 总结

牛市看跌价差通过卖出高行权价看跌、买入低行权价看跌，期初先收取净额，并把下行风险限制在两个行权价之间。只要标的未明显下跌即可获利，收益上限是期初净收入；深度下跌时，保护腿使亏损封顶。适合温和看涨或判断标的能够守住关键价格的情形。

### 3.3 熊市看跌价差

#### 3.3.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入$p(K_2)$、卖出$p(K_1)$，$K_1<K_2$，构成一个净支出组合 |

| 期限 | 自期初持有至到期时刻$T$ |

多头在$S_T$跌破101后盈利，跌到95及以下收益封顶于6；涨至105及以上亏损封顶于4。

#### 3.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看多到中性，即牛市看跌价差，判断标的难以跌破$K_2$；期初收取净额，承担有限下行风险 | $S_T$不低于$K_2$时保留净收入即最大盈利；跌破$K_1$后亏损封顶为$W-D$；盈亏平衡在$K_2-D$ |
| 期权持有方 | 温和看跌，判断标的下跌但跌幅有限、难以跌破$K_1$；买入高行权价腿、卖出低行权价腿降低成本，收益封顶 | $S_T$低于$K_2-D$才盈利，跌到$K_1$以下锁定最大盈利$W-D$；$S_T$落在$K_2-D$与$K_2$之间仍亏损但小于$D$；$S_T$不低于$K_2$时亏损全部净支出$D$ |

#### 3.3.5 总结

熊市看跌价差通过买入高行权价看跌、卖出低行权价看跌，以有限期权费押注标的温和下跌。卖出低行权价腿降低成本，同时限制标的深跌后的额外收益。适合预期下跌幅度有限、希望明确最大亏损的情形。

### 3.4 熊市看涨价差

#### 3.4.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 卖出$c(K_1)$、买入$c(K_2)$，$K_1<K_2$，构成一个净收入组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 低行权价$K_1$、高行权价$K_2$，示例$K_1 = 95$、$K_2 = 105$ |
| 净收入 | $C = c(K_1)-c(K_2)$，期初净额收取，示例$C = 6$ |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 3.4.2 损益结构

多头净损益 = $C-\max(S_T-K_1,0)+\max(S_T-K_2,0)$。盈亏平衡为$S_T = K_1+C$；最大盈利$C$，在$S_T\le K_1$取得；最大亏损$W-C$，在$S_T\ge K_2$取得。与熊市看跌价差到期损益等价，区别在期初收取净额而非支付。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期不高于低行权价 | $S_T\le K_1$ | $C$ |
| 到期介于两行权价之间 | $K_1<S_T<K_2$ | $C-(S_T-K_1)$ |
| 到期不低于高行权价 | $S_T\ge K_2$ | $C-W$ |

#### 3.4.3 示例

$K_1 = 95$、$K_2 = 105$、$C = 6$，$W = 10$，盈亏平衡在$S_T = K_1+C = 101$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T\le K_1$ |$+6$ |$-6$ |
| $101$ | $K_1$与$K_2$之间，恰好损益为零 | $0$ | $0$ |
| $105$ | $S_T\ge K_2$ |$-4$ |$+4$ |
| $110$ | $S_T\ge K_2$ |$-4$ |$+4$ |

多头在$S_T$不高于95时赚满净收入6，涨破101后转亏，涨至105及以上亏损封顶于4。

#### 3.4.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 温和看多到中性，即牛市看涨价差，判断标的上涨但涨幅有限；期初支付净额，承担有限上行收益 | $S_T$高于$K_1+C$才盈利，涨到$K_2$以上锁定最大盈利$W-C$；$S_T$不高于$K_1$时亏损全部净支出 |
| 期权持有方 | 温和看跌，判断标的不明显上涨、大概率不超过$K_1$；希望期初即收取净额，并把上行亏损锁定 | $S_T$不高于$K_1$时保留净收入$C$即最大盈利；涨破$K_2$后亏损封顶为$W-C$；盈亏平衡在$K_1+C$ |

#### 3.4.5 总结

熊市看涨价差通过卖出低行权价看涨、买入高行权价看涨，期初收取净额，以有限风险换取标的不涨的收益。收益上限是净收入，标的大涨时由买入高行权价看涨限制亏损。适合温和看跌或判断标的难以突破上方压力位的情形。

## 4 波动率与区间

方向多为中性，核心是押波动率大小或到期落点。跨式与宽跨式的多头做多波动率，标的波动越大越有利；蝶式与鹰式的多头相反，做空波动率，押标的到期落在特定区间、波动越小越有利。各结构多头均期初净支出、空头净收入，以多头列示、空头反向。蝶式与鹰式的净支出记$D$、净收入记$C$。


### 4.1 跨式

#### 4.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入同一行权价$K$、同一到期的看涨与看跌各1份 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 成本 | $c+p$，期初支付，示例$c = p = 7$，合计14 |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 4.1.2 损益结构

多头净损益 = $|S_T-K|-(c+p)$。两个盈亏平衡为$S_T = K-(c+p)$ 与$S_T = K+(c+p)$；最大亏损$c+p$，在$S_T = K$取得。对本库的股票、指数和ETF等非负价格标的，上行收益无上限；下行收益在$S_T=0$时达到$K-(c+p)$。空头损益方向相反，其中上行风险无上限、下行风险有限。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期低于行权价 | $S_T<K$ | $K-S_T-(c+p)$ |
| 到期等于行权价 | $S_T = K$ | $-(c+p)$ |
| 到期高于行权价 | $S_T>K$ | $S_T-K-(c+p)$ |

#### 4.1.3 示例

$K = 100$、$c = p = 7$，成本14，盈亏平衡在$S_T = 86$与$S_T = 114$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $80$ | $S_T<K$ |$+6$ |$-6$ |
| $86$ | 下行盈亏平衡 | $0$ | $0$ |
| $100$ | $S_T = K$ |$-14$ |$+14$ |
| $114$ | 上行盈亏平衡 | $0$ | $0$ |
| $120$ | $S_T>K$ |$+6$ |$-6$ |

多头在$S_T$跌破86或涨过114后盈利，停在100附近亏损最大14；空头相反，标的越接近100越有利。

#### 4.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的窄幅震荡、无大行情，预期隐含波动率偏高且回落；做空波动率，靠时间价值获利 | $S_T$停在$K$附近赚满$c+p$即最大盈利；偏离$K$超过$c+p$后转亏。对非负价格标的，上行风险无上限，下行风险受$S_T=0$约束，仍须对冲 |
| 期权持有方 | 判断标的短期大幅波动但方向不明，如重大事件公布前；做多波动率，要求已实现波动显著超过隐含波动 | $S_T$偏离$K$超过$c+p$才盈利；上行收益无上限，下行收益最高为$K-(c+p)$；停在$K$附近亏损最大，为$c+p$ |

#### 4.1.5 总结

跨式同时买入看涨和看跌，买的是到期价格偏离行权价的幅度，而不是方向。两腿期权费构成最大亏损，只有上涨或下跌幅度超过总成本才盈利。适合预期将出现大幅波动、但无法判断方向的情形；卖方则承担双向大幅波动的风险。

### 4.2 宽跨式

#### 4.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入低行权价看跌$p(K_p)$ 与高行权价看涨$c(K_c)$，$K_p<K_c$ |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | 看跌行权价$K_p$、看涨行权价$K_c$，示例$K_p = 90$、$K_c = 110$ |
| 成本 | $c+p$，期初支付，示例合计8 |
| 行权方式 | 欧式，两腿均在到期时刻$T$行权 |

#### 4.2.2 损益结构

多头净损益 = $\max(K_p-S_T,0)+\max(S_T-K_c,0)-(c+p)$。两个盈亏平衡为$S_T = K_p-(c+p)$ 与$S_T = K_c+(c+p)$；最大亏损$c+p$，在$K_p\le S_T\le K_c$取得。对本库的非负价格标的，上行收益无上限；下行收益在$S_T=0$时达到$K_p-(c+p)$。空头损益反向。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期低于看跌行权价 | $S_T<K_p$ | $K_p-S_T-(c+p)$ |
| 到期落在两行权价之间 | $K_p\le S_T\le K_c$ | $-(c+p)$ |
| 到期高于看涨行权价 | $S_T>K_c$ | $S_T-K_c-(c+p)$ |

#### 4.2.3 示例

$K_p = 90$、$K_c = 110$，成本8，盈亏平衡在$S_T = 82$与$S_T = 118$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $78$ | $S_T<K_p$ |$+4$ |$-4$ |
| $82$ | 下行盈亏平衡 | $0$ | $0$ |
| $100$ | $K_p$与$K_c$之间 |$-8$ |$+8$ |
| $118$ | 上行盈亏平衡 | $0$ | $0$ |
| $122$ | $S_T>K_c$ |$+4$ |$-4$ |

多头在$S_T$跌破82或涨过118后盈利，落在90与110之间亏损最大8；空头相反。

#### 4.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的长期区间震荡；做空波动率，安全区比卖出跨式更宽 | $S_T$落在$K_p$与$K_c$之间赚满$c+p$、胜率高于卖出跨式，但收取的期权费较少；对非负价格标的，上行突破的亏损无上限，下行突破的亏损有限 |
| 期权持有方 | 判断标的大幅波动、方向不明，但希望比跨式更低成本；做多波动率 | 用更虚值的行权价降低成本，$S_T$突破$K_p-(c+p)$ 或$K_c+(c+p)$ 才盈利，需要更大波动；落在$K_p$与$K_c$之间亏损最大，为$c+p$ |

#### 4.2.5 总结

宽跨式同时买入虚值看跌和虚值看涨，用更低成本押注大幅波动。相较跨式，获利所需的价格变动更大，但最大亏损较低。适合预期存在大行情、同时接受需要更强波动才能盈利的情形。

### 4.3 蝶式

#### 4.3.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入$c(K_1)$、卖出2份$c(K_2)$、买入$c(K_3)$，$K_2 = (K_1+K_3) / 2$；全用看跌构造损益相同 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K_1<K_2<K_3$，示例$K_1 = 90$、$K_2 = 100$、$K_3 = 110$ |
| 净支出 | $D$，期初净额支付，示例$D = 2.5$ |
| 行权方式 | 欧式，各腿均在到期时刻$T$行权 |

#### 4.3.2 损益结构

多头净损益 = $\max(S_T-K_1,0)-2\cdot \max(S_T-K_2,0)+\max(S_T-K_3,0)-D$。两个盈亏平衡为$S_T = K_1+D$与$S_T = K_3-D$；最大盈利为($K_2-K_1)-D$，在$S_T = K_2$时取得；最大亏损为$D$，在$S_T\le K_1$或$S_T\ge K_3$时取得。对手方即卖出蝶式，损益反向。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期落在两端区间外 | $S_T\le K_1$或$S_T\ge K_3$ | $-D$ |
| 到期落在低行权价与中间行权价之间 | $K_1<S_T\le K_2$ | $S_T-K_1-D$ |
| 到期落在中间行权价与高行权价之间 | $K_2<S_T<K_3$ | $K_3-S_T-D$ |

#### 4.3.3 示例

$K_1 = 90$、$K_2 = 100$、$K_3 = 110$、$D = 2.5$，盈亏平衡在$S_T = 92.5$与$S_T = 107.5$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $90$ | $S_T\le K_1$ |$-2.5$ |$+2.5$ |
| $92.5$ | 下侧盈亏平衡 | $0$ | $0$ |
| $100$ | $S_T = K_2$，峰值 |$+7.5$ |$-7.5$ |
| $107.5$ | 上侧盈亏平衡 | $0$ | $0$ |
| $110$ | $S_T\ge K_3$ |$-2.5$ |$+2.5$ |

多头在$S_T$落于92.5与107.5之间盈利，收在100时最大7.5；偏离到90及以下或110及以上亏损最大2.5。

#### 4.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的到期明显偏离$K_2$、朝任一方向走出去，即卖出蝶式；温和做多波动率 | $S_T$远离$K_2$至两端之外时保留净收入即最大盈利；恰好收在$K_2$时亏损最大且有限 |
| 期权持有方 | 判断标的到期正好落在$K_2$附近、波动收敛；以很低成本博一个精确落点 | $S_T$落在$K_1+D$与$K_3-D$之间才盈利，恰好收在$K_2$时收益最大 ($K_2-K_1)-D$，偏离越远越少；落到两端之外亏损最大，为$D$，金额小且已知 |

#### 4.3.5 总结

蝶式用有限成本押注到期价格落在中间行权价附近，收益在中间位置最高，偏离越远收益越低。其本质是放弃大幅波动的收益，换取窄区间内的较高回报和明确的最大亏损。适合预期波动收敛、且对到期位置有较明确判断的情形。

### 4.4 鹰式

#### 4.4.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入$c(K_1)$、卖出$c(K_2)$、卖出$c(K_3)$、买入$c(K_4)$，$K_1<K_2<K_3<K_4$ |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K_1<K_2<K_3<K_4$，示例$K_1 = 85$、$K_2 = 95$、$K_3 = 105$、$K_4 = 115$ |
| 净支出 | $D$，期初净额支付，示例$D = 3$ |
| 行权方式 | 欧式，各腿均在到期时刻$T$行权 |

#### 4.4.2 损益结构

多头净损益 = $\max(S_T-K_1,0)-\max(S_T-K_2,0)-\max(S_T-K_3,0)+\max(S_T-K_4,0)-D$。两个盈亏平衡为$S_T = K_1+D$与$S_T = K_4-D$；最大盈利为($K_2-K_1)-D$，在$K_2\le S_T\le K_3$时取得；最大亏损为$D$，在两端之外取得。对手方即卖出鹰式，损益反向。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期落在两端区间外 | $S_T\le K_1$或$S_T\ge K_4$ | $-D$ |
| 到期落在第一与第二行权价之间 | $K_1<S_T<K_2$ | $S_T-K_1-D$ |
| 到期落在第二与第三行权价之间 | $K_2\le S_T\le K_3$ | ($K_2-K_1)-D$ |
| 到期落在第三与第四行权价之间 | $K_3<S_T<K_4$ | $K_4-S_T-D$ |

#### 4.4.3 示例

$K_1 = 85$、$K_2 = 95$、$K_3 = 105$、$K_4 = 115$、$D = 3$，盈亏平衡在$S_T = 88$与$S_T = 112$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $85$ | $S_T\le K_1$ |$-3$ |$+3$ |
| $88$ | 下侧盈亏平衡 | $0$ | $0$ |
| $100$ | $K_2$与$K_3$之间，平台 |$+7$ |$-7$ |
| $112$ | 上侧盈亏平衡 | $0$ | $0$ |
| $115$ | $S_T\ge K_4$ |$-3$ |$+3$ |

多头在$S_T$落于88与112之间盈利，落在95与105之间收益最大7；偏离到两端之外亏损最大3。

#### 4.4.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的到期走出$K_2$与$K_3$区间、方向不明，即卖出鹰式；温和做多波动率 | $S_T$落在两端之外时保留净收入即最大盈利；落在$K_2$与$K_3$之间亏损最大且有限 |
| 期权持有方 | 判断标的到期落在$K_2$与$K_3$区间、波动收敛，但不押死具体一点；比蝶式容错高 | $S_T$落在$K_1+D$与$K_4-D$之间才盈利，落在$K_2$与$K_3$之间收益最大 ($K_2-K_1)-D$；两端之外亏损最大，为$D$。最高收益略低于同宽蝶式，换来更宽的获利区间 |

#### 4.4.5 总结

鹰式与蝶式同样受益于到期价格落在目标区间，但最大收益形成于两个中间行权价之间，而非单一点位。相比蝶式，鹰式的获利区间更宽，代价是峰值收益通常更低。适合预期标的窄幅波动、但不希望把判断限定在单一价格的情形。

## 5 障碍期权

在普通期权上附加价格触发条件。敲出型在存续期内触及障碍$H$时作废，敲入型在触及$H$后才生效。普通看涨与看跌的到期价值分别为$\max(S_T-K,0)$和$\max(K-S_T,0)$。若以$V_T$表示对应普通期权到期价值，则敲出型净损益为$V_T\cdot\mathbf{1}_{\{\text{全程未触及}H\}}-\text{期权费}$，敲入型净损益为$V_T\cdot\mathbf{1}_{\{\text{曾触及}H\}}-\text{期权费}$。敲入敲出平价：同方向、同行权价、同障碍价格的买入敲入与买入敲出之和等于对应普通期权。观察多为每日观察，障碍附近损益不连续。以下均以多头列示，期权费示例取5，空头损益反向。


### 5.1 向上敲出看涨

#### 5.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入向上敲出看涨，存续期内触及$H$即作废 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$；若提前敲出则终止 |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 障碍价 | 向上障碍$H>K$，示例$H = 120$ |
| 观察 | 每日观察$S_t$是否触及$H$ |
| 期权费 | $c$，期初支付，示例$c = 5$ |
| 收益时点 | 敲出时按$-c$结清；未敲出在到期时刻$T$结算 |

#### 5.1.2 损益结构

多头净损益 = $\max(S_T-K,0)\cdot\mathbf{1}_{\{\text{全程未触及}H\}}-c$。未敲出时同普通看涨、收益随$S_T$上行但因$S_T<H$而封顶，接近$H-K-c$；触及$H$敲出则为$-c$。未敲出时盈亏平衡$S_T = K+c$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 向上敲出 | 触及$H$，敲出 | $-c$ |
| 未敲出且到期实值 | 未敲出且$S_T>K$ | $S_T-K-c$ |
| 未敲出且到期虚值或平值 | 未敲出且$S_T\le K$ | $-c$ |

#### 5.1.3 示例

$K = 100$、$H = 120$、$c = 5$，未敲出时盈亏平衡在$S_T = 105$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 有敲出 | 存续期内触及120，敲出 |$-5$ |$+5$ |
| 未敲出，到期等于行权价 | 未敲出，$S_T = 100$ |$-5$ |$+5$ |
| 未敲出，到期盈亏平衡 | 未敲出，$S_T = 105$ | $0$ | $0$ |
| 未敲出，到期高于行权价 | 未敲出，$S_T = 115$ |$+10$ |$-10$ |

多头只在标的始终不触及120、且到期收在105以上时盈利，收益最高接近15；触及120即敲出，亏损为期权费5。

#### 5.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的会较快触及$H$使合约作废；收取期权费，承担未敲出且标的上行时的赔付 | 触及$H$后保留全部期权费；未敲出且$S_T$上行时按多头收益反向赔付 |
| 期权持有方 | 温和看涨，判断标的上涨但难以触及$H$；放弃触及$H$之后的行情以换取低于普通看涨的期权费 | 未敲出时$S_T$超过$K+c$才盈利，收益随涨幅但被$H$封顶，最高接近$H-K-c$；触及$H$敲出只亏期权费$c$ |

#### 5.1.5 总结

向上敲出看涨保留标的温和上涨时的看涨收益，但一旦价格触及上方障碍便提前作废。投资者以放弃大涨行情为代价，换取低于普通看涨的期权费。适合预期标的会上涨、但难以突破上方障碍的情形。

多头在标的守在82以上、且到期收在95以下时盈利，收益最高接近13；反直觉之处在于一旦跌破82敲出反而归零，只亏期权费5。

#### 5.6.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的会深跌触及$H$使合约作废；收取期权费，承担未敲出且标的温和下行时的赔付 | 跌破$H$后保留全部期权费；未敲出且标的下行时按多头收益反向赔付 |
| 期权持有方 | 温和看跌，判断标的小跌但不会深跌触及$H$；放弃跌破$H$之后的行情换取更低期权费 | 未敲出时$S_T$跌破$K-p$才盈利，收益随跌幅但被$H$封顶，最高接近$K-H-p$；跌破$H$反而敲出，只亏期权费$p$ |

#### 5.6.5 总结

向下敲出看跌只适用于温和下跌：标的下跌可以带来收益，但跌至下方障碍后反而作废。较低期权费对应的是放弃深度下跌的保护，适合预期标的小幅走弱但不会快速下破关键支撑的情形。

### 5.7 向上敲入看跌

#### 5.7.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入向上敲入看跌，触及$H$后才生效 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 障碍价 | 向上障碍$H>K$，示例$H = 120$ |
| 观察 | 每日观察$S_t$是否触及$H$ |
| 期权费 | $p$，期初支付，示例$p = 5$ |
| 收益时点 | 到期时刻$T$结算，未触及$H$则作废 |

#### 5.7.2 损益结构

多头净损益 = $\max(K-S_T,0)\cdot\mathbf{1}_{\{\text{曾触及}H\}}-p$。触及$H$激活后同普通看跌；始终未触及$H$则作废，为$-p$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 未敲入 | 未触及$H$ | $-p$ |
| 已敲入且到期实值 | 触及$H$后且$S_T<K$ | $K-S_T-p$ |
| 已敲入且到期虚值或平值 | 触及$H$后且$S_T\ge K$ | $-p$ |

#### 5.7.3 示例

$K = 100$、$H = 120$、$p = 5$，激活后盈亏平衡在$S_T = 95$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 未敲入 | 未触及120 | $-5$ | $+5$ |
| 已敲入，到期盈亏平衡 | 触及120后回落，$S_T = 95$ | $0$ | $0$ |
| 已敲入，到期低于行权价 | 触及120后回落，$S_T = 85$ | $+10$ | $-10$ |
| 已敲入，到期高于行权价 | 触及120后，$S_T = 110$ | $-5$ | $+5$ |

多头只有在标的先触及120激活、且到期回落收在95以下时才盈利；从未触及120则作废，亏损为期权费5。

#### 5.7.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的难以触及$H$、合约无法激活；收取期权费 | 标的始终不触及$H$时保留全部期权费；触及$H$且标的下行时按多头收益反向赔付 |
| 期权持有方 | 判断标的先冲高触及$H$、再回落下跌；以低于普通看跌的期权费押这一路径 | 需先触及$H$才生效，激活后$S_T$跌破$K-p$才盈利、越跌越多；始终未触及$H$则即便下跌也作废，只亏期权费$p$ |

#### 5.7.5 总结

向上敲入看跌要求标的先冲高触及上方障碍，再回落下跌，触发后才具备看跌收益。该结构以更低成本押注冲高回落的路径，单纯下跌而未先触及障碍并不能使合约生效。

## 6 二元与数字期权

按到期价格或存续期内是否触碰障碍，支付一笔固定赔付，押的是是非题或概率。记赔付发生的条件成立取1、否则取0。恒等关系：同$K$的现金二元看涨与看跌之和等于赔付$Q$；同$H$、同到期的触碰即付与不碰才付之和等于赔付$Q$。现金二元与触碰型的最大盈利为赔付减期权费、最大亏损为期权费；资产二元赔付为标的价值。以下以多头列示，空头损益反向。


### 6.1 现金二元看涨

#### 6.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入现金二元看涨，到期$S_T>K$支付固定$Q$，否则归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$ |
| 行权价 | $K$，示例$K = S_0 = 100$ |
| 赔付 | 固定金额$Q$，示例$Q = 20$ |
| 期权费 | $c$，期初支付，示例$c = 8$ |
| 收益时点 | 到期时刻$T$依据$S_T$判定 |

#### 6.1.2 损益结构

多头净损益 = $Q\cdot (S_T>K)-c$。到期损益是$K$处从$-c$跳到$Q-c$的阶梯，与涨幅无关。最大盈利$Q-c$，最大亏损$c$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 到期未触发 | $S_T\le K$ | $-c$ |
| 到期触发 | $S_T>K$ | $Q-c$ |

#### 6.1.3 示例

$K = 100$、$Q = 20$、$c = 8$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| $95$ | $S_T\le K$ |$-8$ |$+8$ |
| $100$ | $S_T\le K$ |$-8$ |$+8$ |
| $101$ | $S_T>K$ |$+12$ |$-12$ |
| $120$ | $S_T>K$ |$+12$ |$-12$ |

多头只要到期站上100即净赚12，涨到101与涨到120收益相同；未站上则亏期权费8。

#### 6.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断到期标的站不上$K$；收取期权费，承担站上后的固定赔付 | $S_T$不高于$K$时保留期权费即最大盈利；站上$K$后固定赔付$Q$、净亏$Q-c$ |
| 期权持有方 | 判断到期标的能否站上$K$，只关心是否过线、不关心涨幅；对某价位到期能否守住有明确概率判断 | $S_T$站上$K$得固定净收益$Q-c$；未站上亏期权费$c$。赔付固定，不随涨幅变化 |

#### 6.1.5 总结

现金二元看涨只判断到期是否站上行权价，达到条件即获得固定赔付，涨幅大小不再影响收益。投资者买的是一个价格事件发生的概率，而非上涨幅度；最大收益和最大亏损均在期初确定。适合对关键价位能否被突破有明确判断的情形。

| 期限 | 自期初持有至到期时刻$T$，存续期内任一时刻均可触发 |
| 障碍价 | 触碰价$H$，示例$H = 115$ |
| 赔付 | 固定金额$Q$，示例$Q = 20$ |
| 观察 | 每日观察$S_t$是否触及$H$ |
| 期权费 | $c$，期初支付，示例$c = 8$ |
| 收益时点 | 触及$H$即支付，不要求到期仍在；始终未触及则到期归零 |

#### 6.5.2 损益结构

多头净损益 = $Q\cdot\mathbf{1}_{\{\text{存续期内触及}H\}}-c$。只要任一时刻触及$H$即得$Q$，与到期价格无关。最大盈利$Q-c$，最大亏损$c$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 已触碰障碍 | 触及$H$ | $Q-c$ |
| 未触碰障碍 | 始终未触及$H$ | $-c$ |

#### 6.5.3 示例

$H = 115$、$Q = 20$、$c = 8$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 已触碰障碍 | 存续期内触及115 | $+12$ | $-12$ |
| 未触碰障碍 | 始终未触及115 | $-8$ | $+8$ |

多头只要存续期内任一时刻触及115即净赚12，即使到期又回落也不影响；始终触不到则亏期权费8。

#### 6.5.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的整个存续期都触不到$H$；收取期权费，承担触及后的固定赔付 | 始终未触及$H$时保留期权费即最大盈利；触及后固定赔付$Q$、净亏$Q-c$ |
| 期权持有方 | 判断标的会朝某方向触及关键价位$H$，但不确定到期能否守住；波动越大越易触及、越有利 | 存续期内触及$H$即净赚$Q-c$，不要求到期仍在；始终未触及则亏期权费$c$ |

#### 6.5.5 总结

触碰即付只看存续期内是否触及障碍，触发后立即获得固定赔付，到期是否回落不再影响结果。它押注的是价格路径和触碰概率，波动越大通常越有利。适合判断标的会触及关键价位、但不要求到期守住该价位的情形。

### 6.6 不碰才付

#### 6.6.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入不碰才付，存续期内全程未触及$H$才支付固定$Q$，触及即归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻$T$，全程观察 |
| 障碍价 | 触碰价$H$，示例$H = 115$ |
| 赔付 | 固定金额$Q$，示例$Q = 20$ |
| 观察 | 每日观察$S_t$是否触及$H$ |
| 期权费 | $c$，期初支付，示例$c = 8$ |
| 收益时点 | 到期时刻$T$结算，存续期内触及$H$则提前作废 |

#### 6.6.2 损益结构

多头净损益 = $Q\cdot\mathbf{1}_{\{\text{全程未触及}H\}}-c$。全程不触及$H$才得$Q$，中途触及一次即归零。最大盈利$Q-c$，最大亏损$c$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 未触碰障碍 | 全程未触及$H$ | $Q-c$ |
| 已触碰障碍 | 触及$H$ | $-c$ |

#### 6.6.3 示例

$H = 115$、$Q = 20$、$c = 8$。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 未触碰障碍 | 全程未触及115 | $+12$ | $-12$ |
| 已触碰障碍 | 存续期内触及115 | $-8$ | $+8$ |

多头只要标的全程不触及115即净赚12；中途触及一次即作废、亏期权费8。与触碰即付方向相反，波动越小越有利。

#### 6.6.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的迟早会触及$H$；收取期权费，承担全程未触及时的固定赔付 | 触及$H$后保留期权费即最大盈利；全程未触及则固定赔付$Q$、净亏$Q-c$ |
| 期权持有方 | 判断标的始终在区间内、不会突破到$H$，即窄幅震荡；波动越小越有利 | 全程未触及$H$得净收益$Q-c$；中途触及一次即归零、亏期权费$c$ |


#### 6.6.5 总结

不碰才付要求标的在整个存续期内始终不触及障碍，任何一次触碰都会使固定赔付失效。它押注的是低波动和区间稳定，路径比到期价格更重要。适合预期标的不会突破关键价位的情形，但障碍附近的短暂波动也可能导致全部收益落空。



## 7 气囊结构

气囊（Airbag）在普通看涨敞口上加一层下行保护，形似汽车安全气囊。设期初价 S0、到期价 ST，记涨跌幅 R = ST / S0 − 1；另设敲入线 B（B < S0，示例取 B = 80%·S0，每日观察）。核心机制：存续期内标的从未触及敲入线（未敲入）时，下跌不亏、只放弃期初支付的期权费，上涨则按约定方式参与；一旦触及敲入线（敲入），保护失效，投资者按 R 承担标的的全部涨跌，与直接持有标的相仿。标准型付期权费换取“不封顶的上行参与＋下行保护”，封顶型与折让参与率型以让渡部分上行换取零期权费。以下各结构的敲入线、参与率、封顶水平、期权费均为示例值，可按实际条款调整；以多头（产品持有方）列示，空头为发行方，损益反向，收益按名义本金折算收益率。

### 7.1 标准安全气囊Airbag

#### 7.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入标准安全气囊Airbag，未敲入享上行参与＋下行保护，敲入后承担标的涨跌 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，自期初持有至到期时刻 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲入线 | 敲入价 B，示例 B = 80%·S0，每日观察 St 是否触及 |
| 未敲入收益 | Max(0, R)，即上涨全额参与、下跌保护为零 |
| 敲入后收益 | R，即按标的实际涨跌线性承担 |
| 期权费 | 期初支付，示例取 5% |
| 收益时点 | 到期时刻 T 按 ST 结算 |

#### 7.1.2 损益结构

净收益率 = [未敲入时 Max(0, R)，敲入后 R] − 期权费。未敲入且上涨时收益随涨幅无上限；未敲入且下跌时收益为零、只亏期权费，这就是“气囊”的缓冲；一旦触及 B 敲入，保护失效，按 R 承担全部下跌。最大盈利无上限，最大亏损在敲入且标的大跌时接近 R − 期权费。未敲入时盈亏平衡为 R 等于期权费。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 未敲入且标的上涨 | 未敲入且 R > 0 | R − 期权费 |
| 未敲入且标的不涨 | 未敲入且 R ≤ 0 | −期权费 |
| 已敲入 | 存续期内曾触及或跌破$B$ | R − 期权费 |

#### 7.1.3 示例

示例取 S0 = 100、敲入线 B = 80、期权费 5%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入，上涨 | 全程未触及80，ST = 130（R = +30%） | +25% |
| 未敲入，恰好盈亏平衡 | 全程未触及80，ST = 105（R = +5%） | 0% |
| 未敲入，下跌但不亏本金 | 全程未触及80，ST = 90（R = −10%，未触及敲入线） | −5% |
| 敲入，到期未修复 | 存续期内触及80后，到期ST = 70 | −35% |

多头只要标的始终不触及敲入线，下跌最多亏期权费，上涨则全额参与；一旦跌破敲入线，就按标的实际跌幅承担亏损，与直接持股相仿。

#### 7.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看涨但担心阶段性回调，判断标的不会深跌至敲入线；愿付期权费换取“下跌不亏、上涨全参与” | 未敲入且上涨超过期权费才净盈利、收益无上限；未敲入即便下跌也只亏期权费；触及敲入线后保护失效，按标的跌幅承担亏损 |
| 空头 | 发行方，判断标的大概率上涨有限或将跌破敲入线；收取期权费，承担未敲入上行时的参与赔付 | 标的敲入或到期不涨时保留期权费；未敲入且大涨时按多头收益反向赔付 |

#### 7.1.5 总结

标准安全气囊Airbag由“未敲入前的上行参与＋下行保护”和“敲入后按标的实际涨跌线性承担”两段损益拼接而成：先看存续期内是否触及敲入线，未触及时以固定期权费换取下跌不亏、上涨不封顶；一旦触及敲入线，保护即失效，收益与直接持有标的相近。它是用期权费交换“深跌保护”，适合看涨但担心阶段性深跌、且判断标的不会跌穿敲入线的情形；若标的持续下探并跌破敲入线，保护作用随即消失。

### 7.2 安全气囊Airbag（上涨收益封顶）

#### 7.2.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入封顶型安全气囊Airbag，以让渡上限以上涨幅换取零期权费 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，自期初持有至到期时刻 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲入线 | 敲入价 B，示例 B = 80%·S0，每日观察 |
| 收益上限 | 封顶水平 Cap，示例取 25% |
| 未敲入收益 | Max[0, Min(Cap, R)]，即上行参与但封顶 |
| 敲入后收益 | R，即按标的实际涨跌线性承担 |
| 期权费 | 示例取 0%，以封顶换取零成本 |
| 收益时点 | 到期时刻 T 按 ST 结算 |

#### 7.2.2 损益结构

净收益率 = 未敲入时 Max[0, Min(Cap, R)]，敲入后 R；期权费为零。未敲入且上涨时收益随涨幅递增但不超过封顶水平 Cap，涨幅再高收益也不增加；未敲入且下跌时收益为零、不亏期权费；敲入后按 R 承担全部下跌。用“放弃封顶以上的涨幅”换来了零成本。最大盈利为 Cap，最大亏损在敲入且标的大跌时接近 R。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 未敲入且收益达到上限 | 未敲入且 R ≥ Cap | Cap |
| 未敲入且正收益未达上限 | 未敲入且 0 < R < Cap | R |
| 未敲入且无正收益 | 未敲入且 R ≤ 0 | 0 |
| 已敲入 | 存续期内曾触及或跌破$B$ | R |

#### 7.2.3 示例

示例取 S0 = 100、敲入线 B = 80、封顶 Cap = 25%、期权费 0%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入，涨幅超过封顶 | 全程未触及80，ST = 140（R = +40%） | +25% |
| 未敲入，涨幅在封顶以内 | 全程未触及80，ST = 115（R = +15%） | +15% |
| 未敲入，下跌但不亏本金 | 全程未触及80，ST = 90（R = −10%，未触及敲入线） | 0% |
| 敲入，到期未修复 | 存续期内触及80后，到期ST = 70 | −30% |

多头零成本参与上行，但涨过封顶水平后收益不再增加；未敲入下跌不亏；跌破敲入线则承担全部跌幅。

#### 7.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看涨但预期涨幅温和、大概率不超过封顶水平，且不愿支付期权费；判断标的不会深跌至敲入线 | 未敲入时涨多少赚多少、以封顶水平为限；未敲入下跌也不亏（零成本）；触及敲入线后按标的跌幅承担亏损 |
| 空头 | 发行方，判断标的涨幅有限或将敲入；以封顶换取不收期权费的结构，承担未敲入且涨幅在封顶以内的赔付 | 标的敲入或不涨时无需赔付；未敲入且上涨时按多头收益（以封顶为限）反向赔付 |

#### 7.2.5 总结

安全气囊Airbag（上涨收益封顶）与标准安全气囊共用同一套敲入判断逻辑，区别在于把上行参与由“不封顶”改为“封顶于 Cap”，以此换取零期权费：未敲入时下跌不亏、上涨参与但达到封顶后不再增加；一旦触及敲入线，保护失效，按标的实际跌幅承担损失。它省去了期初成本，代价是牺牲大涨时的额外收益，适合预期涨幅温和、不愿支付期权费的情形。

### 7.3 安全气囊Airbag（折让上涨参与率）

#### 7.3.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入折让参与率型安全气囊Airbag，以低于 100% 的参与率换取零期权费 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，自期初持有至到期时刻 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲入线 | 敲入价 B，示例 B = 80%·S0，每日观察 |
| 参与率 | 参与率 α，示例取 74% |
| 未敲入收益 | Max(0, R) × α，即上涨按参与率参与 |
| 敲入后收益 | R，即按标的实际涨跌线性承担 |
| 期权费 | 示例取 0%，以折让参与率换取零成本 |
| 收益时点 | 到期时刻 T 按 ST 结算 |

#### 7.3.2 损益结构

净收益率 = 未敲入时 Max(0, R) × α，敲入后 R；期权费为零。未敲入且上涨时按涨幅的 α 参与、上不封顶；未敲入且下跌时收益为零、不亏期权费；敲入后按 R 承担全部下跌。用“打折的上行参与率”换来了零成本，与封顶型相比保留了大涨的空间，但每一元涨幅只拿 α。最大盈利无上限，最大亏损在敲入且标的大跌时接近 R。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 未敲入且标的上涨 | 未敲入且 R > 0 | R × α |
| 未敲入且标的不涨 | 未敲入且 R ≤ 0 | 0 |
| 已敲入 | 存续期内曾触及或跌破$B$ | R |

#### 7.3.3 示例

示例取 S0 = 100、敲入线 B = 80、参与率 α = 74%、期权费 0%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入，大涨 | 全程未触及80，ST = 140（R = +40%） | +29.6% |
| 未敲入，温和上涨 | 全程未触及80，ST = 110（R = +10%） | +7.4% |
| 未敲入，下跌但不亏本金 | 全程未触及80，ST = 90（R = −10%，未触及敲入线） | 0% |
| 敲入，到期未修复 | 存续期内触及80后，到期ST = 70 | −30% |

多头零成本参与上行、且不封顶，但每一元涨幅只拿参与率；未敲入下跌不亏；跌破敲入线则承担全部跌幅。与封顶型相比，大涨时更占优、温和上涨时略逊。

#### 7.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看涨且预期可能大涨、不愿封顶也不愿付期权费；接受每元涨幅只拿参与率 α；判断标的不会深跌至敲入线 | 未敲入时按涨幅的 α 参与、上不封顶；未敲入下跌不亏（零成本）；触及敲入线后按标的跌幅承担亏损 |
| 空头 | 发行方，判断标的涨幅有限或将敲入；以折让参与率换取不收期权费，承担未敲入上行按 α 的赔付 | 标的敲入或不涨时无需赔付；未敲入且上涨时按多头收益（α 参与）反向赔付 |

#### 7.3.5 总结

安全气囊Airbag（折让上涨参与率）同样以未触及敲入线为前提提供下行保护，但把上行参与由“封顶”改为“打折”：未敲入时下跌不亏、上涨不封顶，只是每一元涨幅按参与率 α 打折兑现；一旦触及敲入线，保护失效，按标的实际跌幅承担损失。相较封顶型，它在大涨行情中更占优，在温和上涨行情中收益略逊，适合预期可能出现较大涨幅、又不愿意支付期权费的情形。

## 8 累计期权

累计期权（Accumulator）以约定的执行价格分批买入或卖出标的，通过每日观察收盘价与执行价、敲出价的关系，决定当日成交数量：价格对投资者越有利（如标的下跌）时，通常需要以更大数量成交；价格达到敲出价则提前终止后续观察。它不是单笔到期结算的期权，而是逐日累计买入或卖出的路径依赖结构，最终损益取决于全部成交数量与执行价、结算价格的关系。以下要素、观察日数、执行价、敲出价、单日数量和累计倍数均为示例值，可按实际条款调整；以多头（投资者/买入方）列示，空头为对手方，损益反向。

### 8.1 标准累购

#### 8.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入标准累购合约，按日以折价方式买入标的，价格跌破执行价时加倍买入，价格达到敲出价后合约提前终止 |
| 标的 | 单一个股、指数或指数基金等标的资产 |
| 合约期限 | 自期初持有至到期，共 N 个观察日，每个交易日观察一次，示例取 N = 240 个交易日 |
| 期初价 | S0，示例取 S0 = 100 |
| 敲出价 | H，示例取 H = 105%·S0；任一观察日收盘价 St ≥ H 即触发敲出，当日起停止观察 |
| 执行价格（买入价） | K，示例取 K = 90%·S0，低于期初价；无论当日收盘价高于或低于 K，均按 K 价成交 |
| 单日基础数量 | q，示例取 q = 100 股 |
| 累计倍数 | m，示例取 m = 2；当日收盘价 St < K 时按 m·q 买入，即 200 股 |
| 保股期 | 合约起算后的前 L 个观察日，示例取 L = 20 个交易日 |
| 保股期内敲出 | 敲出日（含）至保股期截止日（含）之间的每个观察日仍按执行价买入基础数量 q，不再判断当日股价，保股期截止后停止买入 |
| 保股期外敲出 | 敲出当日起立即停止买入 |

#### 8.1.2 损益结构

每个观察日先判断合约是否已敲出：未敲出时，若当日收盘价不低于执行价则按执行价买入基础数量 q，若低于执行价则按执行价买入 m·q；一旦某观察日收盘价达到敲出价，当日及以后是否继续买入取决于敲出日是否落在保股期内。全部成交数量累计后，按累计股数与结算价格、执行价的差额计算最终损益：净损益 = 累计买入股数 ×（结算价格 − 执行价）。结算价格越高于执行价，投资者持有的低价买入份额增值越多；标的持续深跌时，因跌破执行价的交易日按加倍数量买入，累计份额被放大，按结算价格计算的亏损也随之放大。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 保股期内敲出 | 保股期内敲出（第 d 个观察日敲出，d ≤ L） | 累计买入股数 ×（结算价格 − 执行价），累计股数含敲出前按当日股价判断的买入量与敲出后至保股期截止日按基础数量买入的部分 |
| 保股期外敲出 | 保股期外敲出（第 d 个观察日敲出，d > L） | 累计买入股数 ×（结算价格 − 执行价），累计股数为敲出前 d − 1 个观察日按当日股价判断的买入量，敲出当日不买入 |
| 合约期内未敲出 | 合约期内未敲出（全部 N 个观察日均低于 H） | 累计买入股数 ×（结算价格 − 执行价），累计股数为全部 N 个观察日按当日股价判断的买入量 |

#### 8.1.3 示例

示例取 S0 = 100、H = 105、K = 90、q = 100 股、m = 2、L = 20 个交易日、N = 240 个交易日。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 保股期内敲出 | 第15个观察日敲出（保股期内），此前11天收盘价不低于执行价、3天低于执行价，敲出后至第20天保股期截止再买入6天，结算价格110；累计买入股数 = 11×100 + 3×200 + 6×100 = 2,300股 | 2,300 ×（110 − 90）= 46,000元 |
| 保股期外敲出 | 第60个观察日敲出（保股期外），此前57天收盘价不低于执行价、2天低于执行价，敲出当日不买入，结算价格110；累计买入股数 = 57×100 + 2×200 = 6,100股 | 6,100 ×（110 − 90）= 122,000元 |
| 未敲出，温和下跌 | 全程未达到105，237天收盘价不低于执行价、3天低于执行价，期末价格95；累计买入股数 = 237×100 + 3×200 = 24,300股 | 24,300 ×（95 − 90）= 121,500元 |
| 未敲出，持续深跌 | 全程未达到105，前60天收盘价不低于执行价，其后180天持续低于执行价，期末价格85；累计买入股数 = 60×100 + 180×200 = 42,000股 | 42,000 ×（85 − 90）= −210,000元 |

#### 8.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的将维持震荡或温和上涨、不易持续深跌，愿意按执行价持续向投资者出售标的，并承担标的深跌时按加倍数量出售的义务 | 标的达到敲出价时提前终止义务；标的温和波动或上涨时按执行价出售获得价差收益；标的持续深跌时因加倍出售数量而承担更大敞口 |
| 期权持有方 | 本身有持续买入标的的需求，判断标的将在期初价附近区间震荡或温和上涨，愿意每天以低于期初价的执行价折价买入，并接受价格深跌时加倍买入以摊低成本、价格上涨过快时提前终止不再继续买入 | 标的达到敲出价后不再继续买入，已买入部分若结算价格高于执行价则盈利；标的温和波动或上涨时持续以折价买入获利；标的持续深跌时因加倍买入放大累计份额，按结算价格计算的亏损也相应放大 |

#### 8.1.5 总结

标准累购是一种路径依赖的分批买入结构：每个观察日先看合约是否已敲出，未敲出时按当日收盘价与执行价的高低决定当天买入数量——收盘价不低于执行价时按基础数量买入，跌破执行价时按累计倍数加倍买入，且无论哪种情形均按同一折价执行价成交；一旦某个观察日收盘价达到或超过敲出价，合约随即向提前终止方向发展：若敲出发生在保股期内，仍需按基础数量买入至保股期截止日；若发生在保股期外，敲出当日起立即停止买入。

最终损益取决于累计买入股数与执行价相对结算价格的差额：结算价格越高于执行价，持续折价买入的份额增值越多；若标的持续深跌，跌破执行价交易日的加倍买入会放大累计份额，按结算价格计算的亏损也随之放大。它适合本身就有持续加仓标的需求、且能接受价格下跌时被迫加倍买入的投资者，本质是用“折价买入＋深跌加倍摊薄”换取整体买入成本的降低，但深跌情形下由于份额被动放大，最终亏损也会比不设累计买入机制的普通买入更大。

## 9 自动赎回结构

自动赎回结构以敲出、敲入和票息为核心，涵盖雪球、凤凰式、FCN/DCN等以自动提前终止条款为特征的结构化产品。敲出通常表示标的（或表现最差的标的）在观察日达到或超过敲出价格后产品提前终止并支付约定票息；敲入通常表示标的在观察期内触及或跌破敲入价格后，投资者到期可能承担标的下跌损失。此类结构不是单纯的到期价格结构，必须同时判断存续期内是否敲出、是否敲入以及到期修复情况。本章按分类编号收录已登记结构，编号不连续的部分对应尚待录入的结构，参见optionlist.md。

### 9.1 经典型雪球

#### 9.1.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入经典型雪球产品，发行方卖出该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为24个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取20%，有追加保证金要求 |
| 初始价格与执行价 | $S_0$，$K = S_0$ |
| 约定票息/年化收益率 | $y$，示例取年化20% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出方向 | 向上敲出 |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出线 | $H_{out}$，示例取$103\%\cdot S_0$ |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，投资者取得截至敲出日的约定票息 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入方向 | 向下敲入 |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}$，示例取$70\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 若未敲出且曾敲入，到期按$S_T$与$S_0$的差额结算；若到期修复至$S_0$或以上，损失为0 |

#### 9.1.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日，使$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$，产品提前终止 |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全部敲入观察节点$S_t>H_{in}$ | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 全部敲出观察日$S_t<H_{out}$，且曾有$S_t\le H_{in}$ | $N\cdot \min((S_T-S_0)/S_0,0)$ |

#### 9.1.3 示例

设标的为中证500，名义本金$N = 1000$万元，期限24个月，初始保证金比例$g = 20\%$，约定票息$y = 20\%$，敲出线$H_{out} = 103\%\cdot S_0$，敲入线$H_{in} = 70\%\cdot S_0$，执行价$K = S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入后提前敲出 | 第240天观察日$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot20\%\cdot\frac{240}{365}=131.5\text{万元}$ |
| 曾敲入后提前敲出 | 存续期内曾跌破$70\%\cdot S_0$，第182天观察日$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot20\%\cdot\frac{182}{365}=99.7\text{万元}$ |
| 未敲出且未敲入 | 全程未达到$103\%\cdot S_0$，也从未低于$70\%\cdot S_0$ | $1000\text{万元}\cdot20\%\cdot2=400\text{万元}$ |
| 曾敲入且到期未修复 | 存续期内曾跌破$70\%\cdot S_0$，到期$S_T=65\%\cdot S_0$ | $1000\text{万元}\cdot(65\%-100\%)=-350\text{万元}$ |

#### 9.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 向投资者出售票息收入，并获得标的下跌时由投资者承担损失的经济敞口 | 发行方收益与投资者相反，主要风险来自标的走势、波动率和敲入敲出路径对冲 |
| 期权持有方 | 判断标的不会持续大幅下跌，接受以承担下行风险换取较高票息 | 标的上涨至敲出线时提前获得票息；震荡但未敲入时持有到期获得票息；一旦敲入且到期低于期初价格，承担全部跌幅损失 |

#### 9.1.5 总结

经典型雪球是最常见的单标的雪球框架：向上敲出、向下敲入、敲入后以期初价格作为到期结算基准。它以较高票息交换投资者对标的大幅下跌风险的承担。

判断顺序应先看是否敲出，敲出即提前按持有期结算票息；未敲出时再看是否发生过敲入，未敲入则取得到期票息；若曾敲入，则到期价格低于期初价格时按跌幅承担损失，到期回到期初价格或以上时损失为0。它适合对标的持中性偏多判断、且能够承受敲入后下跌风险的投资者。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |

| 曾敲入但到期高于执行价 | 存续期内曾跌至$68\%\cdot S_0$，到期$S_T=90\%\cdot S_0$ | 0 |
| 曾敲入且到期低于执行价 | 存续期内曾跌至$68\%\cdot S_0$，到期$S_T=65\%\cdot S_0$ | $N\cdot (65\%-85\%) = -200$万元 |

#### 9.2.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 通过下调执行价减轻投资者部分尾部损失，并相应调整票息、保证金或其他报价要素 | 敲出前的票息责任与经典雪球相近；未敲出且敲入后，需承担标的下跌风险的对冲成本 |
| 期权持有方 | 看好标的不会深跌，并希望在经典雪球的基础上获得更低的到期损失起点 | 执行价低于期初价格，曾敲入但到期价格介于$K$与$S_0$之间时不产生损失；若到期跌破$K$，才按低于$K$的部分承担损失 |

#### 9.2.5 总结

OTM型雪球与经典雪球的主要区别是执行价$K$低于期初价格$S_0$。敲入后若未敲出，投资者并非从期初价格开始承担下跌，而是只有到期价格跌破$K$才产生损失，因此相对经典雪球多了一段下跌保护。

这部分保护通常以较低票息、较高保证金要求或其他报价条件为代价。它仍是路径依赖结构：敲出即提前结束并按持有期支付票息；未敲出且发生敲入时，最终是否亏损取决于到期价格是否低于执行价。

| 提前敲出 | 存在某个敲出观察日$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全部敲入观察日$S_t>H_{in}$ | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入、到期不低于执行价 | 全部敲出观察日$S_t<H_{out}$，曾有$S_t\le H_{in}$，且$S_T\ge K$ | $0$ |
| 未敲出、曾敲入、到期低于执行价 | 全部敲出观察日$S_t<H_{out}$，曾有$S_t\le H_{in}$，且$S_T<K$ | $N\cdot\frac{S_T-K}{K}$ |

#### 9.3.3 示例

设$N=1000$万元，期限24个月，$y=14\%$，$H_{out}=103\%\cdot S_0$，$H_{in}=70\%\cdot S_0$，$K=85\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 第8个月观察日（第240天）$S_t=104\%\cdot S_0$ | $1000\text{万元}\cdot14\%\cdot\frac{240}{365}=92.1\text{万元}$ |
| 未敲出且未敲入 | 全程未达到敲出线，也未跌破敲入线 | $1000\text{万元}\cdot14\%\cdot2=280\text{万元}$ |
| 曾敲入但到期高于执行价 | 曾跌至$68\%\cdot S_0$，到期$S_T=90\%\cdot S_0$ | $0$ |
| 曾敲入且到期低于执行价 | 曾跌至$68\%\cdot S_0$，到期$S_T=65\%\cdot S_0$ | $1000\text{万元}\cdot(65\%-85\%)/85\%=-235.3\text{万元}$ |

#### 9.3.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望保留经典雪球的票息机会，并把敲入后真正开始承担损失的价格降至期初价格以下 | 到期价格位于执行价和期初价格之间时不产生亏损；跌破执行价后才承担损失 |
| 期权对手方 | 以更低执行价提供一段下跌缓冲，并通过票息、保证金和障碍水平调整报价 | 执行价下调通常会降低持有方尾部损失，同时改变结构成本和可给票息 |

#### 9.3.5 总结

折价OTM雪球的核心是执行价低于期初价格。敲入后未敲出时，持有方并不从期初价格开始承担损失，而是到期跌破执行价后才产生亏损。与经典雪球相比，这增加了一段下跌缓冲；作为交换，票息或其他报价条件通常会相应调整。

### 9.4 折价建仓型雪球

#### 9.4.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 期权持有方买入折价建仓型雪球，期权对手方提供该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为12个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取30%，初始保证金为$G=N\cdot g$ |
| 初始价格 | $S_0$ |
| 执行价 | $K<S_0$，示例取$K=90\%\cdot S_0$ |
| 约定票息 | $y$，示例取年化32% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出线 | $H_{out}$，示例取$103\%\cdot S_0$ |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 仅在尚未敲入时适用；产品提前终止并支付约定票息 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}$，示例取$70\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后处理 | 发生敲入后不再观察敲出，到期按执行价$K$线性结算 |

#### 9.4.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 未敲入后提前敲出 | 尚未敲入，且某个敲出观察日$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出且未敲入 | 全部敲出观察日$S_t<H_{out}$，且全部敲入观察日$S_t>H_{in}$ | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 曾敲入 | 曾有$S_t\le H_{in}$，此后不再观察敲出 | $N\cdot\frac{S_T-K}{K}$ |

#### 9.4.3 示例

设$N=1000$万元，期限12个月，$g=30\%$，$y=32\%$，$H_{out}=103\%\cdot S_0$，$H_{in}=70\%\cdot S_0$，$K=90\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入后提前敲出 | 第4个月观察日（第120天）$S_t=104\%\cdot S_0$ | $1000\text{万元}\cdot32\%\cdot\frac{120}{365}=105.2\text{万元}$ |
| 未敲出且未敲入 | 全程未触及两条障碍线 | $1000\text{万元}\cdot32\%=320\text{万元}$ |
| 曾敲入且到期高于执行价 | 曾跌至$68\%\cdot S_0$，到期$S_T=110\%\cdot S_0$ | $1000\text{万元}\cdot(110\%-90\%)/90\%=222.2\text{万元}$ |
| 曾敲入且到期低于执行价 | 曾跌至$68\%\cdot S_0$，到期$S_T=60\%\cdot S_0$ | $1000\text{万元}\cdot(60\%-90\%)/90\%=-333.3\text{万元}$ |

#### 9.4.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望在未发生极端下跌时获得较高票息；若大跌触发敲入，愿意按折价执行价建立标的敞口 | 敲入前保留正常敲出机会；敲入后不再有敲出，最终收益或亏损随到期价格相对执行价线性变化 |
| 期权对手方 | 将敲入后的收益结构转换为折价建仓敞口，以对应较高票息 | 敲入后需管理线性标的风险，且原有敲出机制不再终止该风险敞口 |

#### 9.4.5 总结

折价建仓型雪球把敲入后的处理从经典雪球的“继续等待敲出”改为“停止观察敲出、按折价执行价结算”。因此，敲入不仅触发下行风险，也改变产品后续路径。执行价低于期初价格提供了折价建仓机会，但到期低于执行价时仍会产生线性亏损。

### 9.5 超低敲入型雪球

#### 9.5.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 期权持有方买入超低敲入型雪球，期权对手方提供该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为24个月 |
| 锁定期 | 前3个月不进行敲出观察，实际以合同约定为准 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g=100\%$，初始保证金为$G=N$ |
| 约定票息 | $y$，示例取年化7.7% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出观察日 | 锁定期结束后通常每月观察 |
| 敲出线 | $H_{out}=100\%\cdot S_0$ |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，支付约定票息 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察 |
| 敲入线 | $H_{in}=65\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 未敲出且曾敲入时，按$S_T$相对$S_0$的跌幅结算，不设置保底 |

#### 9.5.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 任一敲出观察日$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全程未触及敲入线 | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 全部敲出观察日$S_t<H_{out}$，且曾触及敲入线 | $N\cdot\min((S_T-S_0)/S_0,0)$ |

#### 9.5.3 示例

设$N=1000$万元，期限24个月，$y=7.7\%$，$H_{out}=100\%\cdot S_0$，$H_{in}=65\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 第4个月观察日（第120天）$S_t\ge100\%\cdot S_0$ | $1000\text{万元}\cdot7.7\%\cdot\frac{120}{365}=25.3\text{万元}$ |
| 未敲出且未敲入 | 全程未低于$65\%\cdot S_0$ | $1000\text{万元}\cdot7.7\%\cdot2=154\text{万元}$ |
| 曾敲入且未敲出 | 曾跌破$65\%\cdot S_0$，到期$S_T=60\%\cdot S_0$ | $-400\text{万元}$ |

#### 9.5.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 认为发生大幅下跌并跌破65%的概率较低，愿意以全额资金换取较低敲入线和较高票息 | 敲入门槛较低，但一旦敲入且未敲出，仍承担标的全部到期跌幅 |
| 期权对手方 | 通过全保证金和低敲入线控制信用及路径风险 | 极端下跌后未敲出的标的风险仍由持有方承担 |

#### 9.5.5 总结

超低敲入型雪球通过降低敲入线减少敲入概率，但不设置到期亏损上限。它与超低敲入保底型雪球的关键区别是：前者在敲入后仍承担完整跌幅，后者将损失限制在保底水平以内。

#### 9.6.5 总结

超低敲入保底型雪球同时设置较低敲入线和保底水平。它将极端下跌时的最大亏损封顶，但代价通常是较低票息和较高的资金占用。保底仅限制最终损失，不代表不会发生敲入。

### 9.7 敲入变化型雪球

#### 9.7.1 要素

#### 9.7.3 示例

设$N=1000$万元，期限24个月，$y=22\%$，$H_{out}=103\%\cdot S_0$，第一年敲入线为$70\%\cdot S_0$，第二年敲入线为$75\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第一年提前敲出 | 第12个月前的观察日$S_t\ge103\%\cdot S_0$，此前未敲入 | 按22%年化和实际持有天数结算 |
| 第二年曾敲入后提前敲出 | 第二年跌破$75\%\cdot S_0$，后续观察日达到$103\%\cdot S_0$ | 按22%年化和实际持有天数结算 |

| 主体 | 动机与观点 | 盈亏情形 |

| 期权对手方 | 用分阶段敲入线配置不同期限的路径风险和票息 | 各阶段敲入线需要与波动率、期限和对冲成本共同定价 |

#### 9.7.5 总结

敲入变化型雪球把单一敲入线改为分阶段敲入线。示例中第一年为70%、第二年为75%，前期更不容易敲入，后期则提高敲入线。产品的最终损益逻辑仍是经典雪球逻辑，变化的是每段存续期触发敲入的条件。

| 敲出观察日 | 锁定期结束后通常每月观察 |
| 敲出线 | $H_{out}=97\%\cdot S_0$ |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，支付约定票息 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察 |
| 敲入线 | $H_{in}=80\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 未敲出且曾敲入时，按$S_T$相对$S_0$的跌幅结算 |

#### 9.8.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 任一敲出观察日$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全程未触及敲入线 | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 全部敲出观察日$S_t<H_{out}$，且曾触及敲入线 | $N\cdot\min((S_T-S_0)/S_0,0)$ |

#### 9.8.3 示例

设$N=1000$万元，期限24个月，$y=10.8\%$，$H_{out}=97\%\cdot S_0$，$H_{in}=80\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 第8个月观察日（第243天）$S_t\ge97\%\cdot S_0$ | $1000\text{万元}\cdot10.8\%\cdot\frac{243}{365}=71.9\text{万元}$ |
| 曾敲入后提前敲出 | 曾跌破$80\%\cdot S_0$，第6个月观察日（第182天）反弹至97% | $1000\text{万元}\cdot10.8\%\cdot\frac{182}{365}=53.9\text{万元}$ |
| 未敲出且未敲入 | 全程未触及两条障碍线 | $1000\text{万元}\cdot10.8\%\cdot2=216\text{万元}$ |
| 曾敲入且未敲出 | 曾跌破80%，到期$S_T=77\%\cdot S_0$ | $-230\text{万元}$ |

#### 9.8.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 更重视较高的提前结束概率，接受较低的票息 | 敲出线低于期初价格，温和反弹或小幅下跌时也可能敲出；未敲出且敲入后仍有下行损失 |
| 期权对手方 | 通过降低敲出线缩短多数路径的产品期限 | 敲出概率提高通常对应较低票息，剩余尾部风险仍需对冲 |

#### 9.8.5 总结

高概率敲出雪球通过把敲出线设在期初价格以下来提高敲出概率。它降低了长期存续和敲入未敲出的概率，但不改变敲入后的下跌结算逻辑。持有方获得的是更容易实现的较低票息，而不是下行风险的豁免。

### 9.9 敲出递降型雪球

#### 9.9.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 期权持有方买入敲出递降型雪球，期权对手方提供该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为24个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取20%，初始保证金为$G=N\cdot g$ |
| 初始价格与执行价 | $S_0$，$K=S_0$ |
| 约定票息 | $y$，示例取年化19% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出线 | 第一个观察日为$103\%\cdot S_0$；第$j$个观察日的敲出线为$H_{out,j}$，示例中每月下降0.5% |
| 敲出触发条件 | 第$j$个敲出观察日$S_t\ge H_{out,j}$ |
| 敲出结果 | 产品提前终止，持有方取得截至敲出日的约定票息 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}=70\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 未敲出且曾敲入时，按$S_T$相对$S_0$的跌幅结算 |

#### 9.9.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在第$j$个敲出观察日$S_t\ge H_{out,j}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、未敲入 | 所有敲出观察日均低于对应$H_{out,j}$，且未发生敲入 | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 所有敲出观察日均低于对应$H_{out,j}$，且曾发生敲入 | $N\cdot\min((S_T-S_0)/S_0,0)$ |

#### 9.9.3 示例

设$N=1000$万元，期限24个月，$y=19\%$，敲出线从$103\%\cdot S_0$起，每个敲出观察日下降0.5%，敲入线为$70\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 后期敲出 | 标的始终未达到较高的早期敲出线，但第8个月（第243天）达到当月下调后的敲出线 | $1000\text{万元}\cdot19\%\cdot\frac{243}{365}=126.5\text{万元}$ |
| 曾敲入后敲出 | 曾跌破$70\%\cdot S_0$，后续达到某一观察日的递降敲出线 | 按19%年化和实际持有天数结算 |
| 未敲出且未敲入 | 全程未触及敲入线，也未达到各观察日的敲出线 | $1000\text{万元}\cdot19\%\cdot2=380\text{万元}$ |
| 曾敲入且未敲出 | 曾跌破$70\%\cdot S_0$，到期$S_T=65\%\cdot S_0$ | $1000\text{万元}\cdot(65\%-100\%)=-350\text{万元}$ |

#### 9.9.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 预期标的即使不能快速上涨，也可能在后期反弹；希望随时间提高敲出机会 | 敲出线逐步降低，后期更容易敲出；若深跌敲入后仍未敲出，仍承担到期下跌风险 |
| 期权对手方 | 用递降敲出线缩短部分路径下的风险暴露期限 | 后期较低的敲出线会提高提前终止概率，票息通常相应低于同条件的固定高敲出线产品 |

#### 9.9.5 总结

敲出递降型雪球只改变各观察日的敲出线，敲入和到期结算逻辑与经典雪球相同。随着时间推移，敲出线逐步降低，标的无需回到初期的较高位置也可能敲出，因此更适合预期先震荡或回落、后续有温和反弹的路径。

### 9.10 降落伞雪球

#### 9.10.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 期权持有方买入降落伞雪球，期权对手方提供该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为24个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取20%，初始保证金为$G=N\cdot g$ |
| 初始价格与执行价 | $S_0$，$K=S_0$ |
| 约定票息 | $y$，示例取年化15% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 常规敲出线 | 除最后一个敲出观察日外，$H_{out}=103\%\cdot S_0$ |
| 最后敲出线 | 最后一个敲出观察日下调至$70\%\cdot S_0$，与示例敲入线相同 |
| 敲出触发条件 | 任一敲出观察日$S_t$达到对应敲出线 |
| 敲出结果 | 产品提前终止；最后观察日达到下调敲出线也视为敲出 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察 |
| 敲入线 | $H_{in}=70\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 若最后观察日仍未达到下调敲出线，按$S_T$相对$S_0$的跌幅结算 |

#### 9.10.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 常规提前敲出 | 非最后观察日$S_t\ge103\%\cdot S_0$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 最后观察日敲出 | 最后观察日$S_T\ge70\%\cdot S_0$，且此前未敲出 | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 全部非最后敲出观察日$S_t<103\%\cdot S_0$，曾敲入且最后观察日$S_T<70\%\cdot S_0$ | $N\cdot\min((S_T-S_0)/S_0,0)$ |

#### 9.10.3 示例

设$N=1000$万元，期限24个月，$y=15\%$，常规敲出线为$103\%\cdot S_0$，最后观察日敲出线和敲入线均为$70\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 常规提前敲出 | 第6个月观察日（第182天）$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot15\%\cdot\frac{182}{365}=74.8\text{万元}$ |
| 曾敲入但最后敲出 | 存续期内曾跌破70%，到期$S_T=75\%\cdot S_0$ | $1000\text{万元}\cdot15\%\cdot2=300\text{万元}$ |
| 未敲入且最后观察日敲出 | 到期$S_T=80\%\cdot S_0$，全程未敲入 | $300\text{万元}$ |
| 曾敲入且未敲出 | 曾跌破70%，到期$S_T=65\%\cdot S_0$ | $-350\text{万元}$ |

#### 9.10.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望降低“已敲入但到期仍无法敲出”的概率 | 最后观察日的低敲出线提高安全结束的机会；只有到期低于该低线时才保留敲入后的下跌损失 |
| 期权对手方 | 用最后一期下调敲出线改变到期附近的结算路径 | 最后一期敲出概率提高，需相应调整票息和障碍水平 |

#### 9.10.5 总结

降落伞雪球将最后一个敲出观察日的敲出线大幅下调至敲入线附近。这样，即使产品曾敲入，只要到期回到该水平或以上，仍可以敲出并取得票息。它降低的是临近到期的路径风险，而不是消除到期深跌时的损失。

### 9.11 增强型雪球

#### 9.11.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入增强型雪球产品，发行方卖出该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为24个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取20%，有追加保证金要求 |
| 约定票息/年化收益率 | $y$，示例取年化15% |
| 上涨参与率 | $a$，示例取50%，用于计算敲出时超过敲出线的增强收益 |
| 执行价 | $K = S_0$ |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出方向 | 向上敲出 |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出线 | $H_{out}$，示例取$103\%\cdot S_0$ |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，支付约定票息及超过敲出线部分的增强收益 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入方向 | 向下敲入 |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}$，示例取$70\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 若未敲出且曾敲入，到期按$S_T$与$S_0$的差额结算；若到期修复至$S_0$或以上，损失为0 |

#### 9.11.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日，使$S_t\ge H_{out}$ | $N\cdot\left[y\cdot\frac{\text{实际持有天数}}{365}+a\cdot\frac{S_t-H_{out}}{S_0}\right]$，产品提前终止 |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全部敲入观察节点$S_t>H_{in}$ | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 全部敲出观察日$S_t<H_{out}$，且曾有$S_t\le H_{in}$ | $N\cdot \min((S_T-S_0)/S_0,0)$ |

#### 9.11.3 示例

设标的为中证500，名义本金$N = 1000$万元，期限24个月，初始保证金比例$g = 20\%$，约定票息$y = 15\%$，上涨参与率$a = 50\%$，敲出线$H_{out} = 103\%\cdot S_0$，敲入线$H_{in} = 70\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入后提前敲出 | 第120天观察日$S_t=110\%\cdot S_0$ | $1000\text{万元}\cdot\left[15\%\cdot\frac{120}{365}+50\%\cdot(110\%-103\%)\right]=84.3\text{万元}$ |
| 曾敲入后提前敲出 | 存续期内曾跌破$70\%\cdot S_0$，第243天观察日$S_t=110\%\cdot S_0$ | $1000\text{万元}\cdot\left[15\%\cdot\frac{243}{365}+50\%\cdot(110\%-103\%)\right]=134.9\text{万元}$ |
| 未敲出且未敲入 | 全程未达到$103\%\cdot S_0$，也从未低于$70\%\cdot S_0$ | $1000\text{万元}\cdot15\%\cdot2=300\text{万元}$ |
| 曾敲入且到期未修复 | 存续期内曾跌破$70\%\cdot S_0$，到期$S_T=60\%\cdot S_0$ | $1000\text{万元}\cdot(60\%-100\%)=-400\text{万元}$ |

#### 9.11.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 在经典雪球基础上向投资者让渡部分敲出日上涨收益，并通过参与率、票息和障碍水平定价 | 标的大幅上涨并在较高位置敲出时，需要支付更高收益；标的大幅下跌且未敲出时，承担相应对冲风险 |
| 期权持有方 | 除获取固定票息外，也希望在标的上涨幅度较大时参与部分上涨收益 | 敲出时，敲出价格越高于敲出线，增强收益越高；未敲出且未敲入时获得固定票息；敲入后未敲出时仍承担到期下跌损失 |

#### 9.11.5 总结

增强型雪球在经典雪球的敲出、敲入和到期结算框架上，增加了敲出日超过敲出线部分的上涨参与收益。投资者不仅取得按持有期计算的票息，也能按参与率分享超出敲出线的涨幅。

增强收益只在敲出时产生，不能消除敲入后未敲出时的下跌风险。它适合预期标的有上涨空间、并可能在较高位置触发敲出的情形；若市场持续下跌并敲入，最终损失逻辑仍与经典雪球相同。

### 9.12 票息前置型（早利）雪球

#### 9.12.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 期权持有方买入票息前置型雪球，期权对手方提供该结构 |

| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}=85\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 敲入后结算 | 未敲出且曾敲入时，按$S_T$相对$S_0$的跌幅结算 |

#### 9.12.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 第一年提前敲出 | 第一年某个敲出观察日$S_t\ge H_{out}$ | $N\cdot y_1\cdot\frac{\text{实际持有天数}}{365}$ |
| 第二年提前敲出 | 第二年某个敲出观察日$S_t\ge H_{out}$ | $N\cdot y_2\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、未敲入 | 未发生敲出和敲入 | $N\cdot y_2\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 曾发生敲入但未敲出 | $N\cdot\min((S_T-S_0)/S_0,0)$ |

#### 9.12.3 示例

设$N=1000$万元，期限24个月，$y_1=25\%$，$y_2=5\%$，$H_{out}=100\%\cdot S_0$，$H_{in}=85\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第一年敲出 | 第4个月观察日（第120天）$S_t\ge100\%\cdot S_0$ | $1000\text{万元}\cdot25\%\cdot\frac{120}{365}=82.2\text{万元}$ |
| 第二年敲出 | 第22个月观察日（第672天）$S_t\ge100\%\cdot S_0$ | $1000\text{万元}\cdot5\%\cdot\frac{672}{365}=92.1\text{万元}$ |
| 未敲出且未敲入 | 全程未触及两条障碍线 | $1000\text{万元}\cdot5\%\cdot2=100\text{万元}$ |
| 曾敲入且未敲出 | 曾跌破$85\%\cdot S_0$，到期$S_T=80\%\cdot S_0$ | $1000\text{万元}\cdot(80\%-100\%)=-200\text{万元}$ |

#### 9.12.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 预期标的较可能在早期敲出，希望优先锁定较高票息 | 早期敲出收益更高；若未能早期敲出，后续票息明显降低，敲入下行风险仍然存在 |
| 期权对手方 | 将较多票息配置在早期，以匹配预期的提前终止概率 | 早期未敲出会延长产品存续期，但后续票息较低 |

#### 9.12.5 总结

票息前置型雪球不改变敲入后的下行风险，只改变不同时间段的票息。它把更高的票息放在前期，适合认为标的有较高概率在早期敲出的情形。若产品长期未敲出，持有方实际获得的票息会转入较低档位。

### 9.13 高保底雪球

#### 9.13.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 期权持有方买入高保底雪球，期权对手方提供该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为6个月 |
| 锁定期 | 前1个月不进行敲出观察，实际以合同约定为准 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取5%，初始保证金为$G=N\cdot g$ |
| 约定票息 | $y$，示例取年化15.5% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出观察日 | 锁定期结束后通常每月观察 |
| 敲出线 | $H_{out}=103\%\cdot S_0$ |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，支付约定票息 |

敲入与保底要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察 |
| 敲入线和保底水平 | $H_{in}=H_{floor}=95\%\cdot S_0$ |
| 敲入触发条件 | 任一敲入观察日$S_t\le H_{in}$ |
| 保底处理 | 未敲出且曾敲入时，到期最大亏损限制为名义本金的5% |

#### 9.13.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 任一敲出观察日$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全程未触及敲入线 | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入 | 全部敲出观察日$S_t<H_{out}$，且曾触及敲入线 | $N\cdot\max((S_T-S_0)/S_0,-5\%)$ |

#### 9.13.3 示例

设$N=1000$万元，期限6个月，$y=15.5\%$，$H_{out}=103\%\cdot S_0$，$H_{in}=H_{floor}=95\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 第4个月观察日（第120天）$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot15.5\%\cdot\frac{120}{365}=51.0\text{万元}$ |
| 未敲出且未敲入 | 全程未低于$95\%\cdot S_0$ | $1000\text{万元}\cdot15.5\%\cdot\frac{182}{365}=77.3\text{万元}$ |
| 曾敲入、到期跌3% | 曾跌破95%，到期$S_T=97\%\cdot S_0$ | $-30\text{万元}$ |
| 曾敲入、到期跌10% | 曾跌破95%，到期$S_T=90\%\cdot S_0$ | $-50\text{万元}$ |

#### 9.13.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望用较低初始保证金参与，并将到期最大损失限定在较小范围内 | 敲入线较高，容易触发；但一旦发生不利到期结果，亏损上限为保底水平对应的5% |
| 期权对手方 | 通过较高敲入线、较短期限和票息设置平衡有限损失承诺 | 保底压缩持有方尾部亏损，需在报价中反映相应成本 |

#### 9.13.5 总结

高保底雪球的核心是较高的保底水平，示例将最大亏损限制为5%。其代价是敲入线也较高，持有方更容易进入保底结算状态。它适合优先控制最大亏损、接受较高敲入概率的情形。

| 期限 | 自期初持有至到期时刻$T$，示例为24个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例取20%，初始保证金为$G=N\cdot g$ |
| 初始价格与执行价 | $S_0$，$K=S_0$ |
| 初始票息 | $y$，示例取年化7.3% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 初始敲出线 | $H_{out}=100\%\cdot S_0$ |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，按当时适用的敲出票息结算 |

敲入与重置要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}=80\%\cdot S_0$ |

| 重置处理 | 发生敲入后，在约定重置观察日将敲出线重置为较低水平；示例重置为$90\%\cdot S_0$，重置后票息以合同约定为准 |

#### 9.14.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 未敲入后提前敲出 | 未发生敲入，且某个敲出观察日$S_t\ge100\%\cdot S_0$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 曾敲入后重置敲出 | 曾发生敲入，重置后某个观察日$S_t\ge90\%\cdot S_0$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出且未敲入 | 全部敲出观察日未达敲出线，且未发生敲入 | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 曾敲入且未敲出 | 曾发生敲入，重置后仍未敲出 | $N\cdot\min((S_T-S_0)/S_0,0)$ |

#### 9.14.3 示例

设$N=1000$万元，期限24个月，$y=7.3\%$，初始敲出线为$100\%\cdot S_0$，敲入线为$80\%\cdot S_0$，敲入后敲出线重置为$90\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 未敲入后提前敲出 | 第4个月观察日（第120天）$S_t\ge100\%\cdot S_0$ | $1000\text{万元}\cdot7.3\%\cdot\frac{120}{365}=24.0\text{万元}$ |
| 曾敲入后重置敲出 | 第7个月曾跌破$80\%\cdot S_0$，第8个月（第243天）$S_t\ge90\%\cdot S_0$ | $1000\text{万元}\cdot7.3\%\cdot\frac{243}{365}=48.6\text{万元}$ |
| 未敲出且未敲入 | 全程未敲出也未敲入 | $1000\text{万元}\cdot7.3\%\cdot2=146\text{万元}$ |
| 曾敲入且未敲出 | 曾跌破$80\%\cdot S_0$，到期$S_T=85\%\cdot S_0$ | $1000\text{万元}\cdot(85\%-100\%)=-150\text{万元}$ |

#### 9.14.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 担心敲入后标的难以恢复至原敲出线，希望用较低的重置敲出线增加提前结束的机会 | 敲入后若标的反弹至重置敲出线，可较经典雪球更早结束；未能重置敲出时仍承担到期下跌风险 |
| 期权对手方 | 通过重置敲出线和票息重新配置敲入后的路径风险 | 重置提高产品结束概率，也会改变敲入后持续风险的期限和对冲方式 |

#### 9.14.5 总结

救生艇雪球在敲入后降低敲出线，使产品更容易在反弹时提前结束。它解决的是“已经敲入后仍长期无法敲出”的路径风险，而不是取消敲入后的下行损失。重置敲出线、重置时点和重置票息是该结构的核心报价要素。

| 期权对手方 | 以特定避险观察日和避险线限制部分不利路径的继续存续 | 避险提前结束会改变产品期限和票息支付时点，需与正常敲出、敲入共同管理 |

#### 9.15.5 总结

### 9.16 期权费型小雪球（无敲入）

#### 9.16.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 期权持有方买入期权费型小雪球，期权对手方提供该结构 |
| 标的资产 | 单一指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为12个月 |
| 名义本金 | $N$，示例为1亿元 |
| 期权费率 | $q$，按年化计，示例取1% |

| 敲出票息 | $y_{out}$，示例取年化1.98% |
| 未敲出到期票息 | $y_{maturity}=0$ |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出线 | $H_{out}=103\%\cdot S_0$ |
| 敲出触发条件 | 任一敲出观察日$S_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，支付敲出票息；净损益需扣除期权费 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入设置 | 无敲入线、无敲入事件 |

#### 9.16.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日$S_t\ge H_{out}$ | $N\cdot(y_{out}-q)\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出 | 全部敲出观察日$S_t<H_{out}$ | $-N\cdot q\cdot\frac{\text{总期限天数}}{365}$ |

#### 9.16.3 示例

设$N=1$亿元，期限12个月，期权费率$q=1\%$，敲出票息$y_{out}=1.98\%$，敲出线$H_{out}=103\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 第4个月观察日（第120天）$S_t\ge103\%\cdot S_0$ | $1\text{亿元}\cdot(1.98\%-1\%)\cdot\frac{120}{365}=32.2\text{万元}$ |
| 未敲出 | 全部观察日均低于敲出线 | $-1\text{亿元}\cdot1\%=-100\text{万元}$ |

#### 9.16.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望以较低初始资金参与敲出机会，且明确将最大亏损限定为期权费 | 敲出时获得扣除期权费后的净收益；未敲出时损失全部期权费 |
| 期权对手方 | 收取期权费并承担敲出时的收益支付责任 | 标的上涨并敲出时需支付约定收益；未敲出时保留期权费 |

#### 9.16.5 总结

期权费型小雪球不设置敲入，持有方不承担标的下跌的线性损失，但也不返还期权费。它只有敲出和未敲出两种核心结果：敲出获得扣除期权费后的收益，未敲出损失期权费。期权费、名义本金和保证金必须分别列示。

| 到期结算 | 未敲出时返还本金，并按合同支付未敲出到期票息 |

#### 9.17.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日，使$S_t\ge H_{out}$ | $N\cdot y_{out}\cdot\frac{\text{实际持有天数}}{365}$，产品提前终止 |
| 未敲出 | 全部敲出观察日$S_t<H_{out}$ | $N\cdot y_{maturity}\cdot\frac{\text{总期限天数}}{365}$ |

#### 9.17.3 示例

设标的为中证1000，名义本金$N = 1$亿元，期限12个月，初始保证金比例$g = 100\%$。产品一的敲出线$H_{out} = 100\%\cdot S_0$，敲出票息$y_{out} = 4.8\%$，未敲出到期票息$y_{maturity} = 0.55\%$；产品二的敲出线$H_{out} = 103\%\cdot S_0$，敲出票息$y_{out} = 6.5\%$，未敲出到期票息$y_{maturity} = 0.55\%$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 产品一提前敲出 | 第60天观察日$S_t\ge100\%\cdot S_0$ | $1\text{亿元}\cdot4.8\%\cdot\frac{60}{365}=78.9\text{万元}$ |
| 产品二提前敲出 | 第120天观察日$S_t\ge103\%\cdot S_0$ | $1\text{亿元}\cdot6.5\%\cdot\frac{120}{365}=213.7\text{万元}$ |
| 未敲出 | 全部观察日均低于对应敲出线 | $1\text{亿元}\cdot0.55\%=55\text{万元}$ |

#### 9.17.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 通过设置敲出线和两档票息，取得标的上涨时提前终止收益的选择权 | 标的未达到敲出线时，需要支付较低的到期票息并维持产品至到期；标的较早上涨至敲出线时，产品提前结束 |
| 期权持有方 | 以全额资金换取有条件的固定收益，不愿承担敲入后的标的下跌损失或追加保证金压力 | 敲出时按较高的敲出票息结算；未敲出时收益降为较低的到期票息，但不因标的下跌承担本金损失 |

#### 9.17.5 总结

全保证金型小雪球不设置敲入，因此没有经典雪球在敲入后、未敲出时承担标的下跌损失的情形。代价是初始保证金占用为名义本金的100%，且未敲出时的到期票息通常较低。

它的核心判断只有两种：标的在观察日达到敲出线则提前按敲出票息结算；否则持有到期并取得较低的到期票息。敲出线越高，通常敲出票息越高，但未敲出概率也越大。

### 9.18 Worst-Of雪球

#### 9.18.1 要素

基础要素：

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入多标的$Worst$-Of雪球产品，发行方卖出该结构 |
| 标的资产 | 两个或多个指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻$T$，示例为12个月 |
| 名义本金 | $N$，示例为1000万元 |
| 初始保证金比例 | $g$，示例为30% |
| 初始价格 | 每个标的的期初价格分别记为$S_{1,0}$、$S_{2,0}$、…、$S_{n,0}$ |
| 相对价格 | 第$i$个标的在$t$时刻的相对价格为$R_{i,t} = S_{i,t}/S_{i,0}$ |
| 多资产表现/最差表现 | $P_t = \min(R_{1,t},R_{2,t},\ldots,R_{n,t})$，即所有标的里表现最差的那个 |
| 约定票息/年化收益率 | $y$，示例取年化22.5% |

敲出要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲出方向 | 向上敲出 |
| 敲出观察对象 | 每个敲出观察节点看$P_t$ |
| 敲出观察日 | 通常为每月观察，实际以合同约定日期为准 |
| 敲出线 | $H_{out}$，示例取103% |
| 敲出触发条件 | 任一敲出观察日$P_t\ge H_{out}$ |
| 敲出结果 | 产品提前终止，投资者拿到截至敲出日的约定票息 |
| 敲出票息 | 票息通常按$N\cdot y\cdot\frac{\text{实际持有天数}}{365}$计算 |

敲入要素：

| 要素 | 具体说明 |
| --- | --- |
| 敲入方向 | 向下敲入 |
| 敲入观察对象 | 每个敲入观察节点看$P_t$ |
| 敲入观察日 | 通常为每日观察，实际以合同约定日期为准 |
| 敲入线 | $H_{in}$，示例取70% |
| 敲入触发条件 | 任一敲入观察日$P_t\le H_{in}$ |
| 敲入结果 | 不会终止产品，但会改变到期结算；若到期$P_T<100\%$，投资者承担最差标的跌幅损失$N\cdot (1-P_T)$ |
| 敲入后修复 | 若到期$P_T\ge 100\%$，通常本金不亏；是否仍支付票息以合同条款为准 |

#### 9.18.2 损益结构

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 存在某个敲出观察日，使该日$P_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$，产品提前终止 |
| 未敲出、未敲入 | 全部敲出观察日$P_t<H_{out}$，且全部敲入观察节点$P_t>H_{in}$ | $N\cdot y\cdot\frac{\text{总期限天数}}{365}$ |
| 未敲出、曾敲入、到期修复 | 全部敲出观察日$P_t<H_{out}$，曾有$P_t\le H_{in}$，且$P_T\ge 100\%$ | 通常为0；若合同约定修复给息，则按合同给付 |
| 未敲出、曾敲入、到期未修复 | 全部敲出观察日$P_t<H_{out}$，曾有$P_t\le H_{in}$，且$P_T<100\%$ | $N\cdot (P_T-100\%)$，为负值；等价于损失$N\cdot (1-P_T)$ |

#### 9.18.3 示例

设标的为两个相关性较高的个股，名义本金$N = 1000$万元，初始保证金比例$g = 30\%$，初始保证金为300万元，期限12个月，约定票息$y = 22.5\%$，敲出线$H_{out} = 103\%$，敲入线$H_{in} = 70\%$，到期时以两个标的中表现较差者结算。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 第4个月观察日，两个标的分别为105%和104%，$P_t = 104\%\ge 103\%$ | $N\cdot 22.5\%\cdot 4/12 = 75$万元 |
| 未敲出且未敲入 | 全程$P_t$从未低于70%，且未在观察日达到103% | $N\cdot 22.5\% = 225$万元 |
| 曾敲入但到期修复 | 存续期内$P_t$曾跌至68%，到期$P_T$回到101% | 通常为0或约定票息，以合同为准 |
| 曾敲入且到期未修复 | 存续期内$P_t$曾跌至68%，到期$P_T$为80% | $N\cdot (80\%-100\%) = -200$万元 |

#### 9.18.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 收取投资者承担下行风险的补偿，并在多标的相关性、波动率和路径分布中管理风险 | 发行方收益与投资者相反，主要风险来自最差标的大幅下跌及相关性变化 |
| 期权持有方 | 判断一篮子标的整体不会大幅下跌，且至少不会出现某一标的显著拖累组合；希望用承担下行尾部风险换取较高票息 | 最有利情形是较早敲出并获得按持有期计算的票息；次优情形是未敲出且未敲入，持有至到期获得票息；不利情形是曾敲入且到期最差标的未修复，投资者承担最差标的跌幅 |

#### 9.18.5 总结

Worst-Of雪球挂钩两个或两个以上基础资产，所有收益、敲出和敲入判断均由表现最差的标的决定。向上敲出时，只有最差标的也达到敲出线，产品才会提前结束，因此挂钩标的越多，敲出条件越苛刻；向下敲入时，只要一只标的跌至敲入线即可触发，因此单一标的大幅下跌就会影响整笔产品。较高票息正是对这部分更严格敲出条件和更集中下行风险的补偿。

损益按路径判断：先看是否敲出，敲出后产品提前终止，投资者取得截至敲出日的约定票息；未敲出时再看是否曾敲入，未敲入则持有至到期取得约定票息；曾敲入后，若到期最差标的回到期初价格或以上，通常不发生本金损失，票息是否支付以合同为准；若到期仍低于期初价格，则按最差标的的跌幅承担损失。

因此，该结构适合预期各标的走势稳定、相关性较高且不会出现单一标的明显跑输的情形。即使多数标的表现良好，只要一只标的成为明显弱者，仍可能导致敲入并决定最终损失。

### 9.19 凤凰式结构

#### 9.19.1 要素

凤凰式结构在自动赎回框架中加入按期派息机制。以下为非保本、非记忆式派息的常见示例；实际合同可约定记忆派息、降敲出线或不同的敲入观察方式。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入凤凰式结构，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，自期初持有至到期时刻$T$ |
| 名义本金 | $N$，示例取1000万元 |
| 月度票息 | 每个派息观察日满足条件时支付$c$，示例$c = 1\%$ |
| 派息线 | $H_c$，示例取$80\%\cdot S_0$；观察日$S_t\ge H_c$时当期派息 |
| 敲出线 | $H_{out}$，示例取$103\%\cdot S_0$；月度观察日触发后产品提前终止 |
| 敲入线 | $H_{in}$，示例取$70\%\cdot S_0$；通常每日观察 |
| 执行价 | $K=S_0$；发生敲入且未敲出时，用于到期下跌结算 |

#### 9.19.2 损益结构

设存续期内已满足派息条件的观察次数为$n_c$，累计票息为$C=N\cdot c\cdot n_c$。判断顺序为先看敲出，再看敲入，最后看敲入后的到期修复。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个敲出观察日$S_t\ge H_{out}$ | 已累计票息$C$，产品提前终止 |
| 未敲出、未敲入 | 未触发敲出，且全程$S_t>H_{in}$ | $C$ |
| 未敲出、曾敲入、到期修复 | 未触发敲出，曾有$S_t\le H_{in}$，且$S_T\ge K$ | $C$ |
| 未敲出、曾敲入、到期未修复 | 未触发敲出，曾有$S_t\le H_{in}$，且$S_T<K$ | $C+N\cdot(S_T/K-1)$ |

凤凰式结构的票息按观察期逐次锁定，因此敲入后的到期跌幅可被已累计票息部分抵消；但票息不是本金保障，标的大幅下跌时净损益仍可能为负。

#### 9.19.3 示例

设$N=1000$万元，期限12个月，$c=1\%$，$H_c=80\%\cdot S_0$，$H_{out}=103\%\cdot S_0$，$H_{in}=70\%\cdot S_0$，$K=S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第3个月提前敲出 | 前3个派息观察日均在派息线以上，第3个月$S_t=104\%\cdot S_0$ | $1000\text{万元}\cdot1\%\cdot3=30\text{万元}$ |
| 未敲出且未敲入 | 12个派息观察日中10次在派息线以上 | $1000\text{万元}\cdot1\%\cdot10=100\text{万元}$ |
| 曾敲入后修复 | 曾跌至$68\%\cdot S_0$，到期$S_T=101\%\cdot S_0$，累计8次派息 | $80\text{万元}$ |
| 曾敲入且到期未修复 | 曾跌至$68\%\cdot S_0$，到期$S_T=65\%\cdot S_0$，累计10次派息 | $100-350=-250\text{万元}$ |

#### 9.19.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 预期标的大部分月份可维持在派息线以上，希望通过按期派息缓冲尾部风险 | 价格稳定或温和上涨时可连续积累票息；敲入后若到期未修复，已得票息只能部分抵消本金损失 |
| 期权对手方 | 通过票息、派息线、敲入线和敲出线报价并动态对冲 | 标的长期处于派息线以上时需持续支付票息；大幅下跌后承担敲入相关的对冲风险 |

#### 9.19.5 总结

凤凰式结构的核心是“按期派息、敲入承担下跌、票息先行锁定”。与经典雪球相比，票息不完全取决于最终是否敲出，因而在未敲出或已敲入路径下能够形成收益缓冲。其代价通常是同等障碍条件下的票息低于经典雪球，且在敲入后标的深跌时仍承担执行价以下的损失。

### 9.20 保底凤凰式结构

#### 9.20.1 要素

保底凤凰式结构在凤凰式结构的基础上设置到期本金损失上限。以下示例中的“保底”指非违约情形下的损失下限，不等同发行方信用意义上的本金保障。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入保底凤凰式结构，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，自期初持有至到期时刻$T$ |
| 名义本金 | $N$，示例取1000万元 |
| 月度票息与派息线 | 每期票息$c$，派息线$H_c$；满足$S_t\ge H_c$时锁定当期票息 |
| 敲出与敲入 | 月度敲出线$H_{out}$、每日敲入线$H_{in}$，均以合同约定为准 |
| 执行价 | $K=S_0$，用于敲入后到期损益计算 |
| 保底水平 | $F$，示例取$85\%$；敲入后未敲出时，到期本金损失不超过$N\cdot(1-F)$ |

#### 9.20.2 损益结构

设累计票息为$C=N\cdot c\cdot n_c$。若发生敲入且未敲出，到期价格低于执行价时，损失按保底水平截断；其余路径与凤凰式结构一致。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个敲出观察日$S_t\ge H_{out}$ | $C$ |
| 未敲出、未敲入 | 未触发敲出，且全程$S_t>H_{in}$ | $C$ |
| 未敲出、曾敲入、到期修复 | 未触发敲出，曾敲入且$S_T\ge K$ | $C$ |
| 未敲出、曾敲入、到期未修复 | 未触发敲出，曾敲入且$S_T<K$ | $C+N\cdot\max(S_T/K-1,F-1)$ |

当$S_T/K<F$时，本金部分固定为$-N\cdot(1-F)$；保底成本通常通过降低票息、提高派息线或调整其他障碍条件体现。

#### 9.20.3 示例

设$N=1000$万元，期限12个月，$c=0.75\%$，$H_c=80\%\cdot S_0$，$H_{out}=103\%\cdot S_0$，$H_{in}=70\%\cdot S_0$，$K=S_0$，$F=85\%$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第4个月提前敲出 | 前4次均满足派息条件，第4个月触及敲出线 | $1000\text{万元}\cdot0.75\%\cdot4=30\text{万元}$ |
| 未敲出且未敲入 | 12次中9次满足派息条件 | $67.5\text{万元}$ |
| 曾敲入、到期跌10% | 曾跌破敲入线，到期$S_T=90\%\cdot S_0$，累计8次派息 | $60-100=-40\text{万元}$ |
| 曾敲入、到期跌40% | 曾跌破敲入线，到期$S_T=60\%\cdot S_0$，累计8次派息 | $60-150=-90\text{万元}$ |

#### 9.20.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望保留凤凰的按期派息特征，同时明确限制极端下跌时的本金损失 | 正常路径获得累计票息；敲入后深跌时，损失由$F$锁定，但票息通常低于普通凤凰 |
| 期权对手方 | 以显式下行保护换取较低票息或更严格的派息、障碍条件 | 深跌时承担保底与对冲成本，需在条款中限制尾部风险 |

#### 9.20.5 总结

保底凤凰将普通凤凰的“票息缓冲”进一步改为“票息缓冲加本金损失上限”。它改善的是敲入后深度下跌的尾部损失，不改变派息是否触发和提前敲出的路径依赖。比较产品时，应同时看保底水平、票息是否记忆、派息线和敲出线，不能只看名义票息。

### 9.21 FCN（无敲入要素）

#### 9.21.1 要素

FCN为Fixed Coupon Note，通常指固定票息、可自动提前赎回的收益增强结构。无敲入要素FCN不以存续期内的敲入事件决定下行结算；若到期低于执行价，投资者按约定接收标的或承担等价损失。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入无敲入要素FCN，发行方卖出该结构 |
| 标的与期限 | 单一股票、指数或ETF等标的，示例期限12个月 |
| 名义本金 | $N$，示例取1000万元 |
| 固定票息 | 每个存续期观察期支付$c$，示例$c=1.2\%$；可按月支付或到期累计 |
| 敲出线 | $H_{out}$，示例取$103\%\cdot S_0$；月度观察日达到该水平时提前赎回 |
| 执行价 | $K$，示例取$90\%\cdot S_0$；到期低于$K$时产生交割或等价现金损失 |
| 敲入设置 | 无每日或连续敲入观察，路径中的最低价格不直接改变到期结算 |

#### 9.21.2 损益结构

设产品终止前经历$m$个计息期，累计固定票息为$C=N\cdot c\cdot m$。未提前敲出时，只看到期价格与执行价的关系。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个敲出观察日$S_t\ge H_{out}$ | $C$ |
| 未敲出、到期不低于执行价 | 全部敲出观察日未达$H_{out}$，且$S_T\ge K$ | $C$ |
| 未敲出、到期低于执行价 | 全部敲出观察日未达$H_{out}$，且$S_T<K$ | $C+N\cdot(S_T/K-1)$ |

到期交割的经济含义是以$K$取得数量为$N/K$的标的，随后按$S_T$计价。固定票息可缓冲损失，但无法限制标的大幅下跌造成的损失。

#### 9.21.3 示例

设$N=1000$万元，期限12个月，$c=1.2\%$，$H_{out}=103\%\cdot S_0$，$K=90\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第3个月提前敲出 | 第3个月观察日$S_t=104\%\cdot S_0$ | $1000\text{万元}\cdot1.2\%\cdot3=36\text{万元}$ |
| 未敲出、到期高于执行价 | 12个月均未敲出，到期$S_T=95\%\cdot S_0$ | $1000\text{万元}\cdot1.2\%\cdot12=144\text{万元}$ |
| 未敲出、到期低于执行价 | 12个月均未敲出，到期$S_T=75\%\cdot S_0$ | $144+1000\cdot(75\%/90\%-1)=-22.7\text{万元}$ |

#### 9.21.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 预期标的不会在到期时显著跌破执行价，愿意用承担到期接收标的的义务换取固定票息 | 横盘、温和上涨或温和下跌时获取票息；到期深跌时按执行价承受损失 |
| 期权对手方 | 向投资者出售固定票息，并获得到期卖出看跌期权的经济敞口 | 标的深跌时需处理交割与对冲；提前敲出时停止后续票息责任 |

#### 9.21.5 总结

无敲入要素FCN的下行风险是欧式的：不关心存续期内是否曾跌破某条线，只在未敲出时比较到期价格与执行价。它用较低的执行价提供一段到期保护，但并非保本；到期跌破执行价时，固定票息与标的损失共同决定最终净收益。

### 9.22 FCN（有敲入要素）

#### 9.22.1 要素

有敲入要素FCN在固定票息和自动提前赎回之外，增加了路径敲入条件。只有发生敲入且产品未提前赎回时，执行价以下的到期损失才被激活。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入有敲入要素FCN，发行方卖出该结构 |
| 标的与期限 | 单一股票、指数或ETF等标的，示例期限12个月 |
| 名义本金 | $N$，示例取1000万元 |
| 固定票息 | 每期$c$，示例$c=1.35\%$；支付频率和记忆规则以合同为准 |
| 敲出线 | $H_{out}$，示例取$103\%\cdot S_0$，月度观察 |
| 敲入线 | $H_{in}$，示例取$70\%\cdot S_0$，通常每日观察 |
| 执行价 | $K$，示例取$90\%\cdot S_0$；用于敲入后的到期结算 |

#### 9.22.2 损益结构

设累计固定票息为$C=N\cdot c\cdot m$。先判断是否敲出；未敲出时，再判断是否发生敲入，最后比较到期价格与执行价。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个敲出观察日$S_t\ge H_{out}$ | $C$ |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全程$S_t>H_{in}$ | $C$ |
| 未敲出、曾敲入、到期不低于执行价 | 全部敲出观察日$S_t<H_{out}$，曾敲入且$S_T\ge K$ | $C$ |
| 未敲出、曾敲入、到期低于执行价 | 全部敲出观察日$S_t<H_{out}$，曾敲入且$S_T<K$ | $C+N\cdot(S_T/K-1)$ |

与无敲入要素FCN相比，若标的曾短暂低于执行价但未触及$H_{in}$，即使到期低于$K$，本示例下也不触发执行价以下的交割损失；具体观察方式必须以合同为准。

#### 9.22.3 示例

设$N=1000$万元，期限12个月，$c=1.35\%$，$H_{out}=103\%\cdot S_0$，$H_{in}=70\%\cdot S_0$，$K=90\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第4个月提前敲出 | 第4个月$S_t=104\%\cdot S_0$ | $1000\text{万元}\cdot1.35\%\cdot4=54\text{万元}$ |
| 未敲出且未敲入 | 存续期最低价为$72\%\cdot S_0$，到期$S_T=82\%\cdot S_0$ | $162\text{万元}$ |
| 曾敲入但到期高于执行价 | 曾跌至$68\%\cdot S_0$，到期$S_T=95\%\cdot S_0$ | $162\text{万元}$ |
| 曾敲入且到期低于执行价 | 曾跌至$68\%\cdot S_0$，到期$S_T=75\%\cdot S_0$ | $162+1000\cdot(75\%/90\%-1)=-4.7\text{万元}$ |

#### 9.22.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 预期标的大部分时间不会跌破敲入线，愿意承担触及后且到期低于执行价的损失 | 未敲入时固定票息与到期价格脱钩；敲入后未修复时转化为执行价交割风险 |
| 期权对手方 | 利用路径障碍设计调整票息与下行风险的触发概率 | 敲入频率、标的跳空和到期价格共同决定对冲成本 |

#### 9.22.5 总结

有敲入要素FCN把普通FCN的到期下行风险改为“敲入且到期低于执行价”才发生。敲入线带来一层路径保护，但一旦触发，产品仍暴露于执行价以下的到期损失。比较两类FCN时，应区分执行价、敲入线和票息是否在敲入后继续支付。

### 9.23 保底FCN（有敲入要素）

#### 9.23.1 要素

保底FCN在有敲入要素FCN的基础上，对敲入后未敲出的到期损失设置上限。保底可以是本金保底、损失上限或部分对冲安排，以下以本金保底水平$F$为例。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入保底FCN，发行方卖出该结构 |
| 标的与期限 | 单一股票、指数或ETF等标的，示例期限12个月 |
| 名义本金 | $N$，示例取1000万元 |
| 固定票息 | 每期$c$，示例$c=0.9\%$ |
| 敲出与敲入 | 月度敲出线$H_{out}$、每日敲入线$H_{in}$ |
| 执行价 | $K$，示例取$90\%\cdot S_0$ |
| 本金保底水平 | $F$，示例取$85\%$；敲入后最差的本金部分损失为$15\%$ |

#### 9.23.2 损益结构

设累计固定票息为$C=N\cdot c\cdot m$。未敲出且曾敲入时，到期的执行价损失先计算，再与保底水平比较并取较高者。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个敲出观察日$S_t\ge H_{out}$ | $C$ |
| 未敲出、未敲入 | 全部敲出观察日$S_t<H_{out}$，且全程$S_t>H_{in}$ | $C$ |
| 未敲出、曾敲入、到期不低于执行价 | 全部敲出观察日$S_t<H_{out}$，曾敲入且$S_T\ge K$ | $C$ |
| 未敲出、曾敲入、到期低于执行价 | 全部敲出观察日$S_t<H_{out}$，曾敲入且$S_T<K$ | $C+N\cdot\max(S_T/K-1,F-1)$ |

当$S_T/K<F$时，本金部分的损失被限制为$N\cdot(F-1)$。保底水平越高，通常意味着固定票息越低、敲入线越低或需要更高的资金占用。

#### 9.23.3 示例

设$N=1000$万元，期限12个月，$c=0.9\%$，$H_{out}=103\%\cdot S_0$，$H_{in}=70\%\cdot S_0$，$K=90\%\cdot S_0$，$F=85\%$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第5个月提前敲出 | 第5个月观察日触及敲出线 | $1000\text{万元}\cdot0.9\%\cdot5=45\text{万元}$ |
| 未敲出且未敲入 | 12个月未触及敲入线 | $108\text{万元}$ |
| 曾敲入、到期跌10% | 曾跌破敲入线，到期$S_T=90\%\cdot S_0=K$ | $108\text{万元}$ |
| 曾敲入、到期跌40% | 曾跌破敲入线，到期$S_T=60\%\cdot S_0$ | $108-150=-42\text{万元}$ |

#### 9.23.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望获得固定票息和敲入条件带来的路径保护，同时限定极端跌幅损失 | 正常路径获得票息；发生深度敲入且未修复时，损失封顶于保底水平 |
| 期权对手方 | 用保底承诺置换较低票息、较严格障碍或更高资金占用 | 深跌时承担额外保护成本，需关注跳空和流动性风险 |

#### 9.23.5 总结

保底FCN同时包含固定票息、自动赎回、敲入触发和损失上限四层机制。其风险并未消失，而是从无限制的执行价以下损失变为可量化的最大损失，并以更低的收益或更严格的条款作为交换。保底水平须与执行价区分：前者限制最差损失，后者决定一般的到期交割起点。

### 9.24 DCN

#### 9.24.1 要素

本库将DCN定义为按离散观察结果派发条件票息、并可在达到止盈线时自动赎回的结构。缩写的市场含义并不完全统一，以下按`一页通图片.pdf`中的无敲入、到期返还本金版本描述；支付频率、记忆规则和止盈线递降安排以具体合同为准。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入DCN，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，示例期限12个月 |
| 名义本金 | $N$，示例取1000万元 |
| 月度数字票息 | 每个计息观察日满足条件时支付$c$，示例$c=1\%$ |
| 计息线 | $H_c$，示例取$80\%\cdot S_0$；观察日$S_t\ge H_c$时当期计息 |
| 止盈线 | $H_{out,t}$，示例前11个月为$103\%\cdot S_0$、最后一个观察日为$75\%\cdot S_0$ |
| 自动赎回 | 任一止盈观察日$S_t\ge H_{out,t}$时，返还本金并支付已累计票息 |
| 敲入设置 | 无敲入线；本示例中未止盈到期亦返还本金，标的下跌只影响已计息期数 |

#### 9.24.2 损益结构

设满足计息条件的观察次数为$n_c$，累计票息为$C=N\cdot c\cdot n_c$。终止结算与单期计息分列如下：先判断是否止盈；未止盈时再按当期是否满足计息线累计票息。不同合同对止盈当期是否计息的处理可能不同，本示例将其计入累计次数。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前止盈 | 某个止盈观察日$S_t\ge H_{out,t}$ | $C$，并返还本金 |
| 到期未止盈 | 全部止盈观察日未触发 | $C$，并返还本金 |

| 单期状态 | 判断条件 | 对累计票息的影响 |
| --- | --- | --- |
| 未止盈、满足计息线 | 未触发止盈且$S_t\ge H_c$ | 当期增加$N\cdot c$ |
| 未止盈、未满足计息线 | 未触发止盈且$S_t<H_c$ | 当期不计息 |

该版本不因标的价格低于某条敲入线而承担线性本金损失，风险主要体现为未达到计息线导致票息不足，以及发行方信用与流动性风险。

#### 9.24.3 示例

设$N=1000$万元，期限12个月，$c=1\%$，$H_c=80\%\cdot S_0$，前11个月止盈线为$103\%\cdot S_0$，最后一个观察日止盈线为$75\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第4个月提前止盈 | 前4个观察日均高于计息线，第4个月$S_t=104\%\cdot S_0$ | $1000\text{万元}\cdot1\%\cdot4=40\text{万元}$ |
| 到期止盈 | 前11个月均未达止盈线，12个观察日中9次高于计息线，最后一日$S_T=78\%\cdot S_0$ | $90\text{万元}$ |
| 到期未止盈 | 12个观察日中3次高于计息线，最终仍低于最后止盈线 | $30\text{万元}$ |
| 全程未满足计息 | 每次观察日均低于计息线，且未止盈 | $0$ |

#### 9.24.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望降低路径敲入和本金线性损失风险，接受票息取决于离散观察结果 | 标的在计息线以上的月份越多，累计票息越高；长期低于计息线时收益很低或为零 |
| 期权对手方 | 通过计息线、止盈线和票息水平管理数字型支付与提前终止风险 | 市场长期横盘或温和上涨时支付更多票息；止盈发生后停止后续支付义务 |

#### 9.24.5 总结

DCN把自动赎回和数字型计息结合起来：价格达到计息线才获得当期票息，达到止盈线则提前结束。它不宜被理解为固定收益或保本产品，虽然本示例没有敲入后的线性损失，但仍存在票息不达预期、提前终止再投资和发行方信用等风险。

### 9.25 保底DCN

#### 9.25.1 要素

保底DCN在DCN的数字型条件票息之外设置每期最低票息。以下示例中“保底”指票息下限，不代表对发行方信用风险或全部收益作出保证。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入保底DCN，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，示例期限12个月 |
| 名义本金 | $N$，示例取1000万元 |
| 保底票息 | 每个计息期无条件支付$c_g$，示例$c_g=0.25\%$ |
| 增强票息 | 观察日$S_t\ge H_c$时额外支付$c_e$，示例$c_e=0.65\%$ |
| 计息线 | $H_c$，示例取$80\%\cdot S_0$ |
| 止盈线 | $H_{out,t}$，月度观察；触发后返还本金并停止后续计息 |
| 敲入设置 | 无敲入线；本示例中未止盈到期返还本金 |

#### 9.25.2 损益结构

若产品存续$m$个计息期，其中$n_c$次满足计息线，则累计票息为$C=N\cdot(c_g\cdot m+c_e\cdot n_c)$。终止结算与单期计息分列如下；保底票息保证每个已存续计息期至少取得$c_g$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前止盈 | 某个止盈观察日$S_t\ge H_{out,t}$ | $N\cdot(c_g\cdot m+c_e\cdot n_c)$，并返还本金 |
| 到期未止盈 | 全部止盈观察日未触发 | $C$，并返还本金 |

| 单期状态 | 判断条件 | 当期票息 |
| --- | --- | --- |
| 未止盈、满足计息线 | 未触发止盈且$S_t\ge H_c$ | $N\cdot(c_g+c_e)$ |
| 未止盈、未满足计息线 | 未触发止盈且$S_t<H_c$ | $N\cdot c_g$ |

与普通DCN相比，保底票息压低了收益的下限，同时通常降低了条件票息或提高了止盈、计息条件的严格程度。

#### 9.25.3 示例

设$N=1000$万元，期限12个月，$c_g=0.25\%$，$c_e=0.65\%$，$H_c=80\%\cdot S_0$，月度止盈线为$103\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第4个月提前止盈 | 4次均满足计息线，第4个月触及止盈线 | $1000\text{万元}\cdot(0.25\%+0.65\%)\cdot4=36\text{万元}$ |
| 到期未止盈、9次满足计息 | 12个观察日中9次在计息线以上 | $1000\text{万元}\cdot(0.25\%\cdot12+0.65\%\cdot9)=88.5\text{万元}$ |
| 到期未止盈、全程不满足计息 | 12次均低于计息线 | $1000\text{万元}\cdot0.25\%\cdot12=30\text{万元}$ |

#### 9.25.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望保留DCN的本金返还和止盈机制，同时降低长期低于计息线时的收益不确定性 | 每期至少获得保底票息；价格高于计息线时取得更高票息；通常接受较低的最高票息 |
| 期权对手方 | 通过拆分保底票息与条件票息控制支付下限和上行支付成本 | 标的长期低迷时仍需支付保底票息，需以较低的增强票息或更严格条款平衡成本 |

#### 9.25.5 总结

保底DCN将普通DCN的全条件票息拆为“无条件保底部分加条件增强部分”。它改善了低位震荡期间的票息下限，但并不消除自动赎回、再投资和发行方信用风险。评估时应比较总票息上限、保底票息、计息线和止盈线，而非只比较宣传年化收益。

### 9.26 触发器

#### 9.26.1 要素

触发器结构在达到敲出条件时支付预先约定的固定绝对收益，而非按实际持有天数折算票息。由于越早触发，隐含年化收益越高，常用于表达对短期上涨或快速反弹的判断。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入触发器结构，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，示例期限12个月 |
| 名义本金 | $N$，示例取1000万元 |
| 触发收益 | $q$，一旦敲出即支付固定比例，示例$q=12\%$ |
| 敲出线 | $H_{out}$，示例取$103\%\cdot S_0$，月度观察 |
| 敲入线与执行价 | $H_{in}=70\%\cdot S_0$，通常每日观察；$K=S_0$ |
| 未触发到期票息 | $y_T$，示例取$4\%$；未敲入且未触发时的到期收益 |

#### 9.26.2 损益结构

判断顺序为先看是否触发敲出；一旦触发，不论发生在第几个观察日，均取得固定收益$N\cdot q$。未触发时再判断敲入与到期价格。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 触发提前赎回 | 某个观察日$S_t\ge H_{out}$ | $N\cdot q$ |
| 未触发、未敲入 | 全部观察日未达$H_{out}$，且全程$S_t>H_{in}$ | $N\cdot y_T$ |
| 未触发、曾敲入、到期修复 | 全部观察日未达$H_{out}$，曾敲入且$S_T\ge K$ | $0$或合同约定的到期票息 |
| 未触发、曾敲入、到期未修复 | 全部观察日未达$H_{out}$，曾敲入且$S_T<K$ | $N\cdot(S_T/K-1)$ |

固定触发收益$N\cdot q$不随实际持有期缩短而减少，因此其经济价值高于相同名义年化、按天计息的普通雪球敲出收益。

#### 9.26.3 示例

设$N=1000$万元，期限12个月，$q=12\%$，$y_T=4\%$，$H_{out}=103\%\cdot S_0$，$H_{in}=70\%\cdot S_0$，$K=S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第2个月触发 | 第2个月观察日$S_t=104\%\cdot S_0$ | $1000\text{万元}\cdot12\%=120\text{万元}$ |
| 第8个月触发 | 第8个月观察日$S_t=104\%\cdot S_0$ | $120\text{万元}$ |
| 未触发且未敲入 | 全程未达敲出线，也未跌破敲入线 | $40\text{万元}$ |
| 曾敲入且到期未修复 | 曾跌至$68\%\cdot S_0$，到期$S_T=65\%\cdot S_0$ | $-350\text{万元}$ |

#### 9.26.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 判断标的短期内有较大概率触发敲出，重视快速锁定绝对收益 | 早期触发时收益最具吸引力；未触发并发生敲入时仍面对到期下跌损失 |
| 期权对手方 | 向投资者出售早期触发的高收益选择权，并通过障碍和未触发收益定价 | 快速上涨时需一次性支付固定收益；深跌路径需管理敲入风险 |

#### 9.26.5 总结

触发器的核心不是高年化票息，而是“触发即支付固定绝对收益”。它增强了短期敲出的回报，但不改变未触发、敲入后未修复时的下跌风险。判断该结构时，应重点区分固定触发收益与按实际持有期折算的普通票息。

### 9.27 锁盈缓冲结构

#### 9.27.1 要素

本节按`一页通图片.pdf`中的锁盈缓冲结构记录：不观察敲入，到期也不观察敲出；若存续期内提前敲出，按年化票息和实际持有天数结算。未敲出时，缓冲价以上按“期末价格减缓冲价”结算，缓冲价及以下恢复承担相对期初价格的全部跌幅。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入锁盈缓冲结构，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，示例期限12个月 |
| 名义本金 | $N$，示例取1000万元 |
| 初始保证金 | 示例为名义本金的20%，有追加保证金要求 |
| 敲出观察 | 每月特定观察日，示例$H_{out}=103\%\cdot S_0$；到期日不观察敲出 |
| 敲出票息 | 年化$y$，示例$y=20\%$；仅在提前敲出时按实际持有天数结算 |
| 缓冲价 | $B$，示例$B=80\%\cdot S_0$ |
| 敲入设置 | 无敲入线、无敲入事件 |
| 到期结算 | 未敲出时仅比较$S_T$与缓冲价$B$，不支付敲出票息 |

#### 9.27.2 损益结构

记$R=S_T/S_0-1$。提前敲出时，持有方取得$N\cdot y\cdot\frac{\text{实际持有天数}}{365}$。未敲出时，若$S_T>B$，净损益为$N\cdot(S_T-B)/S_0$；若$S_T\le B$，净损益为$N\cdot R$。因此在缓冲价处存在结算跳变，缓冲只改善到期价格高于缓冲价的区间，不构成本金保底。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个非到期敲出观察日$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、到期高于缓冲价 | 未发生提前敲出，且$S_T>B$ | $N\cdot\frac{S_T-B}{S_0}$ |
| 未敲出、到期等于或低于缓冲价 | 未发生提前敲出，且$S_T\le B$ | $N\cdot\left(\frac{S_T}{S_0}-1\right)$ |

敲出票息和未敲出的到期结算互斥；不能把提前敲出票息叠加到未敲出的线性损益中。

#### 9.27.3 示例

设$N=1000$万元，期限12个月，$y=20\%$，$H_{out}=103\%\cdot S_0$，$B=80\%\cdot S_0$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第4个月提前敲出 | 第120天观察日$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot20\%\cdot\frac{120}{365}=65.8\text{万元}$ |
| 未敲出、到期上涨5% | 全程未敲出，$S_T=105\%\cdot S_0$ | $1000\text{万元}\cdot(105\%-80\%)=250\text{万元}$ |
| 未敲出、到期高于缓冲价 | 全程未敲出，$S_T=85\%\cdot S_0$ | $1000\text{万元}\cdot(85\%-80\%)=50\text{万元}$ |
| 未敲出、到期低于缓冲价 | 全程未敲出，$S_T=75\%\cdot S_0$ | $1000\text{万元}\cdot(75\%-100\%)=-250\text{万元}$ |

#### 9.27.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 看好标的不会在到期时跌破缓冲价，或希望在缓冲价以上取得增强收益 | 提前敲出取得票息；未敲出且到期高于缓冲价时收益随价格上升；跌破缓冲价后承担相对期初价格的完整跌幅 |
| 期权对手方 | 通过敲出线、缓冲价和票息管理提前终止与到期结算风险 | 标的未敲出但处于缓冲价以上时承担增强收益支付；深跌时无需提供缓冲价以上的增强结算 |

#### 9.27.5 总结

锁盈缓冲结构的核心不是敲入后的票息抵减，而是“提前敲出票息”与“未敲出时以缓冲价为分界的到期结算”。缓冲价以上的收益从缓冲价起算，缓冲价及以下则回到相对期初价格的线性损益。应重点识别到期日是否观察敲出、缓冲价的边界归属及跳变风险。

### 9.28 限损票息结构

#### 9.28.1 要素

本节按`一页通图片.pdf`中的限损票息结构记录：不观察敲入，未敲出时到期收益只取决于到期价格，并将最大净损失锁定在限损比例。敲出票息只适用于提前敲出路径。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入限损票息结构，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，示例期限6个月 |
| 名义本金 | $N$，示例取1000万元 |
| 锁定期 | 前1个月不进行敲出观察 |
| 初始保证金 | 示例为名义本金的5%，无追加保证金要求 |
| 敲出观察 | 锁定期后每月特定观察日，$H_{out}=103\%\cdot S_0$ |
| 敲出票息 | 年化$y$，示例$y=11.7\%$；敲出时按实际持有天数结算 |
| 限损比例 | $L$，示例取$5\%$；限损价为$(1-L)S_0=95\%\cdot S_0$ |
| 敲入设置 | 无敲入线、无敲入事件 |

#### 9.28.2 损益结构

记$R=S_T/S_0-1$。提前敲出时，净损益为$N\cdot y\cdot\frac{\text{实际持有天数}}{365}$。未敲出时，若$S_T\ge S_0$，净损益为0；若$(1-L)S_0\le S_T<S_0$，净损益为$N\cdot R$；若$S_T<(1-L)S_0$，净损益为$N\cdot\max(R,-L)$。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个敲出观察日$S_t\ge H_{out}$ | $N\cdot y\cdot\frac{\text{实际持有天数}}{365}$ |
| 未敲出、到期不跌 | 未发生提前敲出，且$S_T\ge S_0$ | $0$ |
| 未敲出、到期跌幅未触及限损 | 未发生提前敲出，且$(1-L)S_0\le S_T<S_0$ | $N\cdot R$ |
| 未敲出、到期跌幅触及限损 | 未发生提前敲出，且$S_T<(1-L)S_0$ | $N\cdot\max(R,-L)$ |

限损只约束未敲出到期路径的标的价格损失，不覆盖流动性、对手方违约和合同另行约定的费用。

#### 9.28.3 示例

设$N=1000$万元，期限6个月，$y=11.7\%$，$H_{out}=103\%\cdot S_0$，$L=5\%$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第4个月提前敲出 | 第120天观察日$S_t\ge103\%\cdot S_0$ | $1000\text{万元}\cdot11.7\%\cdot\frac{120}{365}=38.5\text{万元}$ |
| 未敲出、到期上涨2% | 全程未敲出，$S_T=102\%\cdot S_0$ | $0$ |
| 未敲出、到期跌3% | 全程未敲出，$S_T=97\%\cdot S_0$ | $1000\text{万元}\cdot(-3\%)=-30\text{万元}$ |
| 未敲出、到期跌10% | 全程未敲出，$S_T=90\%\cdot S_0$ | $1000\text{万元}\cdot\max(-10\%,-5\%)=-50\text{万元}$ |

#### 9.28.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 希望预先锁定未敲出到期时的最大亏损，并接受未敲出且上涨时没有额外收益 | 提前敲出取得票息；温和下跌时承担实际跌幅；深跌时损失封顶于$L$ |
| 期权对手方 | 通过降低敲出票息或提高敲出条件，置换未敲出路径中的限损承诺 | 标的大幅下跌时承担限损成本；标的温和上涨但未敲出时无需支付到期收益 |

#### 9.28.5 总结

限损票息结构以未敲出路径的下跌限额为核心：上涨不产生到期收益，温和下跌承担实际损失，深跌由限损比例截断。敲出票息与限损到期结算是两条互斥路径，比较产品时应同时看敲出条件、实际持有期计息方式和限损边界。

### 9.29 助推器

#### 9.29.1 要素

本节采用`一页通图片.pdf`中的“敲出限损版”助推器：上行按高参与率放大收益，下行设置最大损失，达到敲出线则取得固定绝对收益。同名的无敲出双边参与率版本不与本节混用，需另行登记时再单列。

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 投资者买入助推器结构，发行方卖出该结构 |
| 标的与期限 | 单一指数、指数基金或个股等标的，示例期限12个月 |
| 名义本金 | $N$，示例取500万元 |
| 初始保证金 | 示例为名义本金的20%，有追加保证金要求 |
| 敲出观察 | 每月特定观察日，敲出线$H_{out}=103\%\cdot S_0$ |
| 敲出收益 | 固定绝对收益$q$，示例$q=9\%$；触发敲出后提前终止 |
| 执行价 | $K=S_0$ |
| 上涨参与率 | $\alpha$，示例$\alpha=300\%$；未敲出且$S_T\ge K$时适用 |
| 下行保护 | 限损比例$L$，示例$L=20\%$，对应保护价$80\%\cdot S_0$ |
| 敲入设置 | 无敲入线、无敲入事件 |

#### 9.29.2 损益结构

记$R=S_T/S_0-1$。若提前敲出，净损益为$N\cdot q$；若未敲出且$S_T\ge K$，净损益为$N\cdot\alpha\cdot R$；若未敲出且$S_T<K$，净损益为$N\cdot\max(R,-L)$。上行参与率与下行限损只作用于未敲出到期路径。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 提前敲出 | 某个敲出观察日$S_t\ge H_{out}$ | $N\cdot q$ |
| 未敲出、到期不低于执行价 | 未发生提前敲出，且$S_T\ge K$ | $N\cdot\alpha\cdot R$ |
| 未敲出、到期低于执行价 | 未发生提前敲出，且$S_T<K$ | $N\cdot\max(R,-L)$ |

该版本没有逐期票息和敲入事件；固定敲出收益、上行高参与率和下行限损构成三段互斥结算。

#### 9.29.3 示例

设$N=500$万元，期限12个月，$q=9\%$，$H_{out}=103\%\cdot S_0$，$K=S_0$，$\alpha=300\%$，$L=20\%$。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 第4个月提前敲出 | 第4个月观察日$S_t=104\%\cdot S_0$ | $500\text{万元}\cdot9\%=45\text{万元}$ |
| 未敲出、到期上涨2% | 全程未敲出，$S_T=102\%\cdot S_0$ | $500\text{万元}\cdot2\%\cdot300\%=30\text{万元}$ |
| 未敲出、到期跌10% | 全程未敲出，$S_T=90\%\cdot S_0$ | $500\text{万元}\cdot(-10\%)=-50\text{万元}$ |
| 未敲出、到期跌30% | 全程未敲出，$S_T=70\%\cdot S_0$ | $500\text{万元}\cdot\max(-30\%,-20\%)=-100\text{万元}$ |

#### 9.29.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权持有方 | 看好标的上涨，希望放大未敲出路径中的上行收益，同时锁定深跌损失 | 提前敲出取得固定收益；未敲出上涨按高参与率放大；下跌损失最多为$L$ |
| 期权对手方 | 通过敲出线、参与率和限损比例控制收益放大与下行保护成本 | 标的温和上涨且未敲出时承担高参与率赔付；深跌时承担限损承诺 |

#### 9.29.5 总结

敲出限损版助推器以高参与率放大上涨，以固定敲出收益锁定提前终止结果，并以限损比例控制深跌风险。它不是逐期加票息结构，评估时应同时比较敲出收益是否为绝对收益、未敲出上行参与率、限损比例和保证金安排。

### 10.1 Worst-Of香草看涨期权

#### 10.1.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入Worst-Of香草看涨期权，收益由两个或多个标的中表现最差者决定 |
| 标的资产 | 两个或多个指数、指数基金或个股等基础资产 |
| 期限 | 自期初持有至到期时刻T，示例取1个月 |
| 名义本金 | N，示例1000万元 |
| 初始价格 | 各标的期初价格分别记为S1,0、S2,0、…、Sn,0 |
| 相对价格 | 第i个标的在t时刻的相对价格Ri,t = Si,t / Si,0 |
| 多资产表现 | P = min(R1,R2,…,Rn)，即到期时所有标的里表现最差者 |
| 执行价 | K，示例K = 100% |
| 期权费率 | 示例取1.59%，明显低于任一单标的普通看涨期权的期权费率 |
| 到期收益 | 名义本金 × Max(P−K, 0) |
| 行权方式 | 欧式，仅在到期时刻T按P结算 |

#### 10.1.2 损益结构

净收益率 = Max(P−K, 0) − 期权费率。P取所有标的里表现最差者，只要有一个标的涨幅落后，收益即被拖累；只有全部标的都上涨、且表现最差的一个涨幅也超过K时，才产生正的行权价值。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 最差标的高于行权价 | P > K | P − K − 期权费率 |
| 最差标的不高于行权价 | P ≤ K | −期权费率 |

#### 10.1.3 示例

示例取两个标的，K = 100%，期权费率1.59%。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 到期不行权 | 标的1收95%，标的2收97%，最差表现P = 95%（P ≤ K） | −1.59% |
| 到期不行权 | 标的1收102%，标的2收100%，最差表现P = 100%（P ≤ K） | −1.59% |
| 到期小幅行权，仍亏损 | 标的1收101%，标的2收105%，最差表现P = 101% | −0.59% |
| 恰好盈亏平衡 | 标的1收105%，标的2收101.59%，最差表现P = 101.59% | 0% |
| 到期获利 | 标的1收120%，标的2收105%，最差表现P = 105% | +3.41% |
| 到期获利 | 标的1收110%，标的2收125%，最差表现P = 110% | +8.41% |

多头只有在两个标的都上涨、且表现较差的一个涨幅也超过期权费率时才净盈利；只要有一个标的滞涨或下跌，都会拖累最终收益。

#### 10.1.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断多个标的中至少有一个难以持续上涨或将跑输，愿以较低期权费率换取“只需一个标的走弱即可获利”的优势 | 只要最差标的到期涨幅不超过K，保留全部期权费；若全部标的都大涨，按最差者的涨幅赔付，赔付幅度小于分别对每个标的卖出看涨的总和 |
| 期权持有方 | 同时看好多个标的但更看重成本控制，接受收益由表现最差者决定；相较于分别买入各标的的看涨期权，Worst-Of结构期权费率明显更低 | 到期收益取决于表现最差的标的，只要最差标的涨幅超过期权费率即可盈利；只要有一个标的滞涨或下跌，都会拖累整体收益，最大亏损为期权费率 |

#### 10.1.5 总结

Worst-Of香草看涨期权由多个标的的相对表现和取最小值的规则构成：到期先算出每个标的的涨跌幅，再取其中最差者作为结算依据，最后按行权价比较是否产生收益。挂钩标的越多、相关性越低，最差表现越容易被单个弱势标的拖累，期权费率也因此明显低于分别持有各标的看涨期权的费率之和，即以“收益由最弱标的决定”换取更低成本。适合看好一篮子标的整体方向、希望以更低成本参与，并能接受收益被最弱标的拖累的情形。

### 10.4 方差互换

#### 10.4.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入方差互换（多头做多波动），到期按已实现方差与执行方差之差结算 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T，按存续期内日收益计算已实现波动率 σ |
| 执行波动率 | 执行波动率 K，示例取 K = 13（波动率点），执行方差 K² = 169 |
| 方差名义本金 | 每 1 个方差点对应的金额，示例取 2500 |
| Vega 名义 | 方差名义 × 2K，示例 2500 × 26 = 65000 |
| 已实现方差 | $\sigma^2=\frac{A}{n_{obs}}\sum_{i=1}^{n_{obs}}\left(\ln\frac{S_i}{S_{i-1}}\right)^2\times10^4$；示例年化交易日数$A=244$，$n_{obs}$为观察收益率个数 |
| 观察口径 | $S_i$为第$i$个观察日收盘价；通常从交易日后至到期日含到期的交易日序列计算，缺失值、停牌和公司行动调整以合同为准 |
| 结算变量 | 已实现年化波动率$\sigma$及其平方$\sigma^2$（已实现方差） |
| 收益时点 | 到期时刻 T 按 σ² 结算 |

#### 10.4.2 损益结构

多头到期损益 = 方差名义本金 ×(σ² − K²)。结算只看已实现波动率的平方与执行方差之差，与标的涨还是跌无关，是纯粹的波动率敞口。已实现波动率高于执行水平时多头获利、且因平方项而随波动加速放大；等于执行水平时损益为零；低于执行水平时多头亏损。多头做多波动，空头（发行方）做空波动、赚取波动率风险溢价。多头最大亏损在 σ = 0 时为 方差名义 × K²，理论最大盈利随波动率无上限。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 已实现波动率高于执行 | σ² > K²（已实现波动率高于执行） | 方差名义 ×(σ² − K²)，为正 |
| 已实现波动率等于执行 | σ² = K²（已实现波动率等于执行） | 0 |
| 已实现波动率低于执行 | σ² < K²（已实现波动率低于执行） | 方差名义 ×(σ² − K²)，为负 |

#### 10.4.3 示例

示例取执行 K = 13、K² = 169、方差名义 2500。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 已实现波动率低于执行 | 到期已实现波动率σ = 10（σ² = 100） | −17.25万元 | +17.25万元 |
| 已实现波动率等于执行 | 到期已实现波动率σ = 13（σ² = 169），恰好等于执行 | 0 | 0 |
| 已实现波动率略高于执行 | 到期已实现波动率σ = 15（σ² = 225） | +14万元 | −14万元 |
| 已实现波动率明显高于执行 | 到期已实现波动率σ = 20（σ² = 400） | +57.75万元 | −57.75万元 |

多头在已实现波动率超过执行水平后盈利，且因方差是波动率的平方，波动越大盈利加速放大；空头相反，只要波动率不超过执行水平就赚取风险溢价，一旦市场剧烈波动则亏损迅速扩大。

#### 10.4.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的未来已实现波动率将高于执行水平，或为持仓对冲波动风险；只做多波动、不含方向敞口 | 已实现波动率高于执行才盈利，且随波动率平方加速放大；低于执行则亏损，最大亏损在波动率归零时为 方差名义 × K² |
| 空头 | 发行方，判断已实现波动率将低于执行水平；收取波动率风险溢价，承担波动放大时的赔付 | 已实现波动率低于执行时获利，最大盈利即执行方差对应的金额；高于执行后亏损随波动加速扩大 |

#### 10.4.5 总结

方差互换以已实现方差与执行方差之差直接结算，收益与标的涨跌方向无关，是纯粹押注已实现波动率相对执行水平高低的结构，且因结算变量是波动率的平方，波动越大盈亏越加速放大。判断顺序只需比较到期已实现波动率与执行波动率：高于执行则多头盈利，低于执行则多头亏损。它适合直接对波动率而非价格方向进行判断或对冲的情形；卖方在波动率维持温和时能持续获得风险溢价，一旦市场剧烈波动则亏损可能迅速扩大。

| --- | --- | --- |
| 向下敲出 | 存续期内触及H，敲出 | 敲出补偿 − 期权费率 |
| 未敲出且到期实值 | 未敲出且ST < K | (K−ST)/S0 − 期权费率 |
| 未敲出且到期虚值或平值 | 未敲出且ST ≥ K | −期权费率 |

#### 10.6.3 示例

示例取S0 = 100、K = 100、H = 90、敲出补偿5%、期权费率3%，名义本金1000万元。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 有敲出 | 存续期内收盘价触及90 | 1000×(5%−3%) = 20万元 |
| 未敲出，到期低于行权价 | 全程未触及90，ST = 92 | 1000×(8%−3%) = 50万元 |
| 未敲出，到期不低于行权价 | 全程未触及90，ST = 105 | 1000×(−3%) = −30万元 |

#### 10.6.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的将触及敲出价格或跌幅有限；收取期权费率，承担未敲出且标的下跌时的赔付 | 触及敲出价格后只需按固定补偿赔付；未敲出且标的上涨或持平时保留期权费；未敲出且下跌时按跌幅赔付 |
| 期权持有方 | 温和看跌，判断标的下跌但可能触及敲出价格；愿放弃敲出价格以下的收益，换取比普通看跌更低的期权费率 | 未敲出时收益随跌幅累积，最高净收益接近行权价与敲出价格之差再扣期权费率；一旦触及敲出价格，产品提前按敲出补偿了结，不再随跌幅继续增加；未敲出且不跌则只亏期权费率 |

#### 10.6.5 总结

看跌鲨鱼鳍（DOP）在普通看跌期权上叠加向下敲出障碍：先看存续期内是否触及敲出价格，未触及时收益随跌幅累积，最高净收益接近行权价与敲出价格之差再扣期权费率；一旦触及敲出价格，产品提前按固定的敲出补偿了结，不再随跌幅继续增加。这一障碍换来了明显低于普通看跌期权的期权费率，适合看跌但预期跌幅可能触底、或愿意用跌幅下限换取更低成本的情形。

### 10.7 双边鲨鱼鳍

#### 10.7.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入双边鲨鱼鳍，设有高低两个障碍价格，同时放弃上端和下端部分收益换取更低期权费率 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | 自期初持有至到期时刻T，示例2个月 |
| 名义本金 | N，示例1000万元 |
| 敲出观察日 | 存续期内每个交易日（日频观察） |
| 期权费率 | 示例0.88% |
| 高敲出价格 | Hu，示例Hu = 115%·S0；任一敲出观察日ST ≥ Hu即向上敲出 |
| 高执行价格 | Ku，示例Ku = 105%·S0 |
| 高敲出补偿 | 示例3% |
| 高参与率 | 示例50%，用于未敲出且到期价格不低于Ku时的上行参与 |
| 低敲出价格 | Hd，示例Hd = 85%·S0；任一敲出观察日ST ≤ Hd即向下敲出 |
| 低执行价格 | Kd，示例Kd = 95%·S0 |
| 低敲出补偿 | 示例4% |
| 低参与率 | 示例80%，用于未敲出且到期价格不高于Kd时的下行参与 |
| 双边敲出优先级 | 日频观察下，以先触及的一侧敲出并终止；若合同采用盘中观察或同一观察时点存在双向触及，应在合同中明确优先级 |

#### 10.7.2 损益结构

净收益率按向上敲出、向下敲出、未敲出三种情形分别确定，均需再扣除期权费率：向上敲出按高敲出补偿了结；向下敲出按低敲出补偿了结；未敲出且到期价格不低于高执行价格时，按超出部分乘高参与率参与上行；未敲出且到期价格不高于低执行价格时，按低于部分乘低参与率参与下行；未敲出且到期价格落在两个执行价格之间时不产生行权收益。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 向上敲出 | 先于向下敲出触及$H_u$ | 高敲出补偿 − 期权费率 |
| 向下敲出 | 先于向上敲出触及$H_d$ | 低敲出补偿 − 期权费率 |
| 未敲出且到期高于上执行价 | 未敲出且ST ≥ Ku | (ST−Ku)/S0 × 高参与率 − 期权费率 |
| 未敲出且到期低于下执行价 | 未敲出且ST ≤ Kd | (Kd−ST)/S0 × 低参与率 − 期权费率 |
| 未敲出且到期落在两执行价之间 | 未敲出且Kd < ST < Ku | −期权费率 |

#### 10.7.3 示例

示例取S0 = 100、Hu = 115、Ku = 105、高敲出补偿3%、高参与率50%、Hd = 85、Kd = 95、低敲出补偿4%、低参与率80%、期权费率0.88%，名义本金1000万元。

| 情景 | 到期状态或路径 | 持有方净损益 |
| --- | --- | --- |
| 向上有敲出 | 存续期内收盘价触及115 | 1000×(3%−0.88%) = 21.2万元 |
| 向下有敲出 | 存续期内收盘价触及85 | 1000×(4%−0.88%) = 31.2万元 |
| 未敲出，到期高于高执行价 | 全程未触及敲出价格，ST = 110 | 1000×[(110%−105%)×50%−0.88%] = 16.2万元 |
| 未敲出，到期低于低执行价 | 全程未触及敲出价格，ST = 90 | 1000×[(95%−90%)×80%−0.88%] = 31.2万元 |
| 未敲出，到期落在两执行价之间 | 全程未触及敲出价格，ST = 100 | 1000×(−0.88%) = −8.8万元 |

#### 10.7.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 期权对手方 | 判断标的将维持窄幅震荡、大概率停留在两个执行价格之间；收取期权费率，承担触及任一端敲出价格或到期突破执行价格时的赔付 | 标的停留在两个执行价格之间时保留期权费率即最大盈利；触及任一端敲出价格后按对应固定补偿赔付；未敲出且突破执行价格时按参与率赔付 |
| 期权持有方 | 无需判断标的运动方向，只要标的最终触及任一端敲出价格或到期收于执行价格之外即可获得收益，接受落在两个执行价格之间时只损失期权费率 | 触及任一端敲出价格后按对应固定补偿了结；未敲出且到期突破执行价格时按参与率分享该方向的涨跌；落在两个执行价格之间时只亏期权费率 |

#### 10.7.5 总结

双边鲨鱼鳍在向上和向下同时设置敲出价格与执行价格：先看存续期内是否触及任一端敲出价格，触及后即按对应固定补偿了结；未触及时再看到期价格是否突破执行价格，突破哪一侧就按对应参与率分享该方向的涨跌，落在两个执行价格之间则只损失期权费率。相较于单边鲨鱼鳍，双边结构无需判断方向、覆盖了两个方向的机会，但每个方向的参与率和补偿也相应更保守，通常对应更低的期权费率。

### 10.8 区间计息（Range Accrual）

#### 10.8.1 要素

| 要素 | 具体说明 |
| --- | --- |
| 头寸 | 买入区间计息，按落在区间内的观察日数累计票息 |
| 标的 | 指数、指数基金、个股或商品等标的资产 |
| 期限 | T，共 N 个观察日，示例取 N = 22 |
| 区间 | [下界·S0, 上界·S0]，示例取 [94%·S0, 106%·S0] |
| 满额票息 | 全程每个观察日均在区间内时的最高收益率，示例取 1.45% |
| 单日累计 | 每个落在区间内的观察日累计 满额票息 / N |
| 期权费 | 期初支付，示例取 1.21% |
| 收益时点 | 到期时刻 T 按累计结果结算 |

#### 10.8.2 损益结构

记 P 为 N 个观察日中落在区间内的天数，满额票息记为 R_max。到期票息率 = R_max × P / N，净收益率 = R_max × P / N − 期权费。标的每在区间内停留一天就累计 R_max / N 的票息，落在区间外的天不计息。全程在区间内得满额 R_max、净赚 R_max − 期权费；全程在区间外得零票息、净亏期权费。因“停留在窄区间”才最有利，该结构做空波动率，标的越平稳越好。最大盈利 R_max − 期权费，最大亏损为期权费。

| 情景 | 判断条件 | 持有方净损益 |
| --- | --- | --- |
| 全程在区间内 | 全程在区间内（P = N） | R_max − 期权费 |
| 部分在区间内 | 部分在区间内（$0<P<N$） | R_max × P / N − 期权费 |
| 全程在区间外 | 全程在区间外（P = 0） | −期权费 |

#### 10.8.3 示例

示例取满额票息 R_max = 1.45%、N = 22、期权费 1.21%。

| 情景 | 到期状态或路径 | 持有方净损益 | 对手方净损益 |
| --- | --- | --- | --- |
| 全程在区间内 | 22个观察日中P = 22天收盘价落在区间内 | +0.24% | −0.24% |
| 部分在区间内 | 22个观察日中P = 11天落在区间内 | −0.485% | +0.485% |
| 全程在区间外 | 22个观察日中P = 0天落在区间内 | −1.21% | +1.21% |

多头在标的窄幅震荡、长期停留区间内时收益最佳；标的大幅波动、频繁走出区间时票息不足以覆盖期权费而亏损。

#### 10.8.4 适用场景

| 主体 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的在存续期内窄幅震荡、大部分时间停留在区间内；做空波动率，波动越小、停留越久越有利 | 停留在区间内的天数越多票息越高，全程在内净赚 R_max 减期权费；停留越少票息越低，全程在外只亏期权费 |
| 空头 | 发行方，判断标的会频繁走出区间；收取期权费，承担标的长期停留区间内时的票息赔付 | 标的常在区间外时保留期权费；标的长期停留区间内则按累计票息赔付 |

#### 10.8.5 总结

区间计息本质是逐日区间二元观察的加总：每个观察日先判断标的收盘价是否落在约定区间内，落在区间内的天数累计一份满额票息，落在区间外的天不计息，到期按累计天数占比结算票息并扣除期权费，属于做空波动率的路径依赖结构。区间越窄、观察频率越高，对标的稳定性的要求也越高。适合判断标的将维持窄幅震荡的情形；一旦标的持续走出区间，票息将不足以覆盖期权费，产生亏损。
