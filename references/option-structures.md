# 期权结构库

## 1 通用说明

### 1.1 记号

| 符号 | 含义 |
| --- | --- |
| S0 | 期初价格 |
| ST | 到期价格 |
| St | 存续期内 t 时刻价格,0 ≤ t ≤ T |
| T | 到期时刻 |
| K | 行权价,同一结构用到多个行权价时按大小记 K1 < K2 < K3 < K4 |

### 1.2 损益口径

多头为买方或产品持有方,空头为卖方或发行方,买卖双方构成零和,空头损益与多头损益大小相等、方向相反,故每种结构以多头列示,空头反向。损益按每份标的计并已扣期权费,结构化产品按名义本金折算收益率。有单一盈亏平衡价的结构,盈亏平衡指多头净损益等于零时的到期价格;路径依赖结构未必有单一盈亏平衡价。

### 1.3 行权与结算

欧式在到期时刻 T 依据 ST 结算,美式在存续期内任一时刻 t 依据 St 行权结算,障碍类按约定观察时点检查 St 是否触及障碍并在触及时提前结算;除特别说明外均为欧式。

## 2 方向性期权

### 2.1 看涨期权

#### 2.1.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 多头买入 1 份看涨期权 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | K,示例取 K = S0 = 100 |
| 期权费 | c,多头即买方在期初支付,空头即卖方在期初收取,示例 c = 5 |
| 行权方式 | 欧式,仅在到期时刻 T 行权;若为美式,则存续期内任一时刻 t 均可行权 |

#### 2.1.2 损益结构

多头净损益 = max(ST − K, 0) − c,其中 max(ST − K, 0) 为到期时刻的行权价值,c 为期初支付的期权费;空头损益与之大小相等、方向相反。盈亏平衡为到期价格 ST = K + c。

| 情形 | 多头净损益 |
| --- | --- |
| ST ≤ K | −c |
| ST > K | ST − K − c |

#### 2.1.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看涨,判断标的在存续期内上涨且到期涨幅超过期权费;同时做多波动率,标的越涨、波动越大越有利;隐含波动率处于较低分位、期权价格较低时买入成本更低 | ST 高于 K + c 才盈利,之后标的每上涨一元收益增加一元、没有上限;ST 落在 K 与 K + c 之间时仍亏损,但亏损小于期权费 c;ST 不高于 K 时亏损全部期权费 c,即最大亏损。相比直接买入标的,占用资金少、下行风险封顶 |
| 空头 | 温和看空到中性,判断标的不会明显上涨、大概率横盘或小幅下跌;同时做空波动率,预期隐含波动率偏高且回落,靠时间价值获利 | ST 不高于 K 时保留全部期权费 c 即最大盈利;高于 K 后按 ST − K 赔付、亏损随涨幅扩大且没有上限,盈亏平衡在 K + c。常在持有标的的同时卖出看涨即备兑,以让渡上行空间换取期权费收入 |

#### 2.1.4 示例

S0 = 100、K = 100、c = 5,盈亏平衡在 ST = K + c = 105。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 90 | ST < K,不行权 | −5 | +5 |
| 100 | ST = K,不行权 | −5 | +5 |
| 105 | 行权,恰好损益为零 | 0 | 0 |
| 110 | 行权 | +5 | −5 |
| 120 | 行权 | +15 | −15 |

多头在 ST 超过 105 后开始盈利,标的每上涨一元收益增加一元;空头在 ST 不超过 105 时盈利,最大盈利为期权费 5,超过 105 后亏损随涨幅扩大且没有上限。

### 2.2 看跌期权

#### 2.2.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 多头买入 1 份看跌期权 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | K,示例取 K = S0 = 100 |
| 期权费 | p,多头即买方在期初支付,空头即卖方在期初收取,示例 p = 5 |
| 行权方式 | 欧式,仅在到期时刻 T 行权;若为美式,则存续期内任一时刻 t 均可行权 |

#### 2.2.2 损益结构

多头净损益 = max(K − ST, 0) − p,其中 max(K − ST, 0) 为到期时刻的行权价值,p 为期初支付的期权费;空头损益与之大小相等、方向相反。盈亏平衡为到期价格 ST = K − p。

| 情形 | 多头净损益 |
| --- | --- |
| ST ≥ K | −p |
| ST < K | K − ST − p |

#### 2.2.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 看跌,判断标的在存续期内下跌且到期跌幅超过期权费,或不判断方向只为持仓买保险;同时做多波动率,标的越跌、波动越大越有利;隐含波动率较低时保护成本便宜 | ST 低于 K − p 才盈利,标的价格越低收益越大,最大收益 K − p 即标的跌到零;ST 落在 K − p 与 K 之间时仍亏损,但亏损小于期权费 p;ST 不低于 K 时亏损全部期权费 p,即最大亏损。市场大幅下跌时隐含波动率往往显著上升、保护成本上升,宜在隐含波动率较低时提前买入 |
| 空头 | 温和看多到中性,判断标的不会明显下跌、大概率横盘或小幅上涨;同时做空波动率,预期隐含波动率偏高且回落,并可接受在更低价位买入标的 | ST 不低于 K 时保留全部期权费 p 即最大盈利;到期价格低于 K 时被行权,须按行权价 K 买入标的,承担 K − ST 的亏损,最大亏损 K − p,盈亏平衡在 K − p。相当于预收期权费,并承诺在到期价格低于 K 时按 K 买入标的,也是雪球等结构中投资者承担下行风险换取票息的基础形态 |

#### 2.2.4 示例

S0 = 100、K = 100、p = 5,盈亏平衡在 ST = K − p = 95。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 110 | ST > K,不行权 | −5 | +5 |
| 100 | ST = K,不行权 | −5 | +5 |
| 95 | 行权,恰好损益为零 | 0 | 0 |
| 90 | 行权 | +5 | −5 |
| 80 | 行权 | +15 | −15 |

多头在 ST 跌破 95 后开始盈利,标的每下跌一元收益增加一元,最大收益在标的跌至零时为 95;空头在 ST 不低于 95 时盈利,最大盈利为期权费 5,到期价格跌破 95 后被行权、须按 K 买入标的并承担扩大的亏损。

## 3 垂直价差

用两个同类型、不同行权价的期权一买一卖构成,方向温和、收益封顶。设价差宽度 W = K2 − K1,净支出记 D、净收入记 C。四种价差按常用命名分别列示;其中牛市看涨与熊市看涨互为对手方、牛市看跌与熊市看跌互为对手方,同一对的两个损益反向。

### 3.1 牛市看涨价差

#### 3.1.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入 c(K1)、卖出 c(K2),K1 < K2,构成一个净支出组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | 低行权价 K1、高行权价 K2,示例 K1 = 95、K2 = 105 |
| 净支出 | D = c(K1) − c(K2),期初净额支付,示例 D = 4 |
| 行权方式 | 欧式,两腿均在到期时刻 T 行权 |

#### 3.1.2 损益结构

净损益 = max(ST − K1, 0) − max(ST − K2, 0) − D。盈亏平衡为 ST = K1 + D;最大盈利 W − D,在 ST ≥ K2 取得;最大亏损 D,在 ST ≤ K1 取得。对手方即熊市看涨价差,损益反向。

| 情形 | 净损益 |
| --- | --- |
| ST ≤ K1 | −D |
| K1 < ST < K2 | ST − K1 − D |
| ST ≥ K2 | W − D |

#### 3.1.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 温和看涨,判断标的上涨但涨幅有限、难以超过 K2;卖出高行权价腿收回部分期权费以降低成本,代价是收益封顶 | ST 高于 K1 + D 才盈利,涨到 K2 以上锁定最大盈利 W − D;ST 落在 K1 与 K1 + D 之间仍亏损但小于 D;ST 不高于 K1 时亏损全部净支出 D |
| 空头 | 温和看空到中性,即熊市看涨价差,判断标的难以上涨至 K1 以上;期初收取净额,承担有限上行风险 | ST 不高于 K1 时保留净收入即最大盈利;涨破 K2 后亏损封顶为 W − D;盈亏平衡在 K1 + D |

#### 3.1.4 示例

K1 = 95、K2 = 105、D = 4,W = 10,盈亏平衡在 ST = K1 + D = 99。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 90 | ST ≤ K1 | −4 | +4 |
| 99 | K1 与 K2 之间,恰好损益为零 | 0 | 0 |
| 105 | ST ≥ K2 | +6 | −6 |
| 110 | ST ≥ K2 | +6 | −6 |

多头在 ST 超过 99 后盈利,涨到 105 及以上收益封顶于 6;跌至 95 及以下亏损封顶于 4。收益与亏损两端都被锁定。

### 3.2 牛市看跌价差

#### 3.2.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 卖出 p(K2)、买入 p(K1),K1 < K2,构成一个净收入组合 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | 低行权价 K1、高行权价 K2,示例 K1 = 95、K2 = 105 |
| 净收入 | C = p(K2) − p(K1),期初净额收取,示例 C = 6 |
| 行权方式 | 欧式,两腿均在到期时刻 T 行权 |

#### 3.2.2 损益结构

净损益 = C − max(K2 − ST, 0) + max(K1 − ST, 0)。盈亏平衡为 ST = K2 − C;最大盈利 C,在 ST ≥ K2 取得;最大亏损 W − C,在 ST ≤ K1 取得。与牛市看涨价差到期损益等价,区别在期初收取净额而非支付。

| 情形 | 净损益 |
| --- | --- |
| ST ≥ K2 | C |
| K1 < ST < K2 | C − (K2 − ST) |
| ST ≤ K1 | C − W |

#### 3.2.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 温和看涨,判断标的不明显下跌、大概率守在 K2 以上;希望期初即收取净额,并把下行亏损锁定 | ST 不低于 K2 时保留净收入 C 即最大盈利;跌破 K1 后亏损封顶为 W − C;盈亏平衡在 K2 − C |
| 空头 | 温和看空到中性,即熊市看跌价差,判断标的下跌但跌幅有限;期初支付净额,承担有限下行收益 | ST 跌破 K2 − C 才盈利,跌到 K1 以下锁定最大盈利 W − C;ST 不低于 K2 时亏损全部净支出 |

#### 3.2.4 示例

K1 = 95、K2 = 105、C = 6,W = 10,盈亏平衡在 ST = K2 − C = 99。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 110 | ST ≥ K2 | +6 | −6 |
| 99 | K1 与 K2 之间,恰好损益为零 | 0 | 0 |
| 95 | ST ≤ K1 | −4 | +4 |
| 90 | ST ≤ K1 | −4 | +4 |

多头在 ST 不低于 105 时赚满净收入 6,跌破 99 后转亏,跌至 95 及以下亏损封顶于 4。

## 4 波动率与区间

方向多为中性,核心是押波动率大小或到期落点。跨式与宽跨式的多头做多波动率,标的波动越大越有利;蝶式与鹰式的多头相反,做空波动率,押标的到期落在特定区间、波动越小越有利。各结构多头均期初净支出、空头净收入,以多头列示、空头反向。蝶式与鹰式的净支出记 D、净收入记 C。

### 4.1 跨式

#### 4.1.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入同一行权价 K、同一到期的看涨与看跌各 1 份 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | K,示例 K = S0 = 100 |
| 成本 | c + p,期初支付,示例 c = p = 7,合计 14 |
| 行权方式 | 欧式,两腿均在到期时刻 T 行权 |

#### 4.1.2 损益结构

多头净损益 = |ST − K| − (c + p)。两个盈亏平衡为 ST = K − (c + p) 与 ST = K + (c + p);最大亏损 c + p,在 ST = K 取得;上行与下行收益均无上限。空头损益与之大小相等、方向相反。

| 情形 | 多头净损益 |
| --- | --- |
| ST < K | K − ST − (c + p) |
| ST = K | −(c + p) |
| ST > K | ST − K − (c + p) |

#### 4.1.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的短期大幅波动但方向不明,如重大事件公布前;做多波动率,要求已实现波动显著超过隐含波动 | ST 偏离 K 超过 c + p 才盈利,无论上行下行、偏离越大收益越大且无上限;停在 K 附近亏损最大,为 c + p |
| 空头 | 判断标的窄幅震荡、无大行情,预期隐含波动率偏高且回落;做空波动率,靠时间价值获利 | ST 停在 K 附近赚满 c + p 即最大盈利;偏离 K 超过 c + p 后转亏,方向剧烈波动时亏损无上限,须对冲 |

#### 4.1.4 示例

K = 100、c = p = 7,成本 14,盈亏平衡在 ST = 86 与 ST = 114。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 80 | ST < K | +6 | −6 |
| 86 | 下行盈亏平衡 | 0 | 0 |
| 100 | ST = K | −14 | +14 |
| 114 | 上行盈亏平衡 | 0 | 0 |
| 120 | ST > K | +6 | −6 |

多头在 ST 跌破 86 或涨过 114 后盈利,停在 100 附近亏损最大 14;空头相反,标的越接近 100 越有利。

### 4.2 宽跨式

#### 4.2.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入低行权价看跌 p(Kp) 与高行权价看涨 c(Kc),Kp < Kc |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | 看跌行权价 Kp、看涨行权价 Kc,示例 Kp = 90、Kc = 110 |
| 成本 | c + p,期初支付,示例合计 8 |
| 行权方式 | 欧式,两腿均在到期时刻 T 行权 |

#### 4.2.2 损益结构

多头净损益 = max(Kp − ST, 0) + max(ST − Kc, 0) − (c + p)。两个盈亏平衡为 ST = Kp − (c + p) 与 ST = Kc + (c + p);最大亏损 c + p,在 Kp ≤ ST ≤ Kc 取得;两侧收益无上限。空头损益反向。

| 情形 | 多头净损益 |
| --- | --- |
| ST < Kp | Kp − ST − (c + p) |
| Kp ≤ ST ≤ Kc | −(c + p) |
| ST > Kc | ST − Kc − (c + p) |

#### 4.2.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的大幅波动、方向不明,但希望比跨式更低成本;做多波动率 | 用更虚值的行权价降低成本,ST 突破 Kp − (c + p) 或 Kc + (c + p) 才盈利,需要更大波动;落在 Kp 与 Kc 之间亏损最大,为 c + p |
| 空头 | 判断标的长期区间震荡;做空波动率,安全区比卖出跨式更宽 | ST 落在 Kp 与 Kc 之间赚满 c + p、胜率高于卖出跨式,但收取的期权费较少;突破区间后亏损无上限 |

#### 4.2.4 示例

Kp = 90、Kc = 110,成本 8,盈亏平衡在 ST = 82 与 ST = 118。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 78 | ST < Kp | +4 | −4 |
| 82 | 下行盈亏平衡 | 0 | 0 |
| 100 | Kp 与 Kc 之间 | −8 | +8 |
| 118 | 上行盈亏平衡 | 0 | 0 |
| 122 | ST > Kc | +4 | −4 |

多头在 ST 跌破 82 或涨过 118 后盈利,落在 90 与 110 之间亏损最大 8;空头相反。

### 4.3 蝶式

#### 4.3.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入 c(K1)、卖出 2 份 c(K2)、买入 c(K3),K2 = (K1 + K3) / 2;全用看跌构造损益相同 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | K1 < K2 < K3,示例 K1 = 90、K2 = 100、K3 = 110 |
| 净支出 | D,期初净额支付,示例 D = 2.5 |
| 行权方式 | 欧式,各腿均在到期时刻 T 行权 |

#### 4.3.2 损益结构

多头净损益 = max(ST − K1, 0) − 2·max(ST − K2, 0) + max(ST − K3, 0) − D,在 ST = K2 达峰 (K2 − K1) − D。两个盈亏平衡为 ST = K1 + D 与 ST = K3 − D;最大盈利 (K2 − K1) − D,在 ST = K2 取得;最大亏损 D,在 ST ≤ K1 或 ST ≥ K3 取得。对手方即卖出蝶式,损益反向。

| 情形 | 多头净损益 |
| --- | --- |
| ST ≤ K1 或 ST ≥ K3 | −D |
| K1 < ST ≤ K2 | ST − K1 − D |
| K2 < ST < K3 | K3 − ST − D |

#### 4.3.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的到期正好落在 K2 附近、波动收敛;以很低成本博一个精确落点 | ST 落在 K1 + D 与 K3 − D 之间才盈利,恰好收在 K2 时收益最大 (K2 − K1) − D,偏离越远越少;落到两端之外亏损最大,为 D,金额小且已知 |
| 空头 | 判断标的到期明显偏离 K2、朝任一方向走出去,即卖出蝶式;温和做多波动率 | ST 远离 K2 至两端之外时保留净收入即最大盈利;恰好收在 K2 时亏损最大且有限 |

#### 4.3.4 示例

K1 = 90、K2 = 100、K3 = 110、D = 2.5,盈亏平衡在 ST = 92.5 与 ST = 107.5。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 90 | ST ≤ K1 | −2.5 | +2.5 |
| 92.5 | 下侧盈亏平衡 | 0 | 0 |
| 100 | ST = K2,峰值 | +7.5 | −7.5 |
| 107.5 | 上侧盈亏平衡 | 0 | 0 |
| 110 | ST ≥ K3 | −2.5 | +2.5 |

多头在 ST 落于 92.5 与 107.5 之间盈利,收在 100 时最大 7.5;偏离到 90 及以下或 110 及以上亏损最大 2.5。

### 4.4 鹰式

#### 4.4.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入 c(K1)、卖出 c(K2)、卖出 c(K3)、买入 c(K4),K1 < K2 < K3 < K4 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | K1 < K2 < K3 < K4,示例 K1 = 85、K2 = 95、K3 = 105、K4 = 115 |
| 净支出 | D,期初净额支付,示例 D = 3 |
| 行权方式 | 欧式,各腿均在到期时刻 T 行权 |

#### 4.4.2 损益结构

多头净损益 = max(ST − K1, 0) − max(ST − K2, 0) − max(ST − K3, 0) + max(ST − K4, 0) − D,在 K2 ≤ ST ≤ K3 形成高度 (K2 − K1) − D 的平台。两个盈亏平衡为 ST = K1 + D 与 ST = K4 − D;最大盈利 (K2 − K1) − D,在 K2 到 K3 取得;最大亏损 D,在两端之外取得。对手方即卖出鹰式,损益反向。

| 情形 | 多头净损益 |
| --- | --- |
| ST ≤ K1 或 ST ≥ K4 | −D |
| K1 < ST < K2 | ST − K1 − D |
| K2 ≤ ST ≤ K3 | (K2 − K1) − D |
| K3 < ST < K4 | K4 − ST − D |

#### 4.4.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的到期落在 K2 与 K3 区间、波动收敛,但不押死具体一点;比蝶式容错高 | ST 落在 K1 + D 与 K4 − D 之间才盈利,落在 K2 与 K3 之间收益最大 (K2 − K1) − D;两端之外亏损最大,为 D。最高收益略低于同宽蝶式,换来更宽的获利区间 |
| 空头 | 判断标的到期走出 K2 与 K3 区间、方向不明,即卖出鹰式;温和做多波动率 | ST 落在两端之外时保留净收入即最大盈利;落在 K2 与 K3 之间亏损最大且有限 |

#### 4.4.4 示例

K1 = 85、K2 = 95、K3 = 105、K4 = 115、D = 3,盈亏平衡在 ST = 88 与 ST = 112。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 85 | ST ≤ K1 | −3 | +3 |
| 88 | 下侧盈亏平衡 | 0 | 0 |
| 100 | K2 与 K3 之间,平台 | +7 | −7 |
| 112 | 上侧盈亏平衡 | 0 | 0 |
| 115 | ST ≥ K4 | −3 | +3 |

多头在 ST 落于 88 与 112 之间盈利,落在 95 与 105 之间收益最大 7;偏离到两端之外亏损最大 3。

## 5 障碍期权

在普通期权上附加价格触发条件。敲出型在存续期内触及障碍 H 时作废,敲入型在触及 H 后才生效。记普通看涨到期价值 max(ST − K, 0)、看跌 max(K − ST, 0):敲出型净损益 = 普通期权到期价值 ×(全程未触及 H 记 1,否则 0)− 期权费;敲入型净损益 = 普通期权到期价值 ×(触及过 H 记 1,否则 0)− 期权费。敲入敲出平价:同方向、同 K、同 H,买入敲入与买入敲出之和等于买入对应普通期权。观察多为每日观察,障碍附近损益不连续。以下均以多头列示,期权费示例取 5,空头损益反向。

### 5.1 向上敲出看涨

#### 5.1.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入向上敲出看涨,存续期内触及 H 即作废 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期或敲出时刻 |
| 行权价 | K,示例 K = S0 = 100 |
| 障碍价 | 向上障碍 H > K,示例 H = 120 |
| 观察 | 每日观察 St 是否触及 H |
| 期权费 | c,期初支付,示例 c = 5 |
| 收益时点 | 敲出时按 −c 结清;未敲出在到期时刻 T 结算 |

#### 5.1.2 损益结构

净损益 = max(ST − K, 0) ×(全程未触及 H)− c。未敲出时同普通看涨、收益随 ST 上行但因 ST < H 而封顶,接近 H − K − c;触及 H 敲出则为 −c。未敲出时盈亏平衡 ST = K + c。

| 情形 | 净损益 |
| --- | --- |
| 触及 H,敲出 | −c |
| 未敲出且 ST > K | ST − K − c |
| 未敲出且 ST ≤ K | −c |

#### 5.1.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 温和看涨,判断标的上涨但难以触及 H;放弃触及 H 之后的行情以换取低于普通看涨的期权费 | 未敲出时 ST 超过 K + c 才盈利,收益随涨幅但被 H 封顶,最高接近 H − K − c;触及 H 敲出只亏期权费 c |
| 空头 | 判断标的会较快触及 H 使合约作废;收取期权费,承担未敲出且标的上行时的赔付 | 触及 H 后保留全部期权费;未敲出且 ST 上行时按多头收益反向赔付 |

#### 5.1.4 示例

K = 100、H = 120、c = 5,未敲出时盈亏平衡在 ST = 105。

| 情景 | 多头净损益 | 空头净损益 |
| --- | --- | --- |
| 存续期内触及 120,敲出 | −5 | +5 |
| 未敲出,ST = 100 | −5 | +5 |
| 未敲出,ST = 105 | 0 | 0 |
| 未敲出,ST = 115 | +10 | −10 |

多头只在标的始终不触及 120、且到期收在 105 以上时盈利,收益最高接近 15;触及 120 即敲出,亏损为期权费 5。

| 期权费 | p,期初支付,示例 p = 5 |
| 收益时点 | 敲出时按 −p 结清;未敲出在到期时刻 T 结算 |

#### 5.5.2 损益结构

净损益 = max(K − ST, 0) ×(全程未触及 H)− p。未敲出时同普通看跌、下行收益随跌幅增大;涨破 H 敲出则为 −p。未敲出时盈亏平衡 ST = K − p。

| --- | --- |
| 触及 H,敲出 | −p |
| 未敲出且 ST < K | K − ST − p |
| 未敲出且 ST ≥ K | −p |

#### 5.5.3 适用场景

| --- | --- | --- |

## 6 二元与数字期权

按到期价格或存续期内是否触碰障碍,支付一笔固定赔付,押的是是非题或概率。记赔付发生的条件成立取 1、否则取 0。恒等关系:同 K 的现金二元看涨与看跌之和等于赔付 Q;同 H、同到期的触碰即付与不碰才付之和等于赔付 Q。现金二元与触碰型的最大盈利为赔付减期权费、最大亏损为期权费;资产二元赔付为标的价值。以下以多头列示,空头损益反向。

### 6.1 现金二元看涨

#### 6.1.1 要素

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入现金二元看涨,到期 ST > K 支付固定 Q,否则归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,自期初持有至到期时刻 |
| 行权价 | K,示例 K = S0 = 100 |
| 赔付 | 固定金额 Q,示例 Q = 20 |
| 期权费 | c,期初支付,示例 c = 8 |
| 收益时点 | 到期时刻 T 依据 ST 判定 |

#### 6.1.2 损益结构

净损益 = Q ×(ST > K)− c。到期损益是 K 处从 −c 跳到 Q − c 的阶梯,与涨幅无关。最大盈利 Q − c,最大亏损 c。

| 情形 | 净损益 |
| --- | --- |
| ST ≤ K | −c |
| ST > K | Q − c |

#### 6.1.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断到期标的能否站上 K,只关心是否过线、不关心涨幅;对某价位到期能否守住有明确概率判断 | ST 站上 K 得固定净收益 Q − c;未站上亏期权费 c。赔付固定,不随涨幅变化 |
| 空头 | 判断到期标的站不上 K;收取期权费,承担站上后的固定赔付 | ST 不高于 K 时保留期权费即最大盈利;站上 K 后固定赔付 Q、净亏 Q − c |

#### 6.1.4 示例

K = 100、Q = 20、c = 8。

| 到期价格 ST | 情形 | 多头净损益 | 空头净损益 |
| --- | --- | --- | --- |
| 95 | ST ≤ K | −8 | +8 |
| 100 | ST ≤ K | −8 | +8 |
| 101 | ST > K | +12 | −12 |
| 120 | ST > K | +12 | −12 |

多头只要到期站上 100 即净赚 12,涨到 101 与涨到 120 收益相同;未站上则亏期权费 8。

| 要素 | 取值 |
| --- | --- |
| 头寸 | 买入不碰才付,存续期内全程未触及 H 才支付固定 Q,触及即归零 |
| 标的 | 指数、指数基金或个股等标的资产 |
| 期限 | T,全程观察 |
| 障碍价 | 触碰价 H,示例 H = 115 |
| 赔付 | 固定金额 Q,示例 Q = 20 |
| 观察 | 每日观察 St 是否触及 H |
| 期权费 | c,期初支付,示例 c = 8 |
| 收益时点 | 到期时刻 T 结算,存续期内触及 H 则提前作废 |

#### 6.6.2 损益结构

净损益 = Q ×(全程未触及 H)− c。全程不触及 H 才得 Q,中途触及一次即归零。最大盈利 Q − c,最大亏损 c。

| 情形 | 净损益 |
| --- | --- |
| 全程未触及 H | Q − c |
| 触及 H | −c |

#### 6.6.3 适用场景

| 立场 | 动机与观点 | 盈亏情形 |
| --- | --- | --- |
| 多头 | 判断标的始终在区间内、不会突破到 H,即窄幅震荡;波动越小越有利 | 全程未触及 H 得净收益 Q − c;中途触及一次即归零、亏期权费 c |
| 空头 | 判断标的迟早会触及 H;收取期权费,承担全程未触及时的固定赔付 | 触及 H 后保留期权费即最大盈利;全程未触及则固定赔付 Q、净亏 Q − c |

#### 6.6.4 示例

H = 115、Q = 20、c = 8。

| 情景 | 多头净损益 | 空头净损益 |
| --- | --- | --- |
| 全程未触及 115 | +12 | −12 |
| 存续期内触及 115 | −8 | +8 |

多头只要标的全程不触及 115 即净赚 12;中途触及一次即作废、亏期权费 8。与触碰即付方向相反,波动越小越有利。
