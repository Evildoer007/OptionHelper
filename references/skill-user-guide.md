## 一、首次配置与开始使用

### 1.1先配置模型和数据接口

在宿主中配置模型API地址、密钥和模型ID，并测试连接。已有可用模型直接复用。Skill不读取App配置，也无需登录App。

按以下顺序准备：

1. 确认宿主已安装并启用OptionHelper，且允许调用本地工具。尚未安装时，先阅读随包的[安装与配置说明](../README.md)。
2. 检查模型连接和工具能力。认证失败核对地址与密钥，模型不可用核对ID与权限，超时检查网络。
3. 需要行情时，在本机配置iFind Refresh Token并检查连接。它与模型密钥不能互换，也不要作为聊天内容发送。
4. 计算前检查Python和锁定依赖，缺项先说明再安装。行情仍需核对标的、字段及日期覆盖。

可以先发一句：

> 使用OptionHelper，先检查模型工具能力、运行环境和数据连接。缺少配置时告诉我从哪里填写，不要开始定价或回测。

纯产品咨询无需行情或Python；计算前再补齐所需条件。

### 1.2开始第一个问题

启用Skill后，直接说明需求：

> 用OptionHelper解释看涨期权和看涨价差的区别，重点说明成本、收益上限和亏损情形。先不计算。

确认回复正常后，补充标的、条款和日期，再发起计算。

### 1.3可以得到什么

| 需求 | 通常得到的内容 |
| --- | --- |
| 解释条款 | 收益机制、触发条件、成本、风险和适用情景 |
| 比较或推荐结构 | 结构差异、适配理由、不适合的情形和待确认条款 |
| 分析收益结构 | 条件路径、收益情景、关键边界及可用收益图 |
| 估值与Greeks | 合同估值、敏感度、市场假设、计算方法及精度信息 |
| 历史回测 | 入场样本、合同结算、路径事件、统计指标及覆盖限制 |
| 正式交付 | 研究简报、完整研究报告、参考报价或多结构对比文件 |

普通问题先返回分析结论。只有明确要求文件时，才生成相应正式交付。

## 二、研究需求与条款确认

### 2.1一条计算需求的基本条件

通常需要明确标的、方向、期限、产品或收益结构、关键条款、估值日或历史区间，以及希望得到什么结果。推荐还需要市场观点、收益偏好和损失承受能力。多标的结构逐一列出标的，不用一个名称替代整篮子资产。

> 挂钩000300.SH，期限三个月，研究买入平值看涨期权。请先列出估值需要的条件，缺项一次问完。

不确定的条件可以直说。Skill会合并追问影响结果的关键缺口，复用同一对话中已确认的条件。输入不完整不意味着可以把任意示例当成真实合同。

### 2.2已有条款文件怎么办

宿主支持附件时，可以提供条款文件或图片，并说明用途。能否解析扫描件、表格或图片取决于宿主，不是所有宿主都具备相同的附件能力。

> 先阅读这份条款，整理标的、期限、观察日、敲入敲出和票息。列出冲突或无法确认的内容，暂不计算。

上传成功、文字提取成功、条款确认完成、正式计算完成是不同状态。模糊图片、缺页或单位不清时，需要补充材料。

## 三、产品解释与结构比较

咨询适合先理解机制，不必直接进入推荐或计算。可以指定分析范围，避免得到不需要的结果。

> 只比较雪球和安全气囊的到期损失机制，解释障碍恰好命中时怎样判断。不下载数据、不定价、不回测。

读比较结论时，逐项看成本、本金损失、收益上限、参与率、路径依赖、观察频率和提前终止。名称相同但障碍、票息或观察规则不同，可能是不同合同，不能只比较产品名称。

数值收益情景要对应明确条款和受控计算。固定示例图帮助理解机制，不代表你本次合同已经计算完成。

## 四、结构推荐

### 4.1提供筛选条件

推荐需要明确标的、期限、市场观点、收益偏好和损失承受能力。损失约束用于筛选，不代表一定存在满足条件的产品。

> 我判断沪深300未来六个月温和上涨，希望比较收益封顶和不封顶的方案。请解释成本与本金损失情形，先给推荐理由，不计算、不生成报告。

阅读候选时，核对适配理由、不适合的市场情景及待确认条款。已经指定产品时，可以直接要求分析该产品，无需重新推荐。

### 4.2比较与验证

直接说明需要比较的产品、关注的问题和是否需要计算。当前对话根据产品资料分析适用条件，按需要调用收益分析、定价和回测。

> 比较已经选定的两个结构，说明各自的成本、收益上限和主要风险。可以使用已有计算结果；需要新计算时，沿用已确认的合同和市场条件。

明确要求只比较、不计算时，不启动金融计算。已有适用证据可复用；数据缺失、计算失败或尚未验证的部分应明确列出，不能把产品解释当成已经完成估值或回测。

## 五、收益结构与情景

收益结构回答哪些市场路径对应哪些合同现金流。通常先核对期限、行权价、票息、障碍和观察规则，再检查上涨、震荡、下跌以及边界情景。

> 按已确认条款生成收益结构。说明敲入、敲出、未触发和普通到期分别怎样结算，保留期初费用的原口径。

路径型产品不能仅凭到期价格判断收益。两条路径可能具有相同终值，却在中途触发不同事件。边界的“大于”“大于等于”、观察时点和是否提前终止，应以本次合同为准。

收益图可能固定部分历史条件，仅展示某个区间或情景。图中的采样最低、最高值不一定是整个产品的最大损失或最大收益。收益图也不是概率分布或未来预测。

## 六、估值、Greeks与反解

### 6.1发起估值

> 沿用当前合同，按指定估值日完成估值与Greeks，列出实际采用的行情日期、波动率、利率和分红率。

可以使用解析定价或Monte Carlo。支持解析定价时默认优先采用解析方法；需要Monte Carlo时，使用明确的正整数路径数，不为了提高显示精度擅自增加路径数。用户指定方法、路径数或随机条件时，应保留这些要求。

新发合同和存续合同不能混用。存续的路径型合同还需要截至估值日的历史观察状态。遇到周末、节假日或请求日行情尚不可用时，应同时披露请求估值日和实际采用的数据日期。

### 6.2估值与风险指标

先看合同、日期和市场假设，再看价值。估值是给定模型下的合同价值，不是保证收益或可成交报价。

| 指标 | 阅读重点 |
| --- | --- |
| 标准误 | Monte Carlo估计的不确定性，不是未来亏损上限 |
| Delta | 价值对标的价格的一阶敏感度，同时看标的坐标与单位 |
| Gamma | 二阶价格敏感度，不能直接当作一次价格变化的损益 |
| Vega | 按结果披露的波动率变动单位阅读，不重复做百分比换算 |
| Theta | 按结果披露的时间单位与符号阅读 |
| Rho | 价值对利率变化的敏感度，保留原单位 |
| Vanna、Volga | 有提供时阅读交叉或二阶风险单位；未提供不等于零 |

Greeks描述当前状态附近的局部敏感度。障碍附近、临近到期或市场大幅变化时，不能只用简单线性外推替代重新估值。多标的共同变化的敏感度不等于单只资产的对冲数量。

### 6.3百分比与名义本金

标准化基准100不是金融基点。Skill的正式估值、回测和报告目前沿用百分比口径，不提供App任务级名义本金控件或金额附表。用户可以询问单位含义；不能因此把未经过正式金额接口验证的换算称为已经完成的交易规模估值。本说明不改变当前Skill的计算接口。

### 6.4公平参数反解

反解回答什么条款值能满足指定目标，例如求票息或行权价。只有明确要求且该产品支持该目标时，才执行反解；普通估值不会自动变成反解。

> 请检查当前产品是否支持公平票息反解。支持时说明目标和固定条件，再按已确认条件执行，报告收敛情况和适用限制。

反解结果要看目标、残差、不确定性和资格状态。仅供研究的结果不能作为正式参考报价交付。

## 七、历史回测

### 7.1设置回测条件

> 回测已确认的六个月雪球，入场区间为2019年至2023年，按月入场。先核对行情覆盖，报告有效样本、排除原因、结算结果和敲入敲出情况。

入场区间并不等于所需行情的全部区间。每笔样本还需要覆盖持有至到期或有效提前终止的观察日；最后一个入场日之后仍可能需要较长行情。

### 7.2检查回测结果

依次核对合同版本、标的顺序、入场规则、样本范围、有效样本和排除原因，然后看逐笔结算、路径事件、公共统计及产品专属指标。零有效样本不是零收益，缺失指标也不能当成零。

高频入场样本可能覆盖同一段历史行情，不能当作相互独立的投资。逐笔合同收益不是可直接交易的账户净值，重叠样本收益不能直接相加成账户收益。

### 7.3HV是什么

HV是用入场前历史价格变化计算的历史波动率，可作为分组分析的特征。窗口不足或价格无效时，需要查看相应限制。

关闭HV特征表示本次不计算这一额外特征或分组，不表示把产品波动率设成零，也不改变合同的收益规则。历史敲入率、敲出率和盈利比例取决于样本，不能当作未来概率保证。

## 八、数据与运行准备

### 8.1运行前检查

| 检查项 | 要求 |
| --- | --- |
| Python环境 | 运行计算前确认解释器，沿用已选环境；未选择时由宿主列出可用环境 |
| 依赖 | 使用随包锁定依赖；缺少或版本不符时，先说明再安装 |
| 数据连接 | 获取新行情前检查iFind连接，通过本机输入流程配置凭据 |
| 行情覆盖 | 核对标的、日期、字段和复权口径，另行核对交易日历 |

已有完整合同的收益分析，以及基于有效结果重新导出报告，不一定需要新行情。已有可用环境、连接和适用数据时，直接复用。

### 8.2处理缺失条件

数据请求失败时，按连接、凭据、权限和覆盖范围逐项排查。不能用编造价格、替换标的或更改日期来代替缺失数据。交易日历不能用普通工作日推算。

### 8.3保存位置

运行数据和结果保存在当前项目中，Skill安装目录保持只读。具体位置和配置方法见[安装与配置说明](../README.md)。密钥不写入普通研究问题、报告或对外分发的文件。

## 九、报告与参考报价

### 9.1选择交付形式

| 交付物 | 适合的用途 |
| --- | --- |
| 研究简报 | 集中阅读推荐理由、条款、估值摘要、回测摘要和主要风险 |
| 完整研究报告 | 查看收益结构、定价、历史回测及更完整的研究依据 |
| 参考报价 | 查看多个合同版本的期限、执行价、期权费和必要条款 |
| 多结构研究简报或完整报告 | 在一份文件中比较明确选择的多个结构 |

> 基于当前已完成且条款一致的收益结构、估值和回测，生成HTML完整研究报告，给我文件链接。

未指定格式时默认HTML，也可明确要求PDF。参考报价是模型参考，不是交易承诺；报价表不承诺包含Greeks或回测图。

### 9.2复用已有结果

明确指向当前对话中的结果、合同版本或已有报告。符合要求的已验证结果可以用于生成文件，已有冻结事实可以换格式或调整报告详略，不必为换文件格式重新计算。

> 把刚才的完整研究报告导出PDF，沿用原事实，不重新取数、估值或回测。

多个结构可以生成单份对比报告；参考报价也可组合多个已保存合同版本，不要求都来自同一份旧报告。不要把参数或估值日期不同的结果当作同一份合同。

### 9.3核对交付状态

计算或资料覆盖不足时，可能只能得到部分结果或不可用说明。部分完成不能称为完整报告。正式文件必须由现成的报告与渲染链路生成，模型解释不能替代缺失计算。

只有文件实际生成后才提供对应链接。宿主能预览时可以直接打开；不能预览时返回可访问文件位置并说明限制。文件生成不表示已经发给任何客户。

## 十、修改、继续与停止

在同一研究对话里继续补充条件，明确改什么、保留什么。宿主对跨对话历史的保留能力不同，新对话不应假定自动继承完整条款和结果。

> 把期限改为三个月，其他条款不变，重新估值并比较变化。暂不重新回测。

改变经济条款需要形成新合同，只重算受影响且用户要求的部分；旧结果继续对应旧输入，不会被改贴到新参数下。已经明确授权的参数调整不需要反复确认。

停止入口由当前宿主提供。发出停止指令后，查看宿主和运行状态；取消正在生成的回复不必然等于底层计算已经终止。重新执行前先核对是否仍在运行，以及上一轮是否留下完整可用结果。

## 十一、完整案例

以下演示操作顺序，不包含真实报价或计算结论。

### 11.1只理解产品

> 解释牛市看涨价差的成本、收益上限和最大损失，并说明到期价格恰好等于两个执行价时如何结算。与单独买入看涨期权比较，先不计算。

核对适用条款和端点含义；具体条款与默认示例不一致时，补充后再讨论。这一过程不需要行情、估值或报告。

### 11.2已有产品，完成研究与交付

1. 检查模型工具能力、计算环境及所需数据连接。
2. 说明产品、标的和期限，上传或补充条款，确认观察规则与合同日期。
3. 要求分析收益结构，核对障碍、提前终止和到期结算。
4. 指定估值日，完成估值与Greeks，检查市场日期、模型和单位。
5. 指定历史入场区间及频率，完成回测，检查样本和排除原因。
6. 确认结果对应所需合同后，生成报告并检查导出文件。

### 11.3从观点到多结构比较

1. 提供标的、期限、市场观点、损失约束与收益偏好，选择研究方式。
2. 阅读候选理由及风险，补充影响筛选的缺项。
3. 确认要比较的结构和条款，执行需要的计算。
4. 明确每个合同采用的结果，生成一份多结构研究简报或完整报告。
5. 后续修改时指明对象与范围，保留其他条件。

## 十二、常见问题

| 问题 | 处理顺序 |
| --- | --- |
| 不能调用Skill或计算工具 | 检查宿主是否启用Skill、模型工具能力及本地工具权限，再检查运行环境 |
| 只咨询产品是否需要行情 | 不需要；产品机制可依据资料解释，需要新行情或计算时再准备对应条件 |
| 没有返回价格 | 确认已要求估值，检查执行状态、待补充条件和失败原因 |
| 修改参数后仍有旧结果 | 旧结果对应原合同；重新计算后核对新条款、日期和来源，再更新报告 |
| 与上次结果不同 | 对比合同、市场日期、模型、波动率、路径数、随机条件和观察状态 |
| 报告缺少内容 | 检查所选来源是否具备对应计算，以及合同和日期是否匹配 |
| 找不到App中的控件 | Skill通过宿主对话使用，不提供App的参数页面；按本说明提出需求 |

日常使用从本说明开始即可。安装问题见[安装与配置说明](../README.md)，产品范围见[产品列表](optionlist.md)，具体规则见[条款资料](optionlib.md)。
